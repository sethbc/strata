# Strata 3.2: Performance Setting and One Grain Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every voice's grains read a buffer (voice rings, a shared input ring with history, or a slot), with pitch as the grain rate; on that path add freeze, per-grain variation and scales, loop regions, a per-voice filter and sends, freeing bypass, longer buffers, and a hardware performance setting that the engine decides at `alloc`.

**Architecture:** Wave 0 splits the engine into `lib/engine/Strata*.sc` extension files that register themselves as areas, splits the engine check and its notes per area, and adds the Lua registries, all with no behavior change. Wave 1 builds the performance setting and the one grain path with neutral hook methods. Wave 2 fills the hooks in five parallel packages, each owning its own engine file, Lua module, check area and docs. Wave 3 releases.

**Tech Stack:** SuperCollider 3.13.0 (norns and CI; class extensions `+ Engine_Strata { }`), core UGens only (`GrainBuf`, `BufWr`, `Phasor`, `PV_MagFreeze`, `RLPF`/`RHPF`/`BPF`, `FreeVerb2`, `DelayL`, `AllpassN`, `LocalIn`/`LocalOut`); Lua 5.3 and LuaJIT for the tests against `test/norns_stubs.lua`; the engine check through `test/run_engine_check.sh` on `$STRATA_SC_PORT`.

**Spec:** `docs/design/3.2-design.md` (approved 2026-11-08, with its "Decisions (2026-11-08)"). It binds over `docs/design/3.1-3.6-roadmap.md` for 3.2. Read the design sections a task names before starting it.

## Global Constraints

- Everything in CLAUDE.md applies: replace-never-stack, `cutSynth`, `openedGate`, `sendToSynth`, fade-before-zeroing and `slotChanges`, the mirror rules and `silentBus`, limiter before the saturator, the velocity invariant, the command table, Lua as the only source of values, `send_param_to_engine`, `request_redraw()`, the layout tests, bounds checks, cleanup steps.
- **No package after Wave 0 edits `lib/Engine_Strata.sc`.** Engine files are named `Strata*.sc` (helper classes too). Extension files add methods only, never variables. An engine file is never renamed or deleted without a norns restart note in the changelog fragment.
- **Two new commands only:** `setScale(root, mask)` `"ii"` (root 0-11, mask a 12-bit pitch-class set) and `setBypass(effect, bypassed)` `"ii"` (effect 0 delay, 1 reverb, others ignored; bypassed 0 or 1). Everything else is a grain param.
- **Ring constants:** `ringSeconds` 4 s per voice ring; input ring `historySeconds + ringGuardSeconds + 1` (`ringGuardSeconds` 4: 21 s standard, 65 s high); `ringReadMargin` 0.005 s; `ringSpreadSeconds` 0.5 s; ring rates clipped to ±`ringMaxRate` (4); slot rates not clipped; grain duration after size jitter capped at 0.5 s; `pitchShift` 0.25-4 is the grain rate.
- **Lookback (§2.3):** continuous `D = margin + history + spreadOffset + max(r - 1, 0) * dur` (`r > 0`), `D = margin + history + spreadOffset` (`r < 0`); triggered `dur' = min(dur, dur / (r - 1))`, `D' = margin + history + max(r - 1, 0) * dur'`, `spreadOffset` 0 in triggered mode.
- **Tiers:** standard `bufferSeconds` 16, high 16/60/120/300 (default 60) stepped down until slots and rings leave at least 1 GB (1048576 kB) of `MemAvailable`; `maxGrains` 128 and `grain_density` maximum 100 on both; input history 16 s / 60 s; spectral freeze and the FDN reverb on high only; `auto` picks high only when the model contains `Raspberry Pi 4` or `Compute Module 4`.
- **Files:** settings `data/strata/performance.data` (`performance auto|standard|high`, `buffer_seconds 16|60|120|300`; missing = auto, 60); active `data/strata/performance_active.data` (`tier`, `buffer_seconds`, `max_grains`, `history_seconds`, `reason`); the engine runs high only if it wrote the active file.
- **`bufferStateStride` is 1000** (and `BUFFER_STATE_STRIDE`). `BUFFER_SECONDS` stops being a constant: Lua reads `S.performance.buffer_seconds`; `S.constants.STANDARD_BUFFER_SECONDS` is 16.
- **Real-time memory floors at 3.2's worst case** (every voice: a live ring grain synth, an input grain synth in its 2 s release, a buffer grain synth in its 50 ms cut): at least 3 MB free on standard (12 probes of 256 KB) and 4 MB on high (16 probes, spectral freeze engaged on every voice). These replace the 1 MB rule. Never size a delay line or table from a control.
- **3.1's sound by default** apart from the accepted pitch change: no reverse, no jitter, intervals off (`interval_prob` 100%), quantize off, scale off, root C, loop 0/1, history 0, freeze off, sends 1, voice filter mix 0, bypass off.
- **Scenes:** `SCENE_DATA_VERSION` 3; every new per-voice field defaults to the values above; discrete keys `freeze`, `freeze_mode`, `intervals`, `quantize`, `filter_type` (and the custom intervals) switch at the end of a transition; globals `scale`, `root`; the bypass params are PSET-only, never scene fields. Randomize and mutations never touch a 3.2 param. 3.2's per-voice params stay off the 256 fader pages (`fader = false`).
- **Bypass is explicit:** only `delay_bypass`/`reverb_bypass` free and re-create a node; a mix at 0 (LFO, scene fade, PARAMS, CC) only silences.
- **Lua registries are read at init** (inside a `register_params` add or later), never at include time, so include order between a registering module and its reader never matters.
- Changelog: each package adds `changes/3.2-<package>.md` (`### Added` / `### Changed` / `### Fixed`, a bullet under each heading used). A feature package never edits CHANGELOG.md; `docs/status.md` changes in Wave 3 only.
- US English in code, comments and docs (the spelling test covers `lib/engine/` and `test/engine_check/` from Wave 0). Docs never name the maintainer.
- After every task: `lua test/run.lua`, `luajit test/run.lua`, `lua test/sync_check.lua` pass; a task that touches engine code or a check area also passes `STRATA_SC_PORT=<its port> test/run_engine_check.sh` (all areas before pushing; its own areas while working, through `STRATA_ENGINE_CHECK_AREAS`).

## Review Focus

1. **A quantized `freq` turned slowly.** One encoder detent or one arc tick moves the raw value less than a scale step; a filter that snaps to the nearest tone of the new value sticks forever on the encoder, and one that snaps in the direction of motion jumps a tone per arc tick. The filter must snap a per-voice unsnapped shadow value, so travel of about one semitone moves about one scale tone on either control. Test in 2b ("a quantized freq moves by scale tones on slow encoder and arc turns").
2. **Stored LFO destination indices.** `strata_lfo<n>_dest` is an option index stored in PSETs and scenes. A registered destination inserted inside the per-voice blocks would retarget every saved LFO after it. Registered destinations go after every built-in one, in registration order. Test in 0c ("built-in LFO destinations keep their indices").
3. **A garbled, stale or newer-release settings file.** A hand-edited `performance.data` (`performance turbo`, `buffer_seconds 999`) or a truncated `performance_active.data` must give auto/60 in the engine and standard in Lua, with one console line, never an error or a tier the two disagree on. Tests in 1a ("an active file with an unknown tier or buffer length gives standard"; engine "performance: a garbled settings file means auto and 60 s").
4. **High-tier values on a standard start.** A PSET or scene saved on high (history 45 s, record duration 200 s, freeze mode spectral) loaded on standard must clamp silently, and the engine must never receive an out-of-range value. Tests in 1b ("a high-tier history recalled on standard plays at most 16 s") and 2a ("spectral freeze mode recalled on standard freezes in hold").
5. **A loop at the end of the slot.** Start set to 1, or a length of 0.001 on a slot shorter than a grain: Lua clamps start to 0.999 and the length to `1 - start`, and the engine keeps every grain inside the valid region. Tests in 2c ("loop start 1 clamps to 0.999 and the length to 0.001"; engine "loops: a loop shorter than a grain never reads past the valid region").

## Self-review notes (design ambiguities and how this plan resolves them)

- **VOICE rows hook.** §8 and §10 give 0c `lib/pages/voice.lua`, but the rows come from `voice_page_rows` in `lib/ui/voice_rows.lua` (3.1 Wave 1). 0c edits that file (a coordination point) and touches `lib/pages/voice.lua` only if the VOICE page cannot edit a binary row.
- **No per-voice group.** §8 says `add_voice_params` sizes each voice's group, but voices use separators today. `count` is asserted per record; the params go under one `voice <i> extras` separator.
- **Registry timing and LFO indices.** Registries are read at init, and registered LFO destinations go after every built-in one in registration order, so saved option indices keep their meaning.
- **Values Wave 1 must change** (`bufferStateStride` 1000, `standardBufferSeconds`) live in `lib/Engine_Strata.sc` today; 0a makes them methods of the owning area file, and also declares `ringSeconds`/`ringGuardSeconds` so 1a's memory arithmetic and 1b share one definition.
- **Grain controls and the stub.** The stub reads SynthDef `arg` lists, so 1b writes the two defs as literal `SynthDef` blocks that declare every 3.2 control with neutral defaults. A `rateLevel` control keeps the synth-source grain synth from bending twice, so 1b need not edit `StrataVoices.sc`.
- **The performance reader** must run before any param is added; init has no such hook, so 1a registers a first `register_params("performance", ...)` record that adds no params.
- **The high memory floor needs spectral freeze**, which arrives in Wave 2: `test/engine_check/memory.scd` passes from 1b to 2a in Wave 2; the FDN joins the high run by itself once 2d merges.
- **2c's reverse check** cannot use 2b's `reverseProb` while both are open: 2c tests `slotGrainPos` at rate −1 in a check-only def, and the second of the two to merge adds the end-to-end case.
- **Quantized `freq`** snaps a per-voice shadow (Review Focus 1); the custom intervals are discrete; scale "off" quantizes to semitones (mask 4095).
- **Freeze mode** is always a param (one option on standard) so PSETs and scenes keep their shape.
- **1 GB** of `MemAvailable` is taken as 1048576 kB.
- **User docs after 3.1's split:** `docs/user/controls.md` and `docs/user/grid.md` become per-page and per-grid files; freeze docs go there, and Wave 3 adds the pointer in `voices-and-grains.md`, so 2a and 2b never share a page.
- **The 3.1 freeze-name scans** are narrowed by 2a. In code, `[F]` is allowed in `lib/pages/main.lua` only, and `toggle_freeze`, `[FREEZE]`, `_freeze(` and `start_or_freeze` stay banned. In docs, Task 1.11's word ban becomes a phrase rule.
- **0b and 3.1-owned docs:** `docs/notes/engine.md` stays as an index until Wave 3, so 0b edits no `docs/user/`, `docs/notes/lua/` or `docs/status.md` file while 3.1 Waves 1-2 are open.
- **High-tier cases of 1b** (the history range at 60 s, the 4 MB floor) need 1a's decision. The second of 1a and 1b to merge adds them. `h.write_performance_active` is 1a's.
- **`scaleNote`** is resent on every change that moves it (`freq`, root, quantize, source), not only in `sync`.
- **VOICE tests and layout states** come from `voice_page_rows` and the records' `layout_states` (0c), so the Wave 1-2 packages never edit `pages_voice_test.lua` or `lib/pages/voice.lua`.
