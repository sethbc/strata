# Strata 3.1 Waves 1-2: UI Foundation and Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every Strata action reachable from the norns' keys and encoders (ALT on K1, fine adjustment, center detents, eight pages with a field cursor), bring the 128h, 128v and 64 grids up to the 256's features, and give the arc center fill, new page rings and the button on every page.

**Architecture:** Wave 1 is one serial package that builds every shared interface Wave 2 needs (page records with ALT and hint hooks, header, `field_list`, `delta_with_detent`, cursors, VOICE rows, randomize undo, the grid hold/gesture core, the arc core) and splits the shared docs and tests so each Wave 2 package owns disjoint files. Wave 2 is twelve parallel packages, one per page, grid layout or arc ring set, each in its own worktree and pull request, touching only its own files plus registration lines.

**Tech Stack:** Lua 5.3 (norns) and LuaJIT for tests, the norns stubs in `test/norns_stubs.lua`, the per-module test runner from Wave 0b (`lua test/run.lua [filter]`).

**Spec:** `docs/design/3.1-design.md` (§0, §2-§7, §9). Builds on `docs/superpowers/plans/2026-11-07-3.1-wave0-restructure.md` (module layout, registries, test split). Read the design sections a task names before starting it.

## Global Constraints

- No engine change (`lib/Engine_Strata.sc`, `test/engine_check.scd` untouched) and no sound change. The single default change is the LFO depth: 25% (§5 LFO).
- No new scene fields: `SCENE_DATA_VERSION` stays 2; the scene field `frozen` and the code name `frozen` stay; only the UI says "lock".
- `UI_PAGES = {"MAIN", "VOICE", "SEQ", "FX", "LFO", "BUFFER", "SCENES", "SETUP"}`, `NUM_UI_PAGES` 8. E1 steps pages and stops at the ends.
- K1 is a hold-only key: norns delivers it after `KEY1_HOLD_TIME` (0.25 s). ALT = K1 held. Every ALT+K2/ALT+K3 action goes through `alt_action(page, key)`, so the 0.6 s long-press fallback can call it.
- ALT+E3 fine adjustment: control params move a tenth of their raw step (`params:set_raw(id, params:get_raw(id) + d * quantum / 10)`); number and option params ignore ALT unless the page gives ALT+E3 a meaning. The arc has no fine mode.
- Center detents: a param whose range spans 0 holds at 0 for the next 3 encoder detents after crossing it, or the next 24 arc ticks. Every `params:delta` from encoders goes through `delta_with_detent(id, d)`.
- Randomize undo window: `UNDO_SECONDS` = 5.
- Header (all pages): title x 0; eight 2×2 px page dots from x 40, 4 px apart, current at level 15, others 3; `[M]`, play mark (filled 3×5 triangle), `REC` (level 15); scene `S1`-`S8` right-aligned at 127. `header_flash(text)` replaces dots and indicators for 1.5 s.
- Grid: holds per port (`grid_held[port][x][y] = press time`), scene save on a 0.5 s hold, step level from a second key on a held step's row. Pages per port.
- Everything in CLAUDE.md applies: `request_redraw()` only, vport-only grid/arc handlers, `send_param_to_engine`, `param_fraction` for every ring, the screen layout tests (no overlap, nothing off-screen, hint row, MAIN divider), bounds checks, cleanup of every clock and poll.
- Only `strata.lua` calls `include`; modules follow Wave 0's constructor shape (`return function(S) local M = {} ... return M end`). No module comes within 30 locals of the limit (the per-file probe test).
- Each package adds a changelog fragment `changes/3.1-<package>.md` (`### Added` / `### Changed` / `### Fixed` with bullets) and updates its own `docs/user/` page and notes file. CLAUDE.md and `docs/status.md` change only in Wave 1 (and Wave 3); a Wave 2 package that finds a rule missing says so in its pull request.
- US English in code, comments and docs. Docs never refer to the maintainer by name.
- All three checks pass after every task: `lua test/run.lua`, `luajit test/run.lua`, `lua test/sync_check.lua`.

## Review Focus

1. **Encoder acceleration across zero.** norns delivers `d` of 2-5 per event on a fast turn; a delta that jumps from -0.04 straight past 0 must still land on 0 and start the hold. Test in Task 1.4 ("an accelerated delta across zero lands on zero").
2. **Rows shrinking under a cursor.** A grid key, MIDI or scene recall switches the selected voice's source to input while VOICE's cursor sits in the synth section (or a BUFFER/SETUP list changes length). The cursor must clamp to a real row and the arc's group must follow. Tests in Task 1.5 (`field_list.clamp`) and 2b ("the VOICE cursor clamps when the synth section disappears").
3. **A grid unplugged mid-hold.** A scene-save hold or the 64's half-toggle hold is pending when the grid is removed (or the script cleans up). The hold must be canceled: no save, no clock error. Test in Task 1.9 ("removing a grid cancels its pending holds").
4. **ALT released before K2 on BUFFER.** K1 down, K2 down (clear), K1 up, K2 up: K2's release must not open the file browser, because the press was an ALT press. Test in Task 1.3 ("a key pressed with ALT releases through the ALT path") and 2e ("ALT+K2 clear never opens the file browser").
5. **An overwrite confirmation armed for one scene.** ALT+K3 on populated S3 arms "K3 again"; the cursor then moves to populated S4 and ALT+K3 is pressed. S4 must not be overwritten without its own confirmation. Test in 2f ("moving the cursor disarms the overwrite").

### Task 1.4: `delta_with_detent`, fine adjustment and param helpers

**Files:**
- Create: `lib/ui/detent.lua`
- Modify: `lib/ui/params.lua` (add `param_spans_zero`, `param_default`), `lib/arc/core.lua` (`arc_sweep_param` passes ticks), every page and arc file that calls `params:delta` on an encoder or ring value (FX E3, MAIN E3, LFO E3, BUFFER E3, SETUP E2/E3)
- Modify: `test/norns_stubs.lua` (`ParamSet:get_raw(id)`, `ParamSet:set_raw(id, v, silent)` as `lua/core/params/control.lua` does: raw clamped to 0-1 and stored unrounded, `get` rounds through `controlspec:map`)
- Test: `test/unit/ui_detent_test.lua`

**Interfaces:**
- Produces: `S.constants.DETENT = {encoder_detents = 3, arc_ticks = 24}`, `S.constants.FINE_DIVISOR = 10`.
- Produces: `param_spans_zero(id) -> boolean` (control or number param with `min < 0 < max`), `param_default(id) -> number` (controlspec default, or the number/option param's `default`).
- Produces: `delta_with_detent(param_id, d, opts)` (global). `opts` nil for encoders: fine adjustment when `S.alt_held` and the param is a control; hold counted in detents (`|d|`). `opts = {arc_ticks = n}` from `arc_sweep_param`: no fine adjustment; hold counted in ticks. Algorithm: if the param doesn't span zero, plain delta. If a hold is active and the value is still 0, subtract the units from the hold; while the remainder is >= 0 the value stays 0, below 0 the hold ends and this delta applies. Otherwise apply the delta; if the value was non-zero and the result is 0 or has the other sign, set exactly 0 and start a hold of `encoder_detents` or `arc_ticks`. A hold ends when the value is found non-zero (moved by anything else).

## Self-review notes (design ambiguities and how this plan resolves them)

- **Three new pages, not two.** §9 Wave 1 says "the two new pages registered as stubs", but §5 adds VOICE, SEQ and SCENES. Wave 1 registers all three.
- **MAIN's lock mark.** §3 says `[LOCK]` at x 127 on MAIN's status row; §5 says `[L]` (the long forms don't fit). §5 is the detailed layout, so MAIN uses `[L]` and `[T]`.
- **Header x positions.** §5's x 80/94/100 overlap a right-aligned `S8` under the harness's width estimate; Wave 1 uses 76/90/96 (same order and spacing). The SEQ header's tempo replaces the indicators through `header_status`.
- **The arc button.** §7 says "as K3 does" but lists VOICE start/stop, SEQ play/stop and LFO on/off, which are not those pages' K3 actions. The explicit list wins.
- **Grid step toggles.** Steps keep toggling on press; the second key of the level gesture is consumed, so "the held step doesn't toggle on release" holds without delaying taps.
- **SCENES ring 1** moves over the same stops as E2 (slots, then fields).
- **LFO strip** shows one field at a time with `<`/`>` and `n/7`; seven fields don't fit on one line. The offset field appears if the offset test passes (the library adds it to `scaled`, which Strata applies).
- **Bypass fallbacks** for an effect never above 0: filter 1 (as now), delay 0.3, reverb 0.3.
- **Input meter scale**: 6 dB per segment from -48 dB.
- **Shared docs and notes**: Wave 1 splits `docs/user/controls.md`, `docs/user/grid.md`, the page/grid/arc notes and tests into one file per Wave 2 package, and writes CLAUDE.md for all of 3.1, so Wave 2 packages touch disjoint files.
