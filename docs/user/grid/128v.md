# 8×16 Grid Layout (128 buttons vertical)

Five pages: patterns, faders, scenes, sources and positions. Back to [Monome Grid](../grid.md).

**Choosing this layout**: a monome 128 reports itself as 16×8, lying flat (the [16×8 layout](128h.md)). Stand it upright and, on the [SETUP page](../pages/setup.md), set its port's rotation (`grid 1 rotation` for a grid on port 1, see SYSTEM > DEVICES > GRID) to 90 or 270, whichever puts the cable where you want it: Strata turns the grid and uses this layout at once, on page 1. The setting stays with the port, so the grid comes up upright at the next start or when plugged in again. A grid that reports itself as 8×16 needs no rotation.

**Column 8: Controls (every page)**
- Rows 1-7: Toggle voices 1-7 on/off
- Row 8: Next page (patterns → faders → scenes → sources → positions → patterns). Its brightness shows the page: dimmest on patterns, full on positions
- Row 9: Play/stop sequencer
- Rows 10-16 (patterns, faders and scenes pages): Select the voice (row 10 = voice 1 ... row 16 = voice 7); the selected one is lit. The faders page shows the selected voice

**Patterns page**
- Columns 1-7: Voices 1-7, 16 steps each from top (step 1) to bottom (step 16)
- Hold a step and press another key in the same column to set the step's level: the lower the second key, the higher the level (row 16 = 15, row 8 = 8)

**Faders page**
- Columns 1-4: Four upright faders for the selected voice. Press a key to set the value: row 16 is the minimum, row 1 the maximum. The fader lights up to its value
- Column 5: Fader page selector (the same groups of four as the 256's fader pages); the lit keys are the pages the voice has, the shown one brightest
- Column 7, rows 10-16: Lock or unlock voices 1-7 (row 10 = voice 1; lit = locked, dim = not). Rows 1-9 of column 7 do nothing

**Scenes page**
- Column 1, rows 1-8: Recall scenes 1-8 at once (the current scene brightest, and the scene a crossfade goes to blinks, one change per crossfade step, until it lands; while the scene sequencer runs, the scene it will recall next is lit a little dimmer; empty slots are skipped)
- Column 2, rows 1-8: Recall with a transition (the scene transition time)
- Column 3, rows 1-8: Save the scene: hold for half a second (the key lights while you hold it; letting go sooner saves nothing)
- Column 4, row 1: Scene sequencer on/off
- Column 4, rows 9-16: Scene sequence length 1-8

**Sources page**
- Columns 1-7: Each voice's source, one column per voice: row 1 synth, rows 2-9 buffers 1-8, row 10 the live input (the selected source brightest, an empty buffer dim)
- Row 12, columns 1-8: Record into buffer 1-8 with the record settings, as the [BUFFER](../pages/buffer.md) page's K3 does (the source, duration or beats, level, feedback, loop, threshold and sync); press again while it records to stop it and keep what was captured, or while it is armed to cancel it, recording nothing. Lit bright while recording, a little dimmer (11) while armed (waiting for its threshold or a synced start), half while the buffer holds audio
- Row 13, columns 1-8: Clear buffer 1-8
- Row 14, columns 1-7: Freeze or unfreeze each voice (bright while frozen, dim otherwise; see [VOICE](../pages/voice.md))

**Positions page**
- Columns 1-7: Each buffer voice's position, one column per voice, 16 cells down from the start of its slot (row 1) to the end (row 16). The selected voice's column (the one the bookmark keys act on) is lit one step brighter, so it shows faintly even with no buffer. Press a cell to jump there and select that voice (outside the voice's loop the loop goes back to the whole buffer first). Hold one cell and press another in the same column to set the loop from the start of the earlier cell to the end of the later one, in either order. What a press does and what the cells show: [Positions](../grid.md#positions)
- Column 8, rows 10-13: The selected voice's bookmarks 1-4: press to recall. Hold row 14 (store) and press one to store the current position. The strip's lights: [Positions](../grid.md#positions)
- Column 8, row 14: Store (hold). While it is held you can select another voice with a position press, and a bookmark press stores for the voice now selected. Row 15: Hold the scan while pressed. Row 16: Loop back to the whole slot
- Column 8, rows 1-9 work as on every page
