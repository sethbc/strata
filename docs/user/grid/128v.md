# 8×16 Grid Layout (128 buttons vertical)

Four pages: patterns, faders, scenes and sources. Back to [Monome Grid](../grid.md).

**Column 8: Controls (every page)**
- Rows 1-7: Toggle voices 1-7 on/off
- Row 8: Next page (patterns → faders → scenes → sources → patterns). Its brightness shows the page: dim on patterns, brighter on faders and scenes, full on sources
- Row 9: Play/stop sequencer
- Rows 10-16 (patterns, faders and scenes pages): Select the voice (row 10 = voice 1 ... row 16 = voice 7); the selected one is lit. The faders page shows the selected voice

**Patterns page**
- Columns 1-7: Voices 1-7, 16 steps each from top (step 1) to bottom (step 16)
- Hold a step and press another key in the same column to set the step's level: the lower the second key, the higher the level (row 16 = 15, row 8 = 8)

**Faders page**
- Columns 1-4: Four upright faders for the selected voice. Press a key to set the value: row 16 is the minimum, row 1 the maximum. The fader lights up to its value
- Column 5: Fader page selector (the same groups of four as the 256's fader pages); the lit keys are the pages the voice has, the shown one brightest

**Scenes page**
- Column 1, rows 1-8: Recall scenes 1-8 at once (the current scene brightest; while the scene sequencer runs, its position is lit a little dimmer)
- Column 2, rows 1-8: Recall with a transition (the scene transition time)
- Column 3, rows 1-8: Save the scene: hold for half a second (the key lights while you hold it; letting go sooner saves nothing)
- Column 4, row 1: Scene sequencer on/off
- Column 4, rows 9-16: Scene sequence length 1-8

**Sources page**
- Columns 1-7: Each voice's source, one column per voice: row 1 synth, rows 2-9 buffers 1-8, row 10 the live input (the selected source brightest, an empty buffer dim)
- Row 12, columns 1-8: Record into buffer 1-8 (press again to stop early). Lit bright while recording, half while the buffer holds audio
- Row 13, columns 1-8: Clear buffer 1-8
