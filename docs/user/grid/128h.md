# 16×8 Grid Layout (128 buttons horizontal)

Patterns, parameter faders, scenes, and sources and buffer slots, on four pages. Back to [Monome Grid](../grid.md).

**Row 8: Multi-function Controls** (every page)
- Columns 1-4: Play/stop (all four light while the pattern plays)
- Columns 5-8: Pages 1-4 (patterns, faders, scenes, sources); the shown page is bright
- Columns 9-15: Voice toggle on/off
- Column 16: Selects the next voice for the faders on page 2 (after voice 7 comes voice 1)

**Patterns page (row 8, column 5)**
- Rows 1-7: one voice per row, 16 steps per pattern
- Press a key to toggle its step; hold a step and press another key on its row to set its level (see [Monome Grid](../grid.md))

**Faders page (row 8, column 6)**
- Rows 1-4: four faders for the selected voice. Press a column to set the value: column 1 = minimum, column 16 = maximum, following each parameter's curve, with a column that sets exactly zero on faders whose range runs through zero. The row lights up to the current value (dim bar, bright value position). The faders and their order are the same as the 16×16's (see [16×16 Grid Layout](256.md))
- Row 5: Fader page selection. Each page shows the next four parameters; columns 1-4, 1-5 or 1-6 light, depending on how many parameters the voice has, and the selected page is bright
- Row 6, columns 1-7: Select the voice the faders edit (bright = selected)
- Row 7, columns 1-7: Lock/unlock each voice (lit = locked)

**Scenes page (row 8, column 7)**
- Row 1: Scene recall (instant), scenes 1-8
- Row 2: Scene recall (with transition)
- Row 3: Scene save (hold for half a second, as on the 256)
- Row 4: Set scene sequence length (1-8)
- Row 5, Column 1: Toggle scene sequencer

**Sources page (row 8, column 8)**
- Rows 1-7, columns 1-10: each voice's source, one voice per row: column 1 = synth, columns 2-9 = buffers 1-8, column 10 = input. The selected source is bright and empty buffers are dimmest
- Rows 1-2, columns 13-16: Record into buffers 1-4 (row 1) and 5-8 (row 2); press again to stop a recording early. Bright while recording, medium when the buffer holds audio, dim when empty
- Rows 3-4, columns 13-16: Clear buffers 1-4 (row 3) and 5-8 (row 4)
- Column 12, rows 1-7: Freeze or unfreeze each voice (bright while frozen, dim otherwise; see [VOICE](../pages/voice.md))
