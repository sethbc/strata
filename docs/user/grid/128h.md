# 16×8 Grid Layout (128 buttons horizontal)

Patterns, parameter faders, scenes, and sources and buffer slots, on four pages, and a fifth page for buffer positions. Back to [Monome Grid](../grid.md).

A monome 128 lying flat uses this layout (its port's rotation on [SETUP](../pages/setup.md) at 0 or 180); stood upright (90 or 270) it uses the [8×16 layout](128v.md).

**Row 8: Multi-function Controls** (every page)
- Columns 1-4: Play/stop (all four light while the pattern plays)
- Columns 5-8: Pages 1-4 (patterns, faders, scenes, sources); the shown page is bright
- Columns 9-15: Voice toggle on/off (lit 12 running, 6 running but muted or silenced by a solo, 2 stopped)
- Column 16: Selects the next voice for the faders on page 2 (after voice 7 comes voice 1)

**Patterns page (row 8, column 5)**
- Rows 1-7: one voice per row, 16 steps per pattern
- Tap a key to turn its step on or off: since 3.4 the step changes when you let go, not when you press. Hold a step and press another key on its row to set its level; hold a step for 0.3 s to open the step editor for it, and let go to close it (see [Monome Grid](../grid.md))

**Faders page (row 8, column 6)**
- Rows 1-4: four faders for the selected voice. Press a column to set the value: column 1 = minimum, column 16 = maximum, following each parameter's curve, with a column that sets exactly zero on faders whose range runs through zero. The row lights up to the current value (dim bar, bright value position). The faders and their order are the same as the 16×16's (see [16×16 Grid Layout](256.md))
- Row 5: Fader page selection. Each page shows the next four parameters; columns 1-4, 1-5 or 1-6 light, depending on how many parameters the voice has, and the selected page is bright
- Row 5, column 16: the macro key. From the voice's faders, a press shows the macro bank MOD shows now on rows 1-4 (it changes nothing elsewhere); each further press shows the next bank (after bank 4 comes bank 1), and the bank shows on MOD and every other grid too; the press after the fourth bank shown since entering (whichever bank that is) goes back to the voice's faders. Rows 1-4 are the bank's four macros (column 1 = 0, column 16 = 1). Its brightness shows which: dim on the voice's faders, brighter for each bank, brightest on bank 4. Each grid keeps its own choice of faders or macros; the bank is the same everywhere, so a bank picked on MOD or another grid shows here at once. A fader page key (row 5), a voice key (row 6) or row 8's column 16 goes back to the voice's faders, on that page of that voice
- Row 6, columns 1-7: Select the voice the faders edit (bright = selected)
- Row 7, columns 1-7: Lock/unlock each voice (lit = locked)

**Scenes page (row 8, column 7)**
- Columns 1-16 are scenes 1-16 on rows 1-3 (columns 1-8 the first bank, 9-16 the second), as on the 256
- Row 1: Scene recall (instant), scenes 1-16; the current scene is bright (the scene a crossfade goes to blinks, one change per crossfade step, until it lands), and while the scene sequencer runs the scene it will recall next (empty slots are skipped) is a little dimmer, as on the 256
- Row 2: Scene recall (with transition)
- Row 3: Scene save (hold for half a second, as on the 256)
- Row 4: Set scene sequence length (1-16, one column per scene)
- Row 5, Column 1: Toggle scene sequencer
- Row 5, Columns 13-16: Gesture recorders 1-4. A tap (let go within half a second) starts recording (from the first thing you move), plays what was recorded, stops it and plays it again, acting as you let go; hold a key for half a second to clear its recorder (holding never plays, records or stops another recorder's recording first, and letting go after the clear does nothing). Lit 15 while recording, 10 playing, 5 stopped, 2 empty
- Row 6: The morph fader (PARAMETERS > morph): column 1 is scene A, column 16 scene B, and the columns between blend the two

**Sources page (row 8, column 8)**
- Rows 1-7, columns 1-10: each voice's source, one voice per row: column 1 = synth, columns 2-9 = buffers 1-8, column 10 = input. The selected source is bright and empty buffers are dimmest
- Rows 1-2, columns 13-16: Record into buffers 1-4 (row 1) and 5-8 (row 2) with the record settings, as the [BUFFER](../pages/buffer.md) page's K3 does (the source, duration or beats, level, feedback, loop, threshold and sync); press again while it records to stop it and keep what was captured, or while it is armed to cancel it, recording nothing. Bright while recording, 11 while the slot is armed (waiting for its threshold or a synced start), medium when the buffer holds audio, dim when empty
- Rows 3-4, columns 13-16: Clear buffers 1-4 (row 3) and 5-8 (row 4)
- Column 12, rows 1-7: Freeze or unfreeze each voice (bright while frozen, dim otherwise; see [VOICE](../pages/voice.md)), at the next beat or bar while PARAMETERS > sequencer > quantize actions is on
- Column 11 lights the row of the grid voice, the voice the bookmark keys below act on (it is not a key)
- Row 5, columns 13-16: the grid voice's bookmarks 1-4 (press to jump; with store held, press to store the playhead)
- Row 6, column 13 store (hold it, then press a bookmark; while it is held you can change the grid voice, and a bookmark press stores for the voice now shown), column 14 hold the scan (while held), column 15 the whole slot as the loop. The grid voice is the one selected with row 8's column 16 or page 2's row 6. The strip's lights: [Positions](../grid.md#positions)

**Positions page (press the sources key, row 8 column 8, while on the sources page; press it again to go back)**
- Rows 1-7: one voice per row, 16 cells across its buffer. Press a cell to jump the voice there (and make it the grid voice; outside the voice's loop the loop goes back to the whole buffer first); hold one and press another on the row to set the loop from the start of the earlier cell to the end of the later one, in either order. Only voices reading a buffer respond. What a press does and what the cells show (the waveform, the loop, the playhead brightest): [Positions](../grid.md#positions)
- The sources key shows bright on the sources page and medium on the positions page
