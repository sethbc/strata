# 8×8 Grid Layout (64 buttons)

Pattern sequencing, one half of the 16 steps at a time. Back to [Monome Grid](../grid.md).

**Rows 1-7: Pattern Sequencer**
- One row per voice, showing steps 1-8 or steps 9-16 (hold row 8 column 1 to switch)
- Patterns are always 16 steps long: the half you don't see keeps playing
- The playhead lights in the shown half
- Hold a step and press another key in the same row to set the step's level (column 8 = 15, column 4 = 8)

**Row 8: Controls**
- Column 1: Tap to play/stop (it acts when you let go). Hold for half a second to cycle steps 1-8, steps 9-16 and the position view (see below). Lit bright while the shown half plays; while the other half plays it blinks with the beat (on for one beat, off for the next). When stopped it shows which half is up: dim for steps 1-8, brighter for steps 9-16
- Columns 2-8: Toggle voices 1-7 on/off

Each 8×8 grid has its own half; a grid plugged in shows steps 1-8.

**Position view** (the third view of row 8 column 1's hold; the key shows 15 while playing and 6 stopped)
- Rows 1-2: the selected voice's buffer as 16 positions (row 1 the first half, row 2 the second). Press one to jump there. Hold one and press another to set the loop between them (the two may be on different rows)
- Row 3: the bookmark strip. Columns 1-4 recall a bookmark; hold column 6 (store) and press one to store it (while store is held you can pick another voice on row 7: a bookmark press stores for the voice now picked). Column 7 holds the scan; column 8 puts the loop back to the whole buffer
- Rows 4-6: dark
- Row 7, columns 1-7: pick the voice (bright selected, medium a buffer voice, dim other)
- Row 8: columns 2-8 still toggle voices

**What the 8×8 leaves to the screen**: it has no faders, no scene page and no source, record or clear keys. Choose each voice's source and record, load and clear buffers on the [BUFFER](../pages/buffer.md) page (or VOICE, or PARAMETERS), and freeze a voice on [VOICE](../pages/voice.md). Save and recall scenes on [SCENES](../pages/scenes.md). Lock voices and edit their parameters on [MAIN](../pages/main.md) and VOICE. The position view shows a voice only while it reads a buffer, so set a voice's source on the screen first.
