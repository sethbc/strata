# VOICE

Every parameter of the selected voice. Back to [Screen Controls](../controls.md).

A placeholder in this build: the page shows only its name and the hint `E1:page`, and ignores the encoders, keys and arc. In 3.1 it lists every parameter of the selected voice in four sections (synth, grain, crossmod, mix), with the arc's rings following the cursor's group of four. Until then the voice's parameters are in PARAMETERS and on the 16×16 grid's fader page.
