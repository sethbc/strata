## Must not break

- **A voice's synth is its type** (3.8, design §0.3): `voiceTypeDefs` lists each type's voice SynthDef in type order, one name a line, and a type package only appends its line (Lua's types, package 0d, are registered in the same order). Voice v starts on type v (`areaState[\voices][\types]`, set in `allocVoiceState`), so the list has at least `numVoices` entries (the stub's parse fails otherwise). Every reader asks `voiceDefFor(voice)`: `startVoiceSynth`, `gateVoice`'s re-gate, an extra note's `startNoteSynth`, `notesUnfrozen`; `ownNotePairs` asks `voiceTypeDefs.includes(defName)`. `voiceSynthDefs`, declared in `lib/Engine_Strata.sc`, is no longer assigned, and nothing reads it.
- **`setVoiceType(voice, type)` ignores anything else without a line**: a voice outside 0..`numVoices` - 1 or a type outside 0..`numVoiceTypes` - 1, or either not an integer (`validVoice`, `validVoiceType`), as the other voice commands do (`docs/notes/engine/voices.md`); it is no guarded command. The voice's own type again is a no-op.
- **A stopped, buffer or input voice only records its type**: its next start on the synth source (`voiceOn`, or `setGrainSource(v, 0)` on a running voice) plays the type's def. So does a running voice whose voice synth failed to start (`synths[voiceKey]` nil): the watcher's restart (`voiceSynthFreed`) or the next start takes the type.
- **A switch cuts, never releases**: on a running synth voice `replaceVoiceType` runs `switchVoiceType` in one bundle: it frees the voice's cutting set (`freeCuttingSynths`), cuts its voice synth (`cutVoiceSynth`: the kill fade, `switchCutTime`), starts the new def at the head of `voiceGroup` (`startVoiceSynth`) and restarts its live voice synth notes (`restartVoiceNotes`). So type switches leave a voice two voice synths at most, the new and the cut, however fast they come (the source-switch cycles keep their own bound, three: `docs/notes/engine/lifecycle.md`). Both methods keep closures (the bundle's function, the new synth's `onFree`), so both are called only through `areaCall` and are `AREA_CALL_METHODS` entries (`test/unit/structure_test.lua`).
- **`gateVoice` re-gates a releasing voice synth only of the voice's current type** (ruling 15): one of another type (switched while the voice was stopped) is cut (`freeCuttingSynths`, then `cutVoiceSynth`) before the new def starts, so a stopped voice's long release never comes back as the old type. No state is needed: one def a type, so the releasing synth's `defName` is its type.
- **A switch leaves the freeze alone**: a frozen synth voice keeps its ring writer (paused, or the spectral writer on high) and its `\stream` notes, whose grains read the ring and never name the def; only the voice synth changes. Held (hold), the voice synth is not heard at all. Spectral, the writer holds the magnitudes (`PV_MagFreeze`) while the phases go on coming from the voice bus, so the new type's voice synth sets the held spectrum's phases: the spectrum stays the old type's, its level moves about a decibel against the same freeze without a switch (3.13). A buffer or input voice has no voice synth to switch.

## Owns

`lib/engine/StrataVoices.sc` (the voices area): `voiceTypeDefs`, `numVoiceTypes`, `validVoiceType`, `voiceType(voice)` (0-based, into the list), `voiceDefFor(voice)` (the def name), `areaState[\voices][\types]` and the command `setVoiceType` (beside `setGrainSource`). `lib/engine/StrataLifecycle.sc`: `replaceVoiceType`, `switchVoiceType` and `gateVoice`'s cut. `lib/engine/StrataNotes.sc`: `restartVoiceNotes`. `noteMainRanges` (`lib/engine/StrataVoiceDefs.sc`) holds one entry a line, in type order, so a type package appends one line there too.

## The switch

`setVoiceType` records the type (`areaState[\voices][\types][voice] = type`), then, on a running synth-source voice with a live voice synth, calls `replaceVoiceType` through `areaCall`. `switchVoiceType`, inside that bundle:

1. `freeCuttingSynths(voice)`: whatever an earlier cut or switch left in its kill fade goes at once (a source switch frees it the same way, so a cutting grain synth loses the rest of its fade as it does there).
2. The live voice synth leaves `synths` and is cut (`cutVoiceSynth`, kept in `cuttingSynths[voice]` until it frees).
3. `startVoiceSynth(voice)`: the new def from `voiceControls` with the own note's park and expression (`ownNotePairs`), so a parked own note stays parked. The voice keeps every value in `voiceControls`, those of the old type included: a name two types share (FM's and Ring's `ratio`) reaches the new def until Lua sends the new type's values (Lua's sync after a switch, package 0d).
4. `restartVoiceNotes(voice)`: each live extra note of kind `\voice` is cut and started again on the new def at its kept `freq`, its order kept, silent (ruling 45). A releasing note keeps releasing on the old def (it is in the pool until it frees, and a slot still holds one live or releasing and one cutting synth at most); a `\stream` note of a frozen voice is left as it is.

Then each `test/engine_check/types/<key>.scd`, sorted, a function of `h`: a type package's own checks of its def, so it edits no shared check.

## Wave

`lib/engine/StrataTypeWave.sc` (3.8, package 1f; the area `typeWave`, order 21): `\strataWave`, a wavetable voice, and the bank it reads.

- **The bank is 0b's reservation and nothing more**: `waveBankSize` (8) tables of `waveTableFrames` (`wavetableBankFrames div: waveBankSize`, 4096 frames: a wavetable of 2048 samples in VOsc's format), so the whole bank is `wavetableBankFrames` (32768 frames, 128 KB of ordinary RAM, which `fixedBufferBytes` already counts: `docs/notes/engine/performance.md`); a change to the bank's size is a change to that method alone. `allocWaveBank` (the area's `allocState`) allocates it once with `Buffer.allocConsecutive`, so its bufnums are consecutive (`VOsc3` reads a table and the next) and never change, and fills each table on the server in its `b_alloc`'s completion message (`/b_gen sine1`, normalized, wavetable, cleared): no sclang loop over the samples. `freeWaveBank` (its `free`) frees every buffer of it. The state is `areaState[\typeWave][\bank]` (`waveBank`).
- **The eight tables** (`waveBankSpectra`, harmonic amplitudes, darkest first): a sine; two, four and eight harmonics falling as 1/k; sixteen odd ones (a soft square); thirty-two as 1/k (a soft saw); twelve peaked around the sixth (a formant); sixty-four as 1/sqrt(k). A table is not band-limited: the brightest aliases at high pitches, as the prototype did (`docs/design/3.8-facts/engine-voices.md`).
- **The def** takes every shared and note control and plays, on each side of a `Balance2`, one `VOsc3` of three oscillators at the pitch and detuned above it (left) or below it (right) by `detune` and twice `detune`. The position is `noteMainValue(\strataWave, morph, noteMain)` plus `LFNoise1.kr(morphRate) * morphDepth` plus `modSig * 0.2`, clipped to 0-1 and scaled by `waveBankSize - 1.001`, so the table after the one read stays in the bank. No delay line, no table sized from a control, no re-excitation on a trigger, and no subsonic block (a table of sines has no energy at 0 Hz; the check measures it). Its expression range is `noteMainRanges`' `strataWave: [\morph, 0, 1]`.
- **The bank's first bufnum is built into the def**, as `scaleBuffer`'s is into the grain defs (`docs/notes/engine/variation.md`): every engine built on a server re-adds `\strataWave` with its own bank, so after a second engine was built and freed (the structure, files, memory and other areas' `h.startEngine`) the def reads that engine's freed bank, which `VOsc3` plays as silence. On norns one engine runs at a time. A check that plays the wave voice on `h.engine` first rebuilds it (`areaCall(\addWaveDef)` on `h.engine`), as `types/wave.scd` does.

The check, `test/engine_check/types/wave.scd` (loaded by the types area): the bank (eight consecutive bufnums, each of `waveTableFrames`, summing to `wavetableBankFrames`, as the server reports them, each filled, the def reading this engine's), a second engine's free leaving none of its bank's buffers (every `Buffer` freed, the server reporting 0 frames at each bufnum), the level at the defaults and at each own key's range ends at 110 and 2000 Hz (finite, peaks 0.11-0.19 against the floor 0.005 and the ceiling 1, 3.14.1), below 8 Hz under 0.15 of the peak (0.0 measured), morph 0 against morph 1 at 220 Hz with no wander (RMS 0.072 against 0.020, 11.4 dB apart, against 1 dB), and a held three-note chord on a wave voice (three `\strataWave` note synths, each finite and above the floor, and `morph` sent voice-wide reaching all three). Its pool size is the memory area's (`checkVoiceSynthSizes`).
