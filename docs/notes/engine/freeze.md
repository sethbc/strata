## Must not break

- **Freeze acts through a synth voice's ring writer, an input voice's copy ring, its grain synth's ring and the `freeze` control, never by stopping a grain synth.** A freeze and a `freezeMode` act, then return false, so `setGrainParam` also stores the control and sends it: `freeze` is what stops a slot's scan (`scanRate`) and moves a frozen ring's read point (`ringScanOffset`). An unfreeze (`freeze` 0) stores and sends the control itself (`unfreezeWithControl`), so it goes in one bundle with the rest of the unfreeze.
- **An input freeze never touches the voice's own ring or its writer** (#494, #495). Its copy goes into the voice's copy ring (`copyRingFor`, the rings area's), which only the voice's input grain synths are pointed at, and its spectral writer is a node of its own on the copy ring. The voice ring holds only what its writer records from the voice bus, so a synth-source grain synth, whose path carries no voice level, never plays input audio: not one a switch to the input leaves releasing, not a new one after a switch back to the synth, and not one a voice stopped while frozen on the input starts on its synth.
- **An unfreeze's re-point and the grain synth's `freeze` 0 land in one block.** `unfreezeWithControl` sends what `unfreezeVoice` sends (the readers set back to the input ring, a copy writer freed, a synth voice's writer resumed or replaced) and the kept control's `freeze` 0 in one `makeBundle`. `ringGrainReader` holds the freeze flag for the block (#535): a reader set back to the input ring a block before its `freeze` 0 starts that block's grains a further `grainMaxSeconds` back, on neither read point (the rings check shows it with the two split across blocks).
- **Fade before overwriting a copy ring.** The input copy is the one ring write that is not a writer's, and it goes into the voice's copy ring: that ring's readers (`copyRingReaders`) get `ringLevel 0` and the copy waits `bufferFadeWait` when any plays, at once otherwise. They are the voice's input grain synths reading the copy and those set back from it within `freezeLeaveSeconds` (a synth-source grain synth is never one), so a copy waits only for a refreeze soon after an unfreeze. Every step after a wait runs only while `ringChanges[voice]` is unchanged and no later copy started: an unfreeze, refreeze or source switch wins. The faded readers get `ringLevel 1` back once the copy is in, or abandoned, by the latest copy only.
- **One writer per ring.** A synth voice's spectral writer changes by `Synth.replace` of its ring writer (the old node freed in the same server step); `synths[ringWrite<i>]` and `areaState[\rings][\writers]` always name the running one, so the rings area's `stop` frees it. A copy ring has at most one writer, a spectral input freeze's (`synths[copyWrite<i>]`, `copyWriterKeys`), from the copy's landing to the unfreeze; the freeze area's `stop` frees any left. All writers are `effectKeys`: plain messages (`run`, `replace`), and a copy writer is freed quietly (`sendToSynth`: one whose `/s_new` found no room never started). A freeze changes a synth voice's ring writer only with `run` (hold) or `Synth.replace` (spectral), never otherwise.
- **Spectral only on the high tier, and only for a ring.** `\strataRingWriteSpectral` is added only when `tier == \high`; `freezeModeFor` gives `\hold` on standard and for a buffer voice whatever `freezeMode` says.
- **No `LocalBuf`, in this def or any engine SynthDef.** Building a `LocalBuf` into a SynthDef corrupts sclang 3.13's garbage collector (norns runs 3.13), and sclang aborts a little later wherever the collector next runs: in CI the engine check died in the buffers, files or performance area. The spectral writer's FFT buffers are server buffers (`\spectralBuffers`, one pair per voice on the high tier, passed as `fftL`/`fftR`); a voice's pair serves one node at a time, its synth freeze's writer or its input freeze's copy writer, since an unfreeze frees the one before the other can start. `test/unit/structure_test.lua` fails on any `LocalBuf` in the engine source outside comments.
- **History is 0 inside a frozen input copy.** The freeze area wraps the grains area's `history` handler: while the voice is frozen on the input it keeps the value and sends nothing; the unfreeze sets the grain synth back to the input ring at that history.
- **A switch unfreezes.** `replaceGrainSynth` calls `unfreezeVoice` first; it puts the kept `freeze` control at 0, so the new grain synth starts unfrozen (Lua's `source_change` hook then sets `v<i>_freeze` 0 too).
- **What a ring grain synth reads is `grainReadPairs`' answer**: the start, the re-gate and `pointAtCopyRing` all send it, never pairs of their own (`grainControlPairs` ends with it). `returnToInputRing` alone keeps its own pairs: it sets back synths the voice may no longer own (a switch calls it with `grainSource` already changed).
- **`inputReaders` holds only playing synths**: `noteInputReader` adds a grain synth that reads the copy (at its start, its re-gate and `pointAtCopyRing`), and `watchVoiceSynth`'s `onFree` removes it (`forgetInputReader`), as it does `ringReaders`; a note synth's watcher (`watchNoteSynth`) removes it the same way.
- **An input freeze reaches the voice's extra notes** (3.5, `docs/notes/engine/notes.md`): `pointAtCopyRing` points the own grain synth and every live extra input note at the copy (`setGrainSynths`) and counts each among the readers, a note started while the voice is frozen reads the copy from its start (`grainControlPairs`), the copy's fade and `returnToInputRing` reach them through `inputReaders`, and the freeze control reaches them (the plain set and `unfreezeWithControl`, through `setGrainSynths`). A synth voice's freeze changes no note on its own: Lua cuts its extra notes, and its later notes are streams of the frozen ring (`\strataGrainRing`s of the voice ring at `noteRate`); its unfreeze (`unfreezeWithControl`, through the notes area's `notesUnfrozen`, in the same bundle) returns the own grain synth's `noteRate` to 1, moves a parked own note's park back to the voice synth, and cuts the ring-stream notes, restarting each live one as a voice synth.
- **The kept `freeze` control is 1 while frozen and 0 after an unfreeze**: `freezeVoice` sets 1 where it sets `\frozen`, `unfreezeVoice` 0, so a mode change (unfreeze, then freeze) leaves 1 and a grain synth a start or re-gate builds is frozen too.
- **Real-time memory.** A spectral writer takes about 80 KB of the pool (two 2048-frame FFT chains; their FFT buffers are server buffers, outside the pool); a spectral input freeze runs it beside the voice's plain writer (a few KB more than 3.2's replacement did). The `memory` area's high run engages spectral freeze on every voice, and the floor it holds the pool to and what it leaves free are in [memory.md](memory.md).
- **Buffer memory.** The copy rings are ordinary RAM (`b_alloc`), allocated once by the rings area beside the voice rings: 7 × 2 × 4 s at the server rate, 10.8 MB at 48 kHz, on both tiers, counted in the high tier's step-down (`highMemoryBytes`, [performance.md](performance.md)). Their bufnums never change.

## The freeze area

`lib/engine/StrataFreeze.sc`, order 110. `areaState[\freeze]`, per voice:

| Key | What |
|-----|------|
| `\frozen` | Boolean |
| `\mode` | `\hold` or `\spectral` while frozen, else nil |
| `\source` | the source it froze (a source changed while the voice was stopped is unfrozen and frozen again) |
| `\copied` | an input voice's copy is in its copy ring and its grain synth reads it |
| `\copies` | the number of the voice's latest input copy |
| `\faded` | the copy ring readers a pending copy set to `ringLevel 0` |
| `\inputReaders` | (one for all voices) input grain synths reading their voice's copy, or set back from it → `(voice, until)`: `until` nil while they read it, the time they stop counting once set back. `noteInputReader` adds one (a start, a re-gate, `pointAtCopyRing`); it is removed when it frees (`forgetInputReader`, from `onFree`) or, set back, after `until` (`copyRingReaders`) |
| `\stopped` | true once the area's `stop` ran: a copy still waiting does nothing, and no copy writer starts |
| `\spectralBuffers` | (high tier only, else empty) each voice's `[left, right]` FFT buffers of `spectralFrames`, for its spectral writer; the area's `free` frees them |

The spectral copy writers are `synths[copyWrite<i>]` (`copyWriterKeys`, the area's `effectKeys`). The copy rings themselves are the rings area's (`areaState[\rings][\copyL]`, `\copyR`, `\copyPhaseBuses`; `copyRingFor(voice)`, [rings.md](rings.md)).

Methods: `spectralFrames` (2048), `spectralDither` (0.00001), `freezeLeaveSeconds` (`grainMaxSeconds + ringReadMargin`), `scanRate(bufScan, freeze)`, `ringScanOffset(bufScan, freeze)`, `freezeVoice(voice)`, `unfreezeVoice(voice)`, `unfreezeWithControl(voice, value)`, `setFreezeMode(voice, value)`, `freezeModeFor(voice)`, `frozenOnInput(voice)`, `readsInputCopy(voice)`, `grainReadPairs(voice)`, `noteInputReader(voice, synth)`, `forgetInputReader(synth)`, `copyRingReaders(voice)`, `copyInputToCopyRing(voice)`, `holdCopyRing(voice)`, `pointAtCopyRing(voice)`, `copyWriterKeys`, `startCopyWriter(voice)`, `stopCopyWriter(voice)`, `stopCopyWriters`, `ringWriterFor(voice)` (and `pauseRingWriter`, `resumeRingWriter`, `replaceRingWriter`: a synth voice's only).

Both controls come through `setGrainParam`: `freeze` 0 (unfrozen) or 1 (frozen), `freezeMode` 0 (hold) or 1 (spectral).

## What a ring grain synth reads

`grainReadPairs(voice)` is the one answer, as `\strataGrainRing` controls `[\bufL, bufnum, \bufR, bufnum, \phaseBus, index, \history, seconds]`:
- the synth source: the voice's ring at history 0 (history is for the input ring, so a voice that leaves the input never reads a wrapped ring);
- the input source: the input ring at the voice's kept history (`grainControls[voice][\history] ? 0`), or, when `readsInputCopy(voice)` (on the input, frozen on the input, the copy in: `\copied`), the voice's copy ring at history 0;
- a buffer source: nothing (`[]`), so a `\strataGrainBuf` gets no new control.

`grainControlPairs` ends with it (after the kept controls, so it wins over the kept history), so `startGrainSynth` (a `voiceOn`, a switch, the late-gate restart in `onFree`) and `gateVoice`'s re-gate (one `setMsg`, through `sendToSynth`) send it; `pointAtCopyRing` sends it when the copy lands or a freeze is resent. Each of them then calls `noteInputReader`, which counts the synth in `\inputReaders` when it reads the copy, so `returnToInputRing` reaches it on unfreeze. A restart while the copy still waits for its fade reads the input ring at the voice's history; the copy, once in, points it at the copy ring.

## What each source holds

| Source | hold | spectral (high tier) |
|---|---|---|
| synth | the voice's writer is paused (`/n_run 0`); the phase bus keeps its last frame, so the grains read the frozen ring | the writer is replaced by `\strataRingWriteSpectral` reading the voice bus: the ring keeps receiving one held spectrum |
| input | the 4 s of the input ring ending at the voice's read point (the head minus `ringReadMargin + history`) are copied into its copy ring (one `/b_gen copy` per channel, two when the span wraps the input ring's end), oldest first from frame 0; the copy ring's phase bus is set to 0 (the copy's end) and the live grain synth gets the copy ring, its phase bus and history 0 with a `set`. The voice's own ring and writer go on as ever (its ring holds its voice bus: silence, as an input voice's stage writes its mirror later in the block) | the same copy, then a spectral writer of `inputBus` into the copy ring (`copyWrite<i>`), starting from the copy's end; the voice's own writer goes on writing its voice bus |
| buffer | `scanRate` is `bufScan × (1 − freeze)`: the position holds while spread, pitch and the draws still move | not offered: holds |

- **Unfreeze** reverses each step. A paused writer resumes from its own phase (the grains may cross the seam between old and new audio once). A synth voice's spectral writer is replaced by a `\strataRingWrite` of the voice bus, which starts from the phase bus. An input voice's copy writer, if any, is freed and its grain synths are set back to the input ring at the voice's history; the copy stays in the copy ring, read by nothing but those grain synths' grains already playing, until the next copy overwrites it (after fading them). The freeze param's unfreeze sends all of it and the grain synth's `freeze` 0 in one bundle (`unfreezeWithControl`); a switch's unfreeze leaves the old grain synth's `freeze` as it was (it fades out).
- **The frozen read point** (`ringScanOffset`, added to a ring grain's lookback): 0 unfrozen. Frozen, a ring's head no longer moves, so a grain must start at least its own length behind it or it reads across the seam into the ring's oldest audio: `grainMaxSeconds` (0.5 s) more covers any grain (`max(r − 1, 0) × dur` is already in the lookback). Then `bufScan` moves the read point back through the ring, in ring lengths per second (a negative scan moves it forward), from where the freeze began, wrapping (a `Phasor` reset as `freeze` rises): moving back, the grains play about 3.5 s of continuous audio before the read point crosses the seam into the newest audio again, once per 4 s of travel. Frozen grains therefore play from about half a second before the freeze point. Spectral keeps the offset: a spectral writer's ring still moves, and 0.5 s back is real audio (the voice's, or the input copy's).
- **The spectral writer** has `\strataRingWrite`'s controls and phase; each channel goes through `FFT(fftL or fftR, …, 0.5)` (the voice's 2048-frame `\spectralBuffers`, which `replaceRingWriter` or `startCopyWriter` passes) → `PV_MagFreeze` → `IFFT`. It writes the input itself until the analysis has run two windows (the IFFT's latency; `PV_MagFreeze` then holds a real spectrum), then crossfades to the held spectrum over 10 ms, so the ring never gets a gap. Its input and output go through `zeroBadValues`. The analysis input gets a dither of about −100 dBFS (`spectralDither`, white noise): on exact digital silence `PV_MagFreeze` would otherwise hold zero phases and buzz at the hop rate; under real sound it is inaudible.
- **A mode change while frozen** (`freezeMode`) freezes again in the new mode: unfreeze, then freeze.
- **A freeze while frozen** on the same source and mode changes nothing but points the live input grain synth at the copy again (Lua's sync sends `freeze` again after `voiceOn`; the grain synth `voiceOn` started or re-gated already reads the copy, `grainReadPairs`). A voice frozen on another source (it changed while the voice was stopped, so no switch unfroze it) is unfrozen first; until that resend the freeze state stays on the old source, and the grain synth `voiceOn` starts reads the new source and is no reader of the copy. A voice moved to its synth source while stopped reads its own live ring (an input freeze never pauses or replaces its writer), so it starts as any voice switched from the input does, from what its voice bus held, until that resend unfreezes it: the gap 3.3's engine-state plan left closed itself with the copy ring (#494, #495).

## The input copy and the copy ring's readers

`copyInputToCopyRing` runs in a routine (`SystemClock`):
1. it counts the copy (`\copies`) and finds the copy ring's readers (`copyRingReaders`), giving each `ringLevel 0` (added to `\faded`);
2. with readers it waits `bufferFadeWait`;
3. it reads the input writer's frame from its phase bus, sends the copies into the copy ring and waits for them (`server.sync`);
4. then `holdCopyRing`: the copy ring's phase bus to 0, the spectral copy writer for spectral (`startCopyWriter`), `\copied`, and the grain synth pointed at the copy (`pointAtCopyRing`);
5. the latest copy gives the faded readers `ringLevel 1` back.

Steps 3 and 4 run only while the copy is current (`ringChanges` unchanged, no later copy and the area not stopped: a `free` inside the wait, #503, runs none of it).

`copyRingReaders(voice)`: the playing input grain synths in `\inputReaders` for the voice, those reading the copy and those set back from it until `freezeLeaveSeconds` after (their grains already playing still read the copy ring); it prunes freed ones and expired ones. A synth-source grain synth reads its voice's own ring and is never among them, so a switch from the synth to the input followed by a freeze (a scene recall's order) copies at once, and the synth-source grain synth the switch left releasing keeps its level and reads its own ring, which holds no input audio (3.2 faded it and then gave it the copy at full level, #494). A refreeze within `freezeLeaveSeconds` of an unfreeze finds the live synth among the readers: it fades (a short dip), the copy waits `bufferFadeWait`, and its level comes back with the copy.

## The engine check (`test/engine_check/freeze.scd`)

It reads a timecode, as the rings area does (a check synth writes the seconds since it started, left, and 1, right, into voice 1's bus and the input bus, each switchable, and the seconds to a private bus; a grain synth with a rectangular envelope plays left/right = the time its audio was written). It checks:
- the area's state, that `freeze` feeds a UGen in both grain SynthDefs, and `scanRate`;
- with a 440 Hz tone on the input and peak meters on voice 4's synth path (just before its stage) and on the main bus: switched from its synth (its ring silent) to the input and frozen at once, the releasing synth-source grain synth never plays the copy (synth path under 1e-4 over 2.4 s, the main bus never above 1.1 × the frozen voice's own level, #494); a frozen input voice at `amp` 0 switched to its synth keeps its synth path under 1e-4 over the first second at pitch 1 and 2 (position spread 0.5), and so does one stopped while frozen, moved to its synth and started again with no freeze resent (#495);
- a frozen synth voice keeps sounding after its voice bus falls silent (the writer paused, the reads from about 0.5 s before the freeze); at `bufScan` 1 each grain starts further back (every step between grain starts is backward) and the start jumps to the newest audio once per 4 s of travel (the seam); unfreeze resumes the live ring (lookback back to the margin);
- spectral on standard holds (the writer paused, no spectral writer); a switch unfreezes (the writer runs, the new grain synth at `freeze` 0);
- an input voice with no reader of its copy ring is copied at once and its grain synth reads the copy ring at history 0; the freeze leaves the voice's ring and writer alone (the same `\strataRingWrite` of the voice bus, running, its ring still silent while the copy ring holds the timecode); history 2 holds the timecode from 2 s back (and 0.5 s more); history stays 0 inside the copy and is kept; the unfreeze sends the grain synth's re-point and its `freeze` 0 in one bundle (a recording address on the server); the live input grain synth is a reader of the copy ring while frozen and 0.2 s after unfreeze, not 0.7 s after;
- with no freeze resent after `voiceOn`: a frozen input voice's grain synth re-gated inside its release keeps reading the copy at history 0; a new one, started once the old one freed, and one restarted by a late gate (freed on the server behind sclang's back) read the copy (the copy ring and its phase bus, history 0, `freeze` 1) and are in `\inputReaders`; an unfreeze sets the restarted one back to the input ring at history 2;
- with `bufferFadeWait` 1 s (so the readings inside the wait have about 0.9 s to spare, #506): a refreeze inside `freezeLeaveSeconds` of an unfreeze fades the live synth before copying and restores it; a switch from the synth to the input leaves no reader of the copy ring, so a freeze lands at once and the releasing synth-source grain synth keeps `ringLevel` 1; an unfreeze inside a refreeze's wait wins (no copy: the zeroed copy ring stays zero, the reader back at `ringLevel` 1); a grain synth restarted inside the wait reads the input ring at history 2, then the copy at history 0 once it is in; a `voiceOff` inside the wait lets the copy land while the voice is stopped, and a `voiceOn` inside the release re-gates the same grain synth onto the copy (history 0, in `\inputReaders`: `gateVoice`'s `noteInputReader`), which the unfreeze sets back to the input ring at history 2; a frozen input voice switched to its synth is unfrozen (its writer reads its voice bus and runs);
- a frozen input voice whose source changed to a slot while it was stopped starts a `\strataGrainBuf`, no reader of the copy; one whose source changed to the synth starts a synth-source grain synth on its own ring, its writer running; a frozen input voice stopped and started three times (freeze resent after each `voiceOn`) leaves one entry in `\inputReaders`, its live grain synth;
- a buffer voice on a 1 s ramp: the scan stops while frozen (a read span of 0.05 s, the grain's), and spread still moves it;
- on a second engine on the high tier: it adds `\strataRingWriteSpectral` (with `\strataRingWrite`'s controls); 20 spectral freeze toggles leave one writer per voice (`synths` and `\writers` naming the running one, the phase moving); a spectral writer frozen on silence writes nothing audible (ring peak under 0.001); a spectral frozen input voice at `amp` 0 switched to its synth keeps its synth path silent; spectral on an input voice copies, then writes the held input into its copy ring (a `copyWrite` node of `inputBus`) which its grain synth reads, the voice's own writer still a `\strataRingWrite` of its voice bus; a mode change while frozen freezes again in the new mode and keeps the voice's `freeze` control at 1; an unfreeze frees the copy writer; the freeze area's `stop`, run alone (before the voices area's, which frees `voiceGroup` and would hide it), frees a running copy writer, and `free` frees the 14 FFT buffers (#503);
- on a second standard engine with `bufferFadeWait` 1 s: a `free` while a refreeze's copy waits for its fade runs none of it (no server failure, `\copied` false, #503).
