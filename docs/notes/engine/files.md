## Must not break

- **File writes** go to a `<path>.<instanceTag>-<generation>.part` file and are renamed into place. Never open the final path for writing. The newest write to a path wins, and two writes never mix.
- `deleteStaleParts` deletes only `.part` files and `writeSlot`'s temporary float files older than `stalePartAge`, and only in absolute directories below the root (`stalePartDirs`: `scratchDir`, its parent and the settings folder the performance area used).
- A write clips samples beyond ±1 symmetrically to ±`int16Peak`, never wraps.
- The engine check never writes into `~/dust`: it points `scratchDir` at a temporary directory.

## File writes

`writeSlot(index, path)` (scratch takes and `saveBuffer`) has the server write each mono buffer's valid frames to a temporary float file, then sclang interleaves them in 8192-frame chunks (a per-frame loop: an array-level `lace` measured about twice as slow, since the `_ArrayLace` primitive only descends into `Array`s and each chunk would be converted FloatArray -> Array -> FloatArray; yielding `writeChunkWait`, 1 ms, between chunks; a 16 s take interleaves in about 0.06 s on a Mac) into a stereo 16-bit WAV at the content's rate and deletes the temporaries; it creates no synth nodes. The buffers are float and `record_level` goes to 2, so a take can hold samples beyond ±1: the interleave clips every sample to ±`int16Peak` (32767 / 32768), so the file is clipped deliberately and symmetrically (+32767 / -32767) whatever libsndfile's own float-to-int conversion does (without its clipping mode it wraps; with it, it clips to +32767 / -32768). Writes to the same path can overlap (a full 16 s take is still being written when the next, shorter take completes), so each write gets a generation number in `writeGenerations[path]`, interleaves into its own `path.<instanceTag>-<generation>.part` file (`instanceTag` is `UniqueID.next` at `alloc`, so two engine instances in one sclang session, before and after a script reload, never share a `.part` or temporary float file `strata-buf<n>-<tag>-<gen>-<L|R>.wav`), and renames it into place (`mv -f`, atomic on one filesystem; sclang has no `File.rename`) only if it is still the newest write for that path. An older write checks after every chunk, abandons as soon as a newer one starts, and deletes its `.part`. The newest write always wins, two writes never mix, and a reader never sees a half-written file. The newest write removes its `writeGenerations` entry when it ends, whether it succeeded or failed (a directory that cannot be made, `File.mkdir` throwing, is caught and reported as `cannot write`); an abandoned write leaves the newer one's entry. `alloc` calls `deleteStaleParts`, which deletes the `*.part` files a crash left in `scratchDir` (scratch takes) and in its parent (`saveBuffer`'s `<date>-buf<n>.wav.<tag>-<gen>.part` in `_path.audio/strata/`, visible in the file browser), and `writeSlot`'s temporary float files (`strata-buf*-*.wav`) in `Platform.defaultTempDir`; nothing else, and only files last modified more than `stalePartAge` (60 s) ago (`File.mtime` against `Date.getDate.rawSeconds`). `File.mtime` throws for a file deleted since the glob, so it is wrapped in `try`: such a file is skipped silently, while one that is still there (or whose existence cannot be read either: a directory without search permission makes `File.exists` throw too) is left and posted (`strata: cannot read when <path> was last written`); `deleteStaleParts` returns those paths. A temporary float file is written just before its interleave opens it, and deleting an open file does not stop it being read, so the age check also keeps a running write's files: after a script reload in the same sclang session the previous instance's write routine may still be interleaving, and a running write touches its `.part` with every chunk. `stalePartDirs` picks the directories: `scratchDir` (with `~` expanded, trailing slash dropped), its `dirname` and the settings folder the performance area used at alloc (`allocSettingsDirectory`: `settingsDir`, or `~/dust/data/strata/`, where a crash can leave `performance_active.data.<tag>-<gen>.part` or Lua's `performance.data.part`), each listed once, keeping only absolute paths below the root, so an empty, relative (`"."`, `"scratch/"`, whose `dirname` is `"."`) or root `scratchDir` never globs the working directory or `/` (never `standardizePath` it: that turns `"."` into the working directory). `test/run_engine_check.sh` starts sclang in its temp dir, so the check's working-directory marker never lands in the caller's directory. Never open the final path directly for writing: `SoundFile.openWrite` truncates it, and libsndfile rewrites the header on `close`. The engine check sets `writeChunkWait` to 0.02 s so the overlap is certain.

**Scratch directory**: `scratchDir` (engine variable, settable) defaults to `Platform.userHomeDir +/+ "dust/audio/strata/scratch/"`, which equals Lua's `_path.audio .. "strata/scratch/"` on norns; it is created on demand before writing. `test/engine_check.scd` points it at a temporary directory so the check never writes into `~/dust`.

Decoding a file before it loads (`fileDecodes`, `loadShortfallFrames`) is under Damaged files and failed reads in `docs/notes/engine/buffers.md`.
