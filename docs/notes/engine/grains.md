## Must not break

- **One grain path.** Every grain synth is a `GrainBuf` pair built by `grainBody`: `\strataGrainRing` for the synth and input sources (their rings, `docs/notes/engine/rings.md`) and `\strataGrainBuf` for the slots. Pitch is the grain rate. No grain SynthDef has a `PitchShift`, a `DelayC` or any other delay line (the engine check fails on one).
- **Buffer and input sources have no voice synth.** Their grain synth writes the voice's other path (`voicePathBus`), and the voice's stage mirrors that path to `granBuses[i]` (filtered and after the level; `docs/notes/engine/mix.md`), so crossmod keeps working, and takes the voice's `pan` (`panBalance`). The synth-source grain synth writes the synth path and keeps `pan` 0 and `rateLevel` 0 (the voice synth already pans, accents, crossmods and bends), with its mod buses on `silentBus`; that path never mirrors: a mirror would count the voice synth twice. Buffer and input grain synths take the voice's bend and frequency crossmod as well as its pan.
- No buffer grain reads past the slot's valid region, and the buffer's rate scale is applied once.
- New voice-level controls that a buffer or input grain synth also needs belong in `voiceControls` / `grainControls` and `controlNameSets`.
- Both grain SynthDefs declare every grain control with a literal `arg` list (the Lua stub reads it), and the 3.2 controls default to 3.1's sound.

## Grain params

**Granular parameters**: grainSize, grainDensity, pitchShift, posSpread, envShape, grainMode, bufPos, bufRate, bufScan (the last three only matter to `\strataGrainBuf`, i.e. buffer sources; Lua `v<i>_buf_pos` 0-1 lin step 0, `v<i>_buf_rate` 0.25-4 exp, `v<i>_buf_scan` -2..2 lin, in `voices[i].grain.buf_pos|buf_rate|buf_scan`), and history (input voices; `lib/history.lua`)
- `envShape` (Lua option `v<i>_grain_env`, `GRAIN_ENV_OPTIONS = {"hann", "sine", "perc", "linen", "trap"}`, default hann; `voices[i].grain.env` holds the option index 1-5) is sent as index − 1. The engine's `envBufnumFor(index)` turns it into the grain synth's `envBuf`: 0 = `-1` (GrainBuf's built-in Hann), 1-4 = `envBuffers[index - 1].bufnum`; any other index is ignored. `envBuffers` are four 1024-frame `Buffer.loadCollection`s of `Env.sine`, `Env.perc(0.1, 0.9)`, `Env.linen(0.1, 0.8, 0.1)` and the trapezoid `Env([0, 1, 1, 0], [0.25, 0.5, 0.25])`
- `grainMode` (Lua option `v<i>_grain_mode`, `GRAIN_MODE_OPTIONS = {"continuous", "triggered"}`, default continuous; `voices[i].grain.mode` holds the option index 1-2) is sent as index − 1. `grainBody` picks the trigger with `Select.ar(mode, [Impulse.ar(grainDensity), T2A.ar(t_trig)])` (`mode = grainMode.round.clip(0, 1)`, written on the control's own name: the Lua stub reads the enumeration from it): continuous fires `grainDensity` grains per second, triggered fires one grain per `retrigger`. In triggered mode `grainDensity` does nothing, and neither does `posSpread` for synth and input sources (a ring grain's spread is 0 there); `\strataGrainBuf` still jitters each triggered grain's position by it. MAIN shows `[TRIG]` for a voice in triggered mode
- `DISCRETE_GRAIN_KEYS` (`{ env = #GRAIN_ENV_OPTIONS, mode = #GRAIN_MODE_OPTIONS }`) maps the grain keys that hold an option index to their option count: `scene_transition_targets` skips them (they switch when the fade ends), mutation and randomize never touch them, and `validate_scene` requires integers from 1 to the count
- `pitchShift` (Lua `grain_pitch`, 0.25-4) is the grain rate: an exact transposition of up to two octaves either way, with no smearing (3.2 replaced 3.1's `PitchShift` stage). `GrainBuf` latches its rate per grain, so a pitch change (drift, an LFO, a scene fade) reaches new grains only: pitch steps grain by grain. A buffer voice's grains play at `pitchShift × bufRate`, so its pitch also changes how fast a grain reads the slot
- `history` (Lua `v<i>_history`, 0 to `S.performance.history_seconds`): seconds back from the input ring's head. The grains area's `history` handler keeps it for every voice and sends it only to an input voice's grain synth; `\strataGrainRing` clips it to `historySeconds`

## Audio Sources (buffers and live input)

Every voice's grain stage has a source (`grainSource[voice]`): 0 = its own synth (the voice synth writes `granBuses[i]`, the voice's ring writer records it, `\strataGrainRing` reads that ring), 1-8 = buffer slot (`\strataGrainBuf`), 9 = live input (the input ring, `\strataGrainRing`). The grains area's `grainDefs` table says which def `grainDefFor` builds: sources 1-`numBuffers` `\strataGrainBuf`, everything else `\strataGrainRing`. The engine side:

- **`\strataGrainBuf`** (`slotGrainReader`): the slot pair, at `rate × bufRate × (bufRateScale / BufRateScale.kr(bufnumL))`, where `rate` is `grainBody`'s (pitch × bend × crossmod). The output is multiplied by `(bufFrames > 0).lag(0.05)`: an empty slot or one being recorded (`bufFrames` 0 until the take completes) is silent instead of every grain reading position 0 and looping the take's first grain. `bufPos` (0-1) and the scan are fractions of the valid region (`bufFrames`), so a 2 s sample uses the whole range; `bufScan` moves the position in **valid-region lengths per second** (spec §1; bipolar, wraps; its rate is `scanRate(bufScan, freeze)`, the freeze area's hook); grain position jitter ± `posSpread * 0.5`. **Grain end**: no grain reads past the valid region into the zeroed rest of the buffer (which made the level dip every time a scan wrapped). GrainBuf reads `|rate| × BufRateScale.kr(bufnumL)` frames per output sample (it applies the buffer's own rate scale to the rate it is given), so a grain covers `grainDur × SampleRate × readRate` frames; `grainDur` is the grain duration capped at the valid region less `grainEndMargin` (4 frames, for the interpolation and rounding) at that rate, and `slotGrainPos` (the loop area's hook, `docs/notes/engine/loops.md`) wraps the scanned position (jitter included) inside the voice's loop and clips it to the starts that keep the grain inside the region (forward: at most `bufFrames - grainEndMargin - grainFrames`). While the slot reads empty (`bufFrames` 0: cleared, reloading or recording, faded out by the level) the last valid length is held (`Gate.kr(bufFrames, bufFrames > 0)`), so the grains fading out keep their size and place instead of shrinking to a few samples at position 0, which clicked. When a grain covers the whole valid region, every grain starts at its beginning, so `bufPos`, `bufScan` and the position spread stop doing anything. So `bufPos` 1 is the last start that still ends inside the region, and a region shorter than a grain gets grains as long as the region. The engine check fills the frames past a silent region with 1 and hears nothing (at the server rate, at 22050 Hz and rate 2, and with a region shorter than a grain). `bufRateScale` = content rate / server rate, tracked by the engine (`b_alloc`/`b_zero` keep a loaded file's rate on the server buffer and norns' scsynth predates `b_setSampleRate`, so `BufRateScale.kr` would be wrong after recording into a slot that held a file). `GrainBuf` itself already multiplies the rate by the buffer's own rate scale (the server's `BufRateScale`), so dividing it out applies the engine's scale exactly once: without the division a 44.1 kHz file played 1.5 semitones flat on a 48 kHz server (the engine check measured a 1 kHz sine at 920 Hz), and dropping `bufRateScale` instead would play a take recorded over a 44.1 kHz file flat. The engine check measures both with `Pitch` (1 kHz from a 44.1 kHz file, 440 Hz from a take recorded over it)
- **`\strataGrainRing`** (`ringGrainReader`): the voice's ring (synth source) or the input ring (input source), starting each grain a lookback behind the write head, at the rate clipped to ±`ringMaxRate`; see `docs/notes/engine/rings.md`
- **Live input**: the persistent `\strataInput` synth (`SoundIn.ar([0, 1])` → stereo `inputBus`) at the head of `voiceGroup`; the input ring's writer records `inputBus`. Input-sourced voices run `\strataGrainRing` on the input ring
- **Mirror to the voice bus**: with no voice synth, a buffer- or input-sourced voice's `granBuses[i]` would be silent and its `\strataMod` (and every voice it modulates) would go dead. So each voice's stage writes its other path, filtered and after the voice-level gain, to `mirrorOut` (= `granBuses[i]`; `docs/notes/engine/mix.md`). The synth source must not mirror: its mod synth already follows the voice synth on that bus, so a mirror would count it twice (the stage mirrors only the other path). (There is no feedback any more: the voice's ring writer runs in `voiceGroup`, before the stage writes the bus.) The mix group sits just before the voice's `\strataMod`, so the mirror reaches it in the same block
- **Voice-level controls follow the source**: `voiceControls[voice]` keeps every `setVoiceParam` and crossmod value (reset by `voiceOn` to its freq/amp/pan and silent routing) and `grainControls[voice]` every `setGrainParam` (`voiceOn` merges its size/density/pitch into it with `putAll` and keeps the rest, so a grain synth `voiceOn` builds starts in the voice's grain mode, envelope and buffer position instead of firing continuous grains until Lua's `grainMode` arrives; `envShape` stored as `envBuf`). When the source is not the synth, `setVoiceControl` also sends the controls the grain SynthDef has: `amp` (the voice's level), `pan`, `bend` and the crossmod routing and amounts (amplitude and frequency) for both buffer and input voices. Input voices follow pitchbend and frequency crossmod since 3.2, because pitch is now a rate. **Pan**: both grain SynthDefs apply `pan` through `panBalance(sig, pan)`, a balance (`sig * [1 - pan.clip(0, 1), 1 + pan.clip(-1, 0)]`): pan -1 leaves only the left channel, 1 only the right, and a centered voice is unchanged (a `Balance2` would take 3 dB off both channels at the center). `controlPairs` filters against a per-SynthDef `IdentitySet` of control names (`controlNameSets`, built in `alloc` for the voice and grain SynthDefs)

The buffer slots themselves are in `docs/notes/engine/buffers.md`; replacing a running voice's grain synth is in `docs/notes/engine/lifecycle.md`.

## The grain SynthDefs

`lib/engine/StrataGrainDefs.sc` writes both as literal `SynthDef(\name, { arg ...; ... })` blocks with the same grain controls, whose bodies collect their controls into an Event and call `this.grainBody(controls, reader)`. They differ only in the reader: `ringGrainReader(bufL, bufR, phaseBus, posSpread, history)` or `slotGrainReader(bufnumL, bufnumR, bufFrames, ...)`, a function of (trigger, rate, duration, mode) returning the buffers, rate, duration, start and an output level.

`grainBody`, for every source:
1. **Trigger**: `Impulse.ar(grainDensity)` or `T2A.ar(t_trig)`, by `grainMode`.
2. **Rate and duration**: `grainRate(trig, pitchShift, bendRate, vary)` and `grainDur(trig, grainSize, sizeJitter)` (the variation area's hooks; neutral: `pitchShift × bendRate` and `grainSize`), the duration capped at `grainMaxSeconds` (0.5 s). `bendRate = 1 + rateLevel × (bend × (1 + rateMod) − 1)`, `rateMod` the frequency crossmod clamped -0.9..2: `rateLevel` 0 (the synth source) makes it 1.
3. **Two stereo `GrainBuf`s**, one per channel buffer, the left's grains panned to -1 and the right's to +1 (plus `grainPan`'s offset, neutral 0, clipped at ±1), so the pair stays sample-aligned and keeps the image of 3.1's two mono `GrainBuf`s. Each uses `maxGrains` and the envelope `envBuf`.
4. **Pan**: the slow wander `Balance2` by `LFNoise1.kr(2).range(panSpread.neg, panSpread)`, then `panBalance` for the voice's `pan`. `grainSignal` returns this, `sig`, and the fade below.
5. **Fade** (`fade`): the ASR (`openedGate`, `grainRelease` 2 s), the kill fade, the reader's level (`hasAudio` for a slot) and `ringLevel.lag(0.05)` (a fade the rings area uses before overwriting a ring). The voice-level gain (`amp`, the amplitude crossmod, the accent), the voice filter, the sends and the mirror are the voice's stage (`docs/notes/engine/mix.md`).
6. **Output**: `grainBody`'s one `Out.ar(out, sig × fade)`: `out` is the voice's synth or other path (`voicePathBus`, set by `startGrainSynth`).

The 3.2 controls past 3.1's, with the defaults that keep 3.1's sound: `history` 0, `ringLevel` 1, `rateLevel` 1, `freeze` 0, `freezeMode` 0, `reverseProb` 0, `pitchJitter` 0, `panJitter` 0, `sizeJitter` 0, `interval1`..`interval8` 0, `intervalCount` 0, `intervalProb` 1, `quantize` 0, `scaleNote` 60, `loopStart` 0, `loopLength` 1. `startGrainSynth` sets `rateLevel` for every source. `\strataGrainRing` adds `bufL`, `bufR`, `phaseBus` and `bufScan` (for `ringScanOffset`); `\strataGrainBuf` keeps `bufnumL`, `bufnumR`, `bufFrames`, `bufRateScale`, `bufPos`, `bufRate` and `bufScan`.

### The hooks

Each is a method in its own area file, registered as an area with no state, defs or commands of its own, which Wave 2 fills without editing this file:

| Hook | File (area, order) | Neutral |
|------|--------------------|---------|
| `grainRate(trig, pitchShift, bendRate, vary)` → signed rate; `vary` an Event of `reverseProb`, `pitchJitter`, `intervals` (Array of 8), `intervalCount`, `intervalProb`, `quantize`, `scaleNote` | `StrataVariation.sc` (variation, 90) | `pitchShift × bendRate` |
| `grainPan(trig, panJitter)` → offset | `StrataVariation.sc` | 0 |
| `grainDur(trig, grainSize, sizeJitter)` → seconds | `StrataVariation.sc` | `grainSize` |
| `slotGrainPos(trig, bufPos, scanPhase, spreadDraw, rate, durFrames, validFrames, loopStart, loopLength)` → start, 0-1 of the valid region | `StrataLoop.sc` (loop, 100) | the scanned position wrapped, scaled to the frames a grain can start in and still end inside the region |
| `scanRate(bufScan, freeze)` → rate | `StrataFreeze.sc` (freeze, 110) | `bufScan` |
| `ringScanOffset(bufScan, freeze)` → seconds further back a ring grain starts | `StrataFreeze.sc` | 0 (an unfrozen ring ignores `bufScan`) |
| `freezeVoice(voice)`, `unfreezeVoice(voice)` | `StrataFreeze.sc` | nothing (`replaceGrainSynth` calls `unfreezeVoice` first) |
| `voiceFilter(sig, filterType, filterFreq, filterRes, filterMix)` → sig (the stage) | `StrataMix.sc` (mix, 120) | `sig` |
| `voiceOutput(sig, out, delaySend, reverbSend)` (the stage) | `StrataMix.sc` | `Out.ar(out, sig)` |

The mix area fills `voiceFilter` and `voiceOutput` (`docs/notes/engine/mix.md`): both now run in the voice's stage, not in each grain synth.
