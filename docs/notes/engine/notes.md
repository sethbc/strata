## Must not break

- **Four commands, exactly**, with these signatures: `noteOn(voice, slot, note, freq, rate, velocity)` `"iiffff"`, `noteOff(voice, slot, cut)` `"iii"`, `noteExpression(voice, slot, bend, amp, position, size, main)` `"iifffff"`, `setNotePool(size)` `"i"` (design 3.5 §3.1). Slots are 0-indexed in the engine: 0 is the voice's own note, 1-7 its extra notes; Lua's are 1-8 and it passes `slot - 1`.
- **Each command checks before it acts**: its indices first (voice 0-6, slot 0..`noteSlots` - 1, `noteOff`'s `cut` 0 or 1, `setNotePool`'s size 0..`notePoolMax`), then that every continuous argument is finite, through the modulation area's `fastModIndicesValid` and `fastModValuesFinite`, as 3.4's five commands do. A bad one is ignored with one console line (`strata: noteOn ignored: voice 7 is not a whole number from 0 to 6`, posted by `postFastModIgnored`): nothing recorded, no state changed. Only then are the continuous arguments clipped (note 0-127, freq 8-20000, rate 0.25-4, velocity 0-1, bend 0.0625-16, amp 0-2, position, size and main -1..1), never ignored for being out of range.
- **The literals** `noteSlots { ^8 }` and `notePoolMax { ^16 }` equal Lua's `NOTE_SLOTS` and `NOTE_POOL.max` (a docs test compares them), and the Lua engine stub reads them as written (`name { ^N }`) for its index checks: keep them literal methods. `noteLag { ^0.02 }` is every per-note control's lag.
- **Extra notes live only in `areaState[\notes]`'s slots**, never in `synths`, `releasingSynths`, `fadingSynths` or `cuttingSynths`: `voiceRunning`, `gateVoice`, the switch's fading and cutting sets and every other own-synth rule are the voice's own synths' alone.
- **The engine holds the bounds whatever Lua sends**: a slot never holds two live synths (a `noteOn` on a releasing slot cuts its tail first); live and releasing extra notes never exceed the pool (before a new synth starts, the oldest releasing note anywhere is cut; with none releasing the note is refused with one line); cutting note synths never exceed one per slot (a slot's earlier cutting synth is freed at once) nor the pool in all (the oldest is freed at once).
- **A note synth is watched as a note's** (`watchNoteSynth`): when it frees, its slot empties (or its cutting entry clears) and nothing restarts it, never `watchVoiceSynth`'s restart rule. Its start counts once the server confirms it (`watchStart`, `unconfirmedStarts`); one unconfirmed past `startConfirmWait` is forgotten at its slot's next command and before any start counts the pool (`forgetFailedNoteStarts`, `makeNoteRoom`), so a failed start frees its slot and its room. A note synth the engine frees itself leaves every list it was in at once (`endNoteSynth`).
- **Voice-wide sends reach a voice's notes through `setVoiceSynths` and `setGrainSynths`**: the own synth through `setSynth`, every live extra note of that kind through `sendToSynth`, without the per-note names (`perNoteVoiceControls`, `perNoteGrainControls`: a voice synth note's `freq`; a buffer note's `bufRate` and `scaleNote`; an input note's `pitchShift`; the note controls, `velocity` and `t_accent`). So the param that is a voice's own pitch moves its own note only. Every voice-wide site uses them: `setVoiceControl`, `setGrainParam`'s plain sets (the `freeze` control's included), the `envShape`, `history` and `t_scanReset` handlers, `retrigger`'s `t_trig`, `unfreezeWithControl`'s `freeze` 0 and `pointAtCopyRing` (the copy ring's read pairs, each note then counted among the copy ring's readers); `bufferChanged`'s live set, which takes a slot's new length and rate, is the own grain synth and the voice's live grain notes (`noteSynths(voice, \grain)`); `sendScaleNote` gives a buffer note its own `scaleNote` (`noteScaleNote`) and an input or ring-stream note the voice's.
- **The own note's state lives on the synth that sounds it** (`ownNoteKey`: the own voice synth on a synth voice, the own grain synth on a buffer or input voice and on a frozen synth voice, whose grain synth plays the frozen ring): slot 0's expression goes there, and every own synth the engine starts or re-gates takes it (`ownNotePairs`), every other own synth the neutral values (the synth-source grain synth, which grains the chord, keeps every note control at its default while the voice is unfrozen). `voiceOn` starts every voice unparked at the neutral expression (`resetOwnNote`).
- **The park follows the own voice synth through a freeze** (ruling 44, `ownNoteGateKeys`): on a synth voice the own voice synth's `noteGate` always follows slot 0's park, frozen or not (inaudible while frozen, so parking it costs nothing); while frozen a slot-0 command also reaches the own grain synth; the freeze itself parks nothing (its ring holds the chord), and the unfreeze returns the grain synth's `noteGate` to 1 and finds the voice synth where the park says. So an unfreeze under a parked own note makes no sound of it.
- **A slot-0 `noteOn` fires no accent and no trigger on an unfrozen voice** (ruling 47, replacing ruling 15's accent): it only sets `noteGate` 1 where the park is. Lua always follows it with `retrigger`, which accents the voice, plucks Karplus and opens the stage's step gate, once. On a frozen synth voice it also sets the own grain synth's `noteRate` and fires that synth's `t_accent` at `velocity` (the only accent that stream has; velocity 0 gives none). Lua sends a slot-0 `noteOn` only to a running voice and never an extra note to a stopped one: one that arrives is ignored with one line.
- **Restarts are silent** (ruling 45): the held extra notes the engine restarts itself (a source switch's `restartNotes`, an unfreeze's `notesUnfrozen`) start with no `t_accent` and no `t_trig`, their `velocity` kept for later.
- The area's state lives in `areaState[\notes]`; `StrataNotes.sc`, like every extension file, adds methods only, never a variable.

## The notes area (`StrataNotes.sc`, order 170)

The last area in `alloc`'s order and the first in `free`'s. It has `allocState`, `addCommands` and `stop`: its `stop` frees every note synth (quietly, `sendToSynth`) and puts every slot back as `alloc` left it, before the voices area's `stop` frees the voices' groups. It has no SynthDef, bus or buffer: a note's synth is a voice or grain SynthDef of its voice.

`areaState[\notes]`:
- `pool`: how many extra notes the pool holds, across every voice; 0 until Lua sends `setNotePool` (Lua sends its tier's default, `NOTE_POOL.standard` 4 or `NOTE_POOL.high` 8, or the player's setting from `notes.data`, at its start).
- `slots`: per voice an Array of `noteSlots` records (`emptyNoteRecord`). Slot 0, the own note: its kept `expression` (an Event of `bend`, `amp`, `position`, `size`, `main`), `parked`, and `rate` (a frozen synth voice's own grain synth's `noteRate`, 1 otherwise). Each extra slot: `state` (`\empty`, `\live` or `\releasing`), `synth` (live or releasing), `cutting` (its synth in the kill fade), `kind` (what its synth is: `\voice`, `\buffer`, `\input`, `\stream`), its last `noteOn`'s `note`, `freq`, `rate` and `velocity`, its kept `expression`, and `order` and `cutOrder` (when it started and when its cutting synth was cut).
- `order`: a counter; every start and every cut takes the next number, so the oldest note (or cutting synth) has the lowest.
- `received`: what each command last took (an IdentityDictionary, the command's name to its arguments, the continuous ones clipped), for the engine check, as the modulation area's `received`.

### The commands

The rows of AGENTS.md's table. Each records what it took (`received`), then acts:

| Command | Indices checked | Clipped | Slot 0 (the own note) | Slots 1-7 (extra notes) |
|---|---|---|---|---|
| `noteOn(voice, slot, note, freq, rate, velocity)` `"iiffff"` | voice 0-6, slot 0-7 | note 0-127, freq 8-20000, rate 0.25-4, velocity 0-1 | unparks the own note (`noteGate` 1 where the park is); no accent, but on a frozen synth voice the own grain synth's `noteRate` and `t_accent` at `velocity`; takes no other pitch | starts the slot's note, or re-pitches and accents a live one (The lifecycle, below) |
| `noteOff(voice, slot, cut)` `"iii"` | voice 0-6, slot 0-7, cut 0-1 | | parks the own note (`noteGate` 0; `cut` ignored) | `cut` 0 releases a live note, 1 cuts a live or releasing one in 50 ms; an empty slot does nothing |
| `noteExpression(voice, slot, bend, amp, position, size, main)` `"iifffff"` | voice 0-6, slot 0-7 | bend 0.0625-16, amp 0-2, position, size and main -1..1 | kept, and set on the synth that sounds the own note | kept for the slot (a later `noteOn` starts with it) and set on its synth, live or releasing. Creates no node |
| `setNotePool(size)` `"i"` | size 0-16 (`notePoolMax`) | | | keeps the size; past a smaller pool, cuts the oldest releasing notes, then the oldest live, and frees the oldest cutting synths |

**`note` is kept and not used yet** (ruling 46): each `noteOn` stores its `note` (0-127, the scale reference) in the slot's record and nothing reads it. A buffer note's `scaleNote` comes from the voice's reference note and the note's rate (`noteScaleNote`), which gives the same today; a later release's tunings will need a note's number apart from its rate, so the argument and the stored value stay.

The Lua engine stub refuses the same indices and, from the clips in the source (`note = msg[3].clip(0, 127)`, ...), the clipped ranges, so Lua sends neither (`docs/notes/test-harness/engine-stub-and-sync.md`).

### The lifecycle (design 3.5 §3.4)

**An extra note's synth** (`startNoteSynth`) is built by its voice's state (`noteKindFor`), from the voice's controls with the note's own last, so they win: its pitch (`notePitchPairs`), its accent at its velocity (`noteAccentPairs`), `noteGate` 1 (the park open) and its kept expression (`noteExpressionPairs`):
- **A synth voice's** (`\voice`): a voice synth of the voice's def at the head of `voiceGroup`, writing the voice's bus (`granBuses`), from `voiceControls` (as `startVoiceSynth`) with its own `freq`, `velocity`, `t_trig` 1 (its accent; a Karplus note's pluck) and `noteBend`, `noteAmp` and `noteMain`. The voice's one ring writer records the chord and its one grain synth grains it: the grain synth, ring writer and mod synth stay one each.
- **A buffer voice's** (`\buffer`): a `\strataGrainBuf` for the voice's slot at the head of its mix group (`startGrainSynth(voice, voiceMixGroup(voice), \addToHead, notePairs, watch)`, from `grainControlPairs`), playing the note's `rate` as its `bufRate`, with a `scaleNote` of its own (`noteScaleNote`: Lua's reference note plus the rate's semitones, as `scaleNoteFor` gives the own note's), its `velocity`, `t_accent` 1 and `noteBend`, `noteAmp`, `notePos` and `noteSize`. Its scan starts at the voice's position, as any grain start does; the playheads show the own note's.
- **An input voice's** (`\input`): a `\strataGrainRing` of the input ring, the same way, playing the note's `rate` as its `pitchShift` (an absolute rate) under the voice's one `scaleNote`.
- **A frozen synth voice's** (`\stream`, `frozenSynthVoice`: on its synth source with its ring held): a stream of the frozen sound, a `\strataGrainRing` reading the voice's ring through `grainReadPairs` (as its own grain synth does, the freeze on) at the head of `processGroup`, writing the synth path with `rateLevel` and `pan` 0 and its mod buses on the silent bus (`startGrainSynth`'s synth source), at `noteRate` the note's `rate` (the rate against the voice's freeze reference, Lua's); the voice's `pitchShift` and `scaleNote` stay voice-wide. A hold's and a spectral freeze's notes are the same: both read the voice ring.

Placement is never relative to another note's synth (a group never ends). `startGrainSynth` keeps a note's grain synth in `grainSlots` or `ringReaders` (and `inputReaders` while it reads a frozen input voice's copy) as it does the own one's, and `watchNoteSynth`'s `onFree` takes it out (`forgetGrainReader`).

**`noteOn` on an extra slot** (`extraNoteOn`; a stopped voice's is ignored with one line):
- **Live:** the pitch is set on its synth and its accent fired, in one message. No node.
- **Releasing:** the tail is cut (`cutNote`: it becomes the slot's cutting synth, an earlier cutting synth of the slot freed at once) and a new synth starts.
- **Empty:** a new synth starts.
- Before a new synth starts (`startNote`, `makeNoteRoom`), if live and releasing extra notes already number the pool, the oldest releasing one anywhere is cut; if none is releasing the note is refused with one line (`strata: noteOn ignored: the pool of 4 is full of live notes`): Lua never sends that, since its own count of held notes stays within the pool.

**`noteOff`**: `cut` 0 sends `gate 0` (`releaseNote`: the synth frees itself after its release; the slot is releasing until then, and its tail counts against the pool); `cut` 1 cuts it (`cutNote`: `kill` 1, the 50 ms kill fade). Both through `sendToSynth`.

**Cutting** (`cutNote`, `trimCuttingNotes`): a cut synth stays the slot's `cutting` until it frees; a later cut on the slot frees it at once, and when cutting note synths would pass the pool the oldest is freed at once, so they never exceed one per slot nor the pool in all (with a pool of 0, a cut frees at once).

**The own note (slot 0)**: its synths are the voice's own (`synths`). `ownNoteKey` names the one that sounds the own note: the own voice synth on a synth voice, the own grain synth on a buffer or input voice and on a frozen synth voice, whose grain synth plays the frozen ring (`ownNoteOnGrain`). On a frozen synth voice a slot-0 `noteOn` also sets the own grain synth's `noteRate` to its `rate`, parked or not (kept in slot 0's `rate`), and fires its `t_accent` at `velocity`. A slot-0 `noteOff` parks the own note (`noteGate` 0: the voice def's or grain def's second envelope, `notePark`, falls over the def's release; nothing frees), a slot-0 `noteOn` unparks it (`noteGate` 1, over the attack), each on the synths the park is on (`ownNoteGateKeys`: a synth voice's own voice synth, frozen or not, and the own grain synth where it sounds the own note), and a slot-0 `noteExpression` sets the sounding synth's note controls. Every own synth the engine starts (`startVoiceSynth`, `startGrainSynth` with no note pairs) or `gateVoice` re-gates takes `ownNotePairs`: slot 0's expression when it sounds the own note, the neutral values when not; the park on a voice synth always and on a grain synth when it sounds the own note.

**The voice's own commands**:
- **`voiceOff`** releases every live extra note with the voice (`releaseVoice` calls `releaseNotes`). Their tails stay in their slots and the pool until they free.
- **`voiceOn`** resets slot 0 (`resetOwnNote`: unparked, the neutral expression) and re-gates the voice's own synths as before, with `ownNotePairs`; it leaves the extra tails to end.
- **`setGrainSource`** on a running voice: the own note crossfades as before, and in the same bundle (`replaceGrainSynth`'s `makeBundle`) every extra note is cut and each that was live restarts on the new source from its kept values (`restartNotes`: a buffer note's rate, an input note's, a voice synth note's `freq`), keeping its order; a releasing one is not restarted. So a slot holds a live and a cutting synth at most.
- **A buffer load or clear** fades every grain synth reading the slot, extra notes included (they are in `grainSlots`); `bufferChanged`'s live set, which takes the slot's new length and rate, is the own grain synth and every live extra grain note.
- **A synth voice's freeze** changes no note on its own: Lua cuts the extra notes (`noteOff` with `cut` 1), and the own note's state stays on the voice synth; while frozen a slot-0 park or unpark reaches the voice synth and the grain synth both (ruling 44). **Its unfreeze**, in the bundle that re-points the ring and sends `freeze` 0 (`unfreezeWithControl` calls `notesUnfrozen`): the own grain synth back to the neutral note controls (`noteRate` 1, its park open), slot 0's expression on the voice synth again with the park already there (`ownNotePairs`), every ring-stream note cut, and each that was live restarted as a voice synth at its kept `freq`, keeping its order, silent (a releasing one is not restarted). A source switch unfreezes without this (`unfreezeVoice`), and its `restartNotes` restarts the ring-stream notes on the new source.
- **An input freeze** points every live ring grain synth of the voice at the copy ring (`pointAtCopyRing` through `setGrainSynths`, each counted in `inputReaders`); a note started while frozen reads it from its start; the unfreeze's `returnToInputRing` sets them all back, and its `freeze` 0 reaches them in its bundle.
- **`stop`** (the area's) frees every note synth with the voices.

### Watching

A note synth is watched with a watcher of its own (`watchNoteSynth`), never `watchVoiceSynth`'s restart rule. `watchStart` (the lifecycle's, shared with `watchVoiceSynth`) registers it and keeps it in `unconfirmedStarts` until its `/n_go`. When it frees, its slot's entry clears (the slot empties, or its cutting entry clears) and it leaves `grainSlots`, `ringReaders` and `inputReaders`; nothing restarts it. A start the server never confirms (its `/s_new` failed: no room in the real-time pool) is forgotten as `forgetFailedStarts` does (#497), at the slot's next `noteOn` or `noteOff` past `startConfirmWait` (`forgetFailedNoteStarts`, `endFailedStart`): the slot is then empty, so a `noteOn` starts it and a `noteOff` does nothing, and neither sends the server anything it fails on. Lua and the engine heal at the next note. A failed start never holds room in the pool: `makeNoteRoom` forgets every note start unconfirmed past `startConfirmWait` before it counts, whatever slot it is in. A note synth the engine frees itself (a slot's earlier cutting synth, the pool's cap on cutting synths, the area's `stop`) goes through `endNoteSynth`: freed quietly and forgotten at once wherever it was registered (the NodeWatcher, `unconfirmedStarts`, its `onFree`), as its `/n_end` would have it, since one that never started sends none.

### Memory

The note pool is sized from what a note costs. A synth voice's extra note is a voice synth, a buffer or input voice's a grain synth; the memory area measures all seven voice SynthDefs and `\strataMod` (`memory: \strataResonator takes <n> KB`, ...), each under its own limit. Karplus is the costliest note (80.9 KB with 1a's note controls, against `\strataGrainBuf`'s 73.3 KB), so the pool's worst case is seven Karplus notes, then buffer notes: 7 × 2 × 80.9 + 9 × 2 × 73.3, about 2452 KB with every slot live and cutting. The memory area measures a full pool itself, on both tiers (its pool cases: the all-buffer worst case with every pool slot live and cutting, and synth -> buffer -> synth with sixteen voice synth notes, Karplus's seven first), each against 1280 KB. The figures, the sum and the cases are in `docs/notes/engine/memory.md` (the voice SynthDefs; the floors section).

### The check (`test/engine_check/notes.scd`)

In lifecycle's CI shard (`.github/workflows/test.yml`). Its checks:
- the area runs at order 170; its literals (8, 16, 0.02) and its state as `alloc` leaves it: no pool, every extra slot empty, every own note unparked;
- the four commands exist with their signatures;
- with the pool empty no command creates a node (the server's synth and group counts are the same after each of seven valid calls of the four, sent to a running voice), and the extra note the empty pool has no room for is refused with one line;
- each command records its arguments, the continuous ones clipped (the limits themselves, and values past each limit);
- out-of-range indices (negative, too large, fractional) and non-finite values (NaN, both infinities) of every command are ignored, one line each naming the command, with nothing recorded, the pool unchanged and no node made;
- the check counts those lines through the modulation area's `postIgnored` hook, and gives the hook back however its body ends (`withIgnoredLines`, a `protect`): a deliberate error inside it must leave the hook as it was, so the areas after this one see their lines;
- `setNotePool` keeps the size it is sent, and an ignored one leaves it;
- what reached the server: the checks that a command's messages go in one bundle read them as they reach the server's NetAddr (`h.wireUnits`, a forwarding stand-in for the address while the command runs: one entry per bundle or message the real address sent), so a split bundle fails them; and where a run ends, the note synths the server runs (one `/g_queryTree`, by def and node ID, without the voices' own) must be exactly those the slots hold, none held twice (`h.noteNodesAgree`);
- buffer and input notes: a `noteOn` on an empty slot of a buffer voice starts one `\strataGrainBuf` at the head of its mix group with its own `bufRate` and `scaleNote`; one on a live slot re-pitches and accents it (the `t_accent` 1 found in the command's bundle) with no node; `noteOff` releases a note, which frees after the grain release, and one with `cut` 1 frees it within 0.1 s; a hundred `noteOn` and `noteOff` pairs 5 ms apart on one slot never leave it more than one live and one cutting synth, in the engine or on the server; an input voice's note is a `\strataGrainRing` with its own `pitchShift`, in `ringReaders`;
- the fan-out: a voice-wide grain param (`grainSize`, a buffer voice's `pitchShift`, `envShape`, the voice-level `pan`, an input voice's `history`, `t_scanReset`) and `retrigger`'s `t_trig` reach every note of the voice; `bufRate` and an input voice's `pitchShift` only the own note's; a new `scaleNote` moves each buffer note's by its own rate;
- expression: kept for an empty slot, a later `noteOn` starting with it; set on a live note at once; `main` reaches a voice synth note's `noteMain`, `position` and `size` a grain note's `notePos` and `noteSize`;
- a failed start (the note's `/s_new` held back from the command's bundle): past `startConfirmWait` the slot's next `noteOn` starts it and a `noteOff` forgets it, and `noteOff` on an empty slot sends nothing the server fails on;
- synth-voice notes: one voice synth at the head of `voiceGroup`, on the voice's bus, with its own `freq` and started with `t_trig` 1; under a chord of eight the voice's grain synth, ring writer and mod synth stay one each; `setVoiceParam` reaches every note's synth (a synthesis param, `releaseTime`, `amp`) and `freq` only the own note's;
- the park, on a synth voice (Pulse, its times set short), a buffer voice and an input voice (fed a test tone): `noteOff` on slot 0 sets `noteGate` 0 on the sounding synth, whose level (a peak meter on the voice's bus) falls under 1% while every synth stays; `noteOn` on slot 0 brings it back;
- the voice's commands: `voiceOff` releases every note and `voiceOn` after it re-gates only the own synths (no node; the own note unparked and neutral), and after the longest release every slot is empty;
- failed starts: after a start that failed (its `/s_new` held back), sixteen notes on other slots all start with a pool of 16, the server's note synths the slots'; five never-started notes cut on a pool of 2 leave the NodeWatcher and `unconfirmedStarts` as the cap frees them, but for the two still a slot's cutting synth;
- the rulings of the fix round: an unfreeze under a parked own note makes no sound of it, parked before the freeze or during it (a Pulse voice's bus, by level; ruling 44); restarted notes (three switches and an unfreeze under a chord) start with no `t_accent` or `t_trig`, their velocity kept, read from the `/s_new`s that reached the server (ruling 45); with a slot-0 `noteOn` and the `retrigger` after it Karplus's own voice synth gets one `t_trig`, and a buffer voice's own grain synth no `t_accent` from the slot-0 `noteOn` (ruling 47);
- frozen synth voices (a hold on Sub): a note is a `\strataGrainRing` of the voice's ring at the head of `processGroup` at `noteRate`, its synth path, `rateLevel` and `pan` 0, the freeze on; a slot-0 `noteOn` sets the own grain synth's `noteRate` and fires its accent (in the command's bundle); a slot-0 `noteOff` parks the own grain synth and the voice synth (ruling 44); the unfreeze's one bundle (as it reached the server: the ring writer resumed, `freeze` 0, the own synths' note controls, the cuts and the restarts) cuts the ring-stream notes, restarts the live ones as voice synths at their `freq` (the releasing one not), returns `noteRate` to 1 and the grain synth's park to open, the voice synth's staying parked; on a high engine of its own, spectral freeze plays a ring-stream note too (the voice's synth path carries it with the own note parked);
- sources, buffers and the input freeze: a source switch under a chord (synth to buffer, buffer to input, input to synth) cuts every extra note and restarts the live ones on the new source, the kill of each old synth, the `/s_new` of each new one and of the voice's new own grain synth in one bundle as it reached the server, the releasing one not restarted, the live count the same; a buffer load sends every note reading the slot `bufFrames` 0 in its first step and, once the file is in, the live notes its new length and rate (the releasing one keeps 0); an input freeze points the own grain synth and every note at the copy ring at history 0, a note started while frozen too, and the unfreeze sets them all back with `freeze` 0;
- the pool: full of live and releasing notes, a new note cuts the oldest releasing one; full of live notes, a new note is refused with one line; a seeded random run of 2000 commands over seven voices (notes, releases, cuts, stops and starts, new pool sizes) never has live and releasing notes, nor cutting ones, past the pool, and ends with the server's note synths the slots'; `setNotePool` below what is held cuts the oldest releasing note, then the oldest live; with a pool of 2, cutting note synths never pass 2, and the server holds exactly two in their kill fade beside one live note after each round;

The area sets the pool back to 0 and stops the voices it started; the runner's `stopAllVoices` cuts every note synth too, and after each area it checks `"<area>: leaves no note in a slot"`.
