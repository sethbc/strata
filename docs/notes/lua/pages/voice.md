## Must not break

- The page file sets every record field but the arc fields; VOICE's rings are `lib/arc/voice.lua`'s (`docs/notes/lua/arc-pages.md`).
- The VOICE cursor is `S.cursors.voice`, a row index into `voice_page_rows(S.selected_voice)`; it and its anchor are `lib/ui/cursors.lua`'s (`docs/notes/lua/ui/field-list-and-cursors.md`). Every VOICE handler and the draw read it through `S.lib.pages_voice.sync_cursor()` (which is `S.lib.ui_cursors.sync("voice")`), never directly: it puts the cursor on the anchored param's row when the current rows have it and clamps from the anchored index only when they don't (ruling W7). It is idempotent (it never moves the anchor, so any number of calls from the page, the rings or between `clamp_all` runs give the same cursor) and returns `rows, cursor`. The rings (`lib/arc/voice.lua`) call `S.lib.ui_cursors.sync("voice")` themselves, never the page module.
- The anchor (the param key, the id without `v<i>_`, and its row index) changes only on deliberate moves: E2 (`S.lib.ui_cursors.move("voice", d)`, which anchors where it lands), K2/K3 and `S.lib.pages_voice.place_cursor(index)` (which is `S.lib.ui_cursors.place("voice", index)`). A source or voice change and back (A -> B -> A) therefore returns the cursor to its param, however many redraws and `clamp_all` runs happened in between. Code that puts the cursor on a row from outside VOICE's handlers uses `place_cursor` (or the module's `place`); a bare `S.cursors.voice = index` is taken back to the anchored param by the next sync.
- E3 edits through `enc_param_delta(3, id, d)` (never `params:delta`), so ALT+E3 is fine adjustment and the center detents apply. VOICE has no `alt_enc`: ALT+E2 moves the cursor in whole rows.
- The voice text (`<n><+|-> <name> [L]`) is cut in the name, never the lock tag (#421): the name gets the room left after the section text, the prefix and the tag. Layout state `locked voice, filter & sends` pins it; the states use `NUM_VOICES`, `S.constants.GRAIN_MODE_OPTIONS` by name, never bare voice numbers or option indices (#430).
- ALT+K2 and ALT+K3 are the record's `alt_key`, reached only through `alt_action`; the plain K2/K3 never reset or lock. ALT+K2 acts on release only, through the shared handler (`S.lib.ui_alt.k2_down` at the press, `k2_up(record)` in `alt_key_release`; `docs/notes/lua/ui/alt-and-keys.md`): a quick press randomizes the cursor's section or undoes it, a press held `ALT_HOLD_SECONDS` resets the row (`alt_hold`), on a locked voice too.
- `randomize_section` draws only the cursor's section, never a kept row: amp, the source, grain mode, the mod sources, freeze and freeze mode, and every registered row its record's `randomize` leaves out (the interval set, the custom intervals, quantize, the filter's mix). A registered row is drawn only through its record's `randomize[key](voice_idx)`, so nothing in VOICE lists another module's ranges. A locked voice's spec still comes, with `"locked"` (its undo runs, nothing is randomized), and a section with no draws (a Sub voice's mix) is a spec with none, so the hint says `K2:rand` and the press does nothing. A buffer voice's synth section has its own undo key (`"synth (buffer)"`), so `K2:undo` is never offered over rows the undo would not change.
- `randomize_section` stays cheap: the hint calls it on every draw while ALT is held, and VOICE animates while ALT+K2 is held (`animates` is `S.lib.ui_alt.k2_held`). It syncs the cursor once and builds one closure per drawn row; no param is set or read beyond the rows.
- The arc button (`arc_button`) starts and stops the selected voice (`toggle_voice`, design §7), not K3's next-section jump, and never locks.
- The ring-group marks are drawn only while `S.arc_connected`, beside exactly the rows `voice_page_group(rows, cursor)` returns (those in view).
- Values come from the param itself (`params:string`, trailing spaces dropped), except mod sources (`<n> <list_name>` or `none`), and are cut with `fit_text` to the room after their label (at least `LAYOUT.value_gap` px), so no row overlaps for any voice, source or value. The layout tests draw every voice with every source and the cursor on the first and last row of each section (the record's `layout_states`), plus an arc-marked and a locked state.

## Owns

- `lib/pages/voice.lua` (`S.lib.pages_voice`): the VOICE record (`draw`, `hints`, `enc`, `key`, `alt_key`, `alt_key_release`, `randomize_section`, `alt_hold`, `animates`, `arc_button`, `layout_states`); `VOICE_DRAWS` (the built-in rows' draws, by key); `M.LAYOUT` (positions), `M.sync_cursor()` and `M.place_cursor(index)` (the page's names for `S.lib.ui_cursors.sync("voice")` and `.place("voice", index)`), `M.row_of(param_id)`.
- Its unit tests: `test/unit/pages_voice_test.lua`. The rows and ring groups it shows are `lib/ui/voice_rows.lua`'s (`voice_page_rows`, `voice_page_group`), tested in `test/unit/ui_cursors_test.lua`; the cursor is `lib/ui/cursors.lua`'s.

## The page

Layout (`M.LAYOUT`):
- y 16: the selected voice at x 0, level 10, as MAIN's list shows it (`<n><+|-> <list_name>`, ` [L]` when locked), cut with `fit_text` to end `line_gap` (6) px before the section text; the cursor's section and its position among the voice's sections (`grain 2/6`: a synth voice has six sections today, the four built-in ones and the registered `variation` and `filter & sends`; a buffer voice seven, with `bookmarks`; an input voice six, `input` in place of `synth`) right-aligned at x 124, level 4.
- Rows through `S.lib.ui_field_list.draw`: 5 visible (`visible`) from y 24 (`first_y`), 7 px apart (`spacing`), so y 24-52; the view keeps one row above the cursor and the scroll marker is field_list's at x 127.
- Section label rows at x 0, level 2. Field rows: the label at x 3 (`field_x`), the value right-aligned at x 124 (`value_right`); the cursor row at level 15, the others at 4.
- While an arc is connected, each row of the cursor's ring group gets a 1×5 px filled rect at x 0 (`mark_x`), y - 4 .. y, level 8.

Keys and encoders:
- E2: `S.lib.ui_cursors.move("voice", d)` (from the synced cursor through field_list's move: section labels take no stop, so E2 at a section's end goes on into the next; clamped at the ends; anchored where it lands).
- E3: `enc_param_delta(3, row.param_id, d)` (option and number rows step whole values).
- K2: the first field of the previous section; in the first section, its own first field. K3: the first field of the next section; in the last section, nothing.
- ALT+K2, on release (#557): a quick press (under `ALT_HOLD_SECONDS`, 0.5 s) runs `S.lib.mutation.undo()` while `undo_for(VOICE, <the cursor's section>, S.selected_voice)`, else `S.lib.mutation.randomize(spec)` with `voice_randomize_section()`'s spec (nothing for a locked voice). A press held 0.5 s runs `alt_hold`, `voice_reset_row`: `params:set(id, param_default(id))` for the row under the cursor at the release (`set_binary_param` for a binary row, so a MIDI-mapped controller follows, #519) (on the source row this switches the source, and the rows follow). ALT+K3: `toggle_lock(S.selected_voice)`, at the press.
- The spec: `{page = VOICE, section = rows[cursor].section, voice = S.selected_voice, draws}`, one draw per drawn row of the section, in row order. A buffer voice's synth section (its buffer params and loop) is `"synth (buffer)"` in the spec (its rows' label stays `synth`), so its undo is not a synth voice's: after a switch between synth and buffer, in either direction, the hint offers `K2:rand` there and a quick press randomizes the rows shown, never undoing rows the section no longer shows. The grain section's undo still survives a source switch (its rows are the same for every source). A row's draw is, in turn: its registered record's `randomize[key](voice_idx)`; `VOICE_DRAWS[key](param_id)`; a synthesis param of the synth section (a key of `S.voices[i].params`) `controlspec:map(math.random())`, its whole range, as MAIN's randomize; else none (kept). `VOICE_DRAWS`: `buf_pos` 0-1, `buf_rate` `2 ^ (2r - 1)` (0.5-2), `buf_scan` -0.5 to 0.5 (MAIN's buffer ranges); `grain_size` 0.05-0.35, `grain_density` 2-40, `grain_pitch` 0.5-2.5, `grain_spread` 0-0.6, `grain_env` a uniform option; `mod_speed` 0.2-10 Hz even in octaves (`0.2 * 50 ^ r`), each `mod_amp_amt_<n>` and `mod_freq_amt_<n>` -0.5 to 0.5; `pan` -0.8 to 0.8. Uniform unless said. The registered sections' ranges are their notes': loops (`docs/notes/lua/loops.md`), history, variation, voice mix and bookmarks (`docs/notes/lua/positions.md`).
- Hints: `K2:prev K3:next`; ALT: `S.lib.ui_alt.k2_hint(record)` (`K2:rand`, `K2:undo`, `K2:locked`; `K2:reset` once ALT+K2 is held 0.5 s), then `K3:lock`, or `K3:unlock` when the voice is locked. With K1 let go while ALT+K2 is down, `k2_hint(record)` alone, since the release still acts. The layout states `ALT held, voice locked` (the widest, `K2:locked K3:unlock`) and `ALT+K2 held past the hold time` draw them.
- `arc_button`: `toggle_voice(S.selected_voice)`.

Cursor anchoring (ruling W7) is `lib/ui/cursors.lua`'s (`S.lib.ui_cursors.sync`/`place`/`move`, described in `docs/notes/lua/ui/field-list-and-cursors.md`); the page only calls it. With it, grain pitch stays grain pitch when the synth section goes or comes back and on the newly selected voice, pan comes back after a switch to input and back or to Sub and back, and a param the new rows lack (`rq` on an input voice, `index` on voice 1) clamps from the anchored index. `redraw()` runs `clamp_all()` before the page draws, which may move the index; the anchor, not the clamped index, decides. The screen draws before the arc in each frame (`draw_frame`), and the rings sync the cursor themselves, so they follow the same cursor even while the norns menu replaces the screen's redraw. `M.row_of(param_id)` gives a param's row index in the selected voice's rows (the layout states use it).
