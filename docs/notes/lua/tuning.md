## Must not break

- **One tuning, this module's.** Every MIDI key, snap, degree and chord goes through it: a key through `pitch_of_key` (`S.lib.variation.midi_note`), a quantized freq and a MIDI note on a quantized voice through `snap` (`S.lib.variation.snap_note`, the freq filter's `tone_freq`, which also walks with `step`), a step's degrees through `step` and `equal_step` (`S.lib.sequencer.degree_semitones`), the chord set through `chord` (`S.lib.variation.interval_set`). Nothing else holds a scale walk of its own.
- **Twelve equal steps give 3.7's pitches exactly**: `pitch_of_key(k) == k` for every key and root, `snap` and `step` whole notes, the chord 0, 4, 7, 11 (whole numbers come back as integers, `tidy`, so a value prints as 3.7's did). The tests that pinned 3.7 pass unedited.
- **Only this module sends `setTuning` and `setTuningTone`**, and only through `send`: from `apply_text`, `tuning_tones`' action (which `select` also calls for a text the param holds already whose tuning the engine lacks, #842), and from the `read` PSET hook after a silent read (#965): the count and period, then every tone, direct, up to 129 messages). A default start sends neither (3.8 ruling 42: the engine starts in `TUNING.default`; a docs test compares the engine's start, `TUNING` and what the param's default sends, #460's rule).
- **The mask applies only to twelve tones of an octave** (`scale_active()`: twelve tones and a period within `octave_tolerance` of 1200 cents), as the engine's `tuningAllowed`; `allowed()` is every tone otherwise, never empty.
- **The tuning is saved with the PSET, never in a scene**: `tuning_name` (shown) and `tuning_tones` (hidden) are text params in the `scale` record, after `root` and `scale_mask` and before every voice, so a PSET applies the tuning before any voice's `freq` line, which the filter then snaps by the right tuning (#125). Both have a text default for a PSET read (`S.lib.params_setup.set_text_default`), so a PSET without them (3.7's) comes back in twelve equal steps and its quantized voices are snapped again (`S.lib.variation.tuning_changed`). A silent read sets them silently, and the module's `read` PSET hook then takes `tuning_tones`' text whenever the read left the module's tuning apart from it (#842: `apply_text(text, true)`), so `tuning_name` always names the tuning in force, and sends it (#965, the engine follows a silent read: `send`; then `S.lib.variation.snap_quantized_freqs()`, the stored freqs snapped as the text's action snaps them ahead of the voices' lines; then each `v<i>_freq` the read left goes back, silently, for `voice_params`' replay to set through its filter, as the line follows the tuning in a read with actions; then `request_redraw()`; the chords are resent once, by `engine_params`, `docs/notes/lua/params.md`). The module keeps the text the engine has (`engine_text`): a read that is not silent (whose unchanged text runs no action) sends the tuning in force when the engine lacks it, which no event now leaves so; `select` applies directly a text the param holds already that the tuning never took (a silent `params:set` of `tuning_tones`) or whose tuning the engine lacks. Because that default arrives after the voices' lines, the module's `read` PSET hook (`S.register_pset_hook`, name `tuning`) then sets every voice's `freq` the file names again from the file's own value (`S.lib.params_setup.pset_value`), honoring the read's `silent`, but only when the default changed the tuning (`S.lib.params_setup.read_defaulted("tuning_tones")`): so a PSET without the lines loads its voices' exact saved pitches over a session in any tuning (#125), and a PSET with them, or one read over twelve equal steps, sets no freq twice.
- **A bad `tuning_tones` text** prints one line (`tuning: <reason>`) and the param is set back, silently, to the tuning in force; nothing is sent.
- **A tuning is checked as the engine will hear it** (#884): the engine gets each tone and the period as an OSC float (float32) and keeps its old tuning for a set that does not ascend below the period there, so the ascent and the period's bound compare `float32` values (`float32`: `string.pack` on Lua 5.3, LuaJIT's `ffi` without it; the suites run on both). Each test names what passes (`not (a > b)`, never `a <= b`), as the engine's ascent does (its tone and period tests refuse `isNaN` and `abs == inf` by name), so a tone or a period that is not a number (a Scala ratio of two 309-digit integers is inf / inf) or infinite is refused too. Lua never sends, nor records as the engine's, a set the engine would refuse.
- **A player's file is read as text, never run**: at most `max_file_bytes`, `io.open(path, "rb")`; no `load`, `dofile` or `tonumber` alone on a token (it reads `0x10`, `1e3` and `inf`). A refused file prints one line (`tuning: <file>: <reason>`) and leaves the tuning.
- **`TUNING` mirrors the engine's tuning constants** (`tuningMaxTones`, `tuningMinPeriod`, `tuningMaxPeriod`, `octaveCents`, `tuningTwelve`, `tuningOctaveTolerance`, `tuningRootKey`, `tuningTableFrames`, `tuningTableLow`, `tuningTableResolution`, `docs/notes/engine/tuning.md`; a docs test compares them).

## Machines

### tuning
- **State:** three texts: `tuning_tones`' (the param's), `current.text` (the tuning in force, a local of `lib/tuning.lua`, read through `count()`, `period()` and `tones()`) and `engine_text` (the text whose tuning the engine has, `send`'s); `engine_has_tuning()` says whether the last two agree (always, since #965, but inside a read).
- **Invariant:** `tuning`: the param's text equals `current.text`, through a refused text too (the action sets the param back, silently). `engine_text` lags only inside a silent read, until the hook sends (#965).
- **Test:** `test/unit/tuning_test.lua`: "tuning: every cell is decided" and its rows (on ji normal; each check counts the `setTuning` and `setTuningTone` sends and the tones in force), and "the tuning invariant holds through a refused text and names a param text the tuning never took".

Every cell is a row. Inside a read the param's text can stand apart from `current.text` until the module's `read` PSET hook takes it, which is why the hook runs at every read. Until #965 a silent read left the engine on the old tuning, a second state, `engine lags`; since, the hook sends what it takes, so no event leaves `engine_text` apart from `current.text` and `engine has it` is the one state (`engine_has_tuning()` is true after every event).

| State | Event | Next | Effect |
|---|---|---|---|
| `engine has it` | `a text that reads` | `engine has it` | `apply_text`: taken and sent (`setTuning`, then every `setTuningTone`), quantized voices snapped |
| `engine has it` | `a refused text` | `engine has it` | one line, `tuning: <reason>`; the param is set back silently; nothing sent |
| `engine has it` | `a silent read of another text` | `engine has it` | the hook takes the file's text (`apply_text(text, true)`) and sends it, the stored freqs snapped and the read's put back; the chords resent once by `engine_params` (#965) |
| `engine has it` | `a silent read of the same text` | `engine has it` | nothing: the text is the one in force, and the engine has it |
| `engine has it` | `a read of another text` | `engine has it` | the text's action takes it and sends it |
| `engine has it` | `a read of the same text` | `engine has it` | nothing: no action runs for an unchanged text, and the engine has it |
| `engine has it` | `choosing the tuning in force` | `engine has it` | `select`: the same name and text; nothing sent |
| `engine has it` | `choosing another tuning` | `engine has it` | `select`: its name, then its text through the action, sent |

## lib/tuning.lua (`S.lib.tuning`)

The one tuning (3.8, design §6): a name, its tones in cents above the first (ascending, the first 0) and its period in cents. Included after `lib/loops.lua` and before `lib/variation.lua`; nothing is read at include time but `S.constants`.

**State and readers.** The tuning in force is what `tuning_tones`' text last applied: `count()`, `period()`, `tones()` (a copy) and `name()` (the `tuning_name` param); `engine_has_tuning()`, whether the engine has it (false only inside a silent read, until the `read` hook sends the text it took, #842, #965; Machines). `scale_active()`; `allowed()` (cents above degree 0, ascending: the tones whose degree's bit of `S.lib.variation.scale_mask()` is set while the scale applies).

**Keys and pitches.** Degree 0 is key `root_key + root` (60 + the root), at that key's equal-tempered pitch; key k is degree `(k - that key)` modulo the tone count, a period up or down for each wrap, so the root transposes the tuning.
- `pitch_of_key(key)`: that pitch, a fractional note.
- `snap(pitch)`: the allowed tone nearest the pitch, a tie going down (candidates in the pitch's period and one either side).
- `step(pitch, k)`: the k-th allowed tone strictly above `pitch + tone_tolerance` (0.01 semitone; k > 0) or strictly below `pitch - tone_tolerance` (k < 0); the pitch for 0. Index arithmetic over the allowed tones and whole periods, no loop bound.
- `equal_step()`: the step in semitones when every tone of the tuning is allowed and they divide the period equally (every gap, the wrap's included, within `octave_tolerance`), else nil: 1 in twelve equal steps with the scale off, 12/19 in 19 equal; nil under a scale, even an evenly spaced one (Whole Tone), so a degree from an off-scale voice walks the scale's tones as 3.7's did (from C# degree 1 is D#, one semitone; from 60.3, 1.7).
- `mean_step()`: the period over the allowed tones' count, in semitones (the freq filter's turn scale, `docs/notes/lua/variation.md`).
- `chord()` (ruling 40): with a scale on (`S.lib.variation.scale_on()`) and the scale applying, its degrees 1, 3, 5 and 7 over two periods of the allowed tones, measured from the lowest allowed tone so the first is always 0 (a custom scale without its root, C#, F and G#, gives 0, 7, 16) (0, 4, 9, 14 for Major Pentatonic; In Sen Pou's now ascend, 0, 2, 8, 13, where musicutil's unsorted list gave 0, 5, 8, 13); otherwise the tuning's tones nearest 0, 4, 7 and 11 semitones above degree 0, each once (0, 4, 7, 11 in twelve equal steps; 0, 6, 11 and 17 steps in 19 equal).

**The text.** `text_of(period, tones)`: the period then each tone, each at `cents_places` (4) places with its trailing zeros dropped (`1200 0 100 ...`); a 128-tone text is about 1.26 KB. `parse_text(text)` gives `period, tones` or `nil, reason`: tokens split on spaces, each a plain decimal (`^%-?%d+%.?%d*$`), 1-128 tones, a period of 100-4800 cents, the first tone 0, each above the last, all below the period, the ascent and that bound compared as float32 (`float32(x)`, the value an OSC float carries: so 100.0000001 and 100.0000002 are one tone, and 1199.99999 is a period of 1200; the period's range and the first tone are tested as given, so a period a hair past 100 or 4800 cents, which the engine would take, stays refused). `apply_text(text, silent)` is `tuning_tones`' action: a text that reads becomes the tuning (the text kept as given), is sent (`send`, which records the text the engine has), then `S.lib.variation.tuning_changed()` snaps every quantized voice and resends every chord, then `request_redraw()` (text params get no redraw from `redraw_on_param_changes`). With `silent` (the read hook's, on a silent read) the text is only taken; the hook then sends it, snaps the stored freqs and puts back the read's, and asks for a redraw (#965). `select(entry)` sets `tuning_name`, then `tuning_tones` (whose action applies it; norns' text param runs its action only on a change, so a text the param holds already that the tuning never took, a silent `params:set` of `tuning_tones`, or whose tuning the engine lacks, is applied directly, #842).

**Built-ins** (`built_ins()`, in the editor's order), all of a 1200-cent period, held as ratios or generators and formatted through `text_of`, so a session and its reloaded PSET apply the same text: `12 equal`; `ji normal`, `ptolemy`, `overtone`, `undertone` and `lamonte` (norns' `intonation` tables, copied: the stub has none and none is required); `pythagorean` and `meantone 1/4` (a chain of fifths of 3/2 and of 5^(1/4), Eb to G#); `19 equal`, `24 equal`, `31 equal`; `partch 43` (`JI.partch()`'s 43 ratios).

**Scala files.** `files()`: the `.scl` files of `_path.data .. "strata/tunings/"`, sorted, through `S.lib.files.files_of` (none for a missing folder). `parse_scl(text)` gives `period, tones` or `nil, reason`: at most `max_file_bytes` (65536); a UTF-8 BOM is dropped and a CR ending a line is whitespace to the tokens read (`%s`), so a Windows copy reads as its Unix file (a test, which a tokenizer keeping the CR fails); a line starting `!` is a comment; the first other line is the description (any text, even empty); the next line's first token the count (a whole number 1-128); then that many pitch lines (blank ones skipped), each read up to its first space: cents when it holds a point (with a digit), else a ratio `a/b` or a whole number `a`, both terms positive; 1/1 is implied and the last pitch is the period. Refused: a count out of range, fewer pitch lines, a pitch that is neither, a period outside 100-4800 cents, tones that do not ascend (a repeated 1/1 included), a tone at or above the period (both as float32, as `parse_text`). `load_file(name)` reads one file of the folder and gives an entry (`name` is `file_tuning_name(file)`: the file's name without its extension, matched without case, its control characters dropped so a PSET line stays one line, cut to `name_max`, 24; the editor names a file's choice by the same rule, so it steps on from an applied file) or `nil, reason`, printing `tuning: <file>: <reason>`.

**Params** (`add_params()`, from `S.lib.variation.add_scale_params()` after `root` and `scale_mask`): `tuning_name` (text, shown, `12 equal`; its action only asks for a redraw, so editing it in PARAMETERS only renames) and `tuning_tones` (text, hidden, `TUNING.default_text`; its action is `apply_text`), each with its `set_text_default`.

**Start** (`START_ORDER.tuning`, 55): makes the tunings folder (`util.make_dir`); sends nothing. No registry, no cleanup step, no global function. The invariant `tuning` (3.9, #915; Machines).

The editor that chooses a tuning is `docs/notes/lua/ui/scale-editor.md`; the engine's table, `docs/notes/engine/tuning.md`; MIDI out's tuned bend, `docs/notes/lua/io/midi_out.md`.
