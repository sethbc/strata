## Must not break

- **A set changes the sound only** (design §9, ruling 52): a `set.params` line naming a rig param (`FACTORY.rig`), a param that is no Strata record param (norns' own: `clock_tempo`, `output_level`, ...), no param, or a param saved nowhere or a trigger (`delay_freeze`, `delay_clear`, `save_scenes`) is refused with one console line naming it. The rig is the module's own list: every param of its nine menu groups and every id its patterns match; no other module is edited for it, and a test walks the groups' params (each group param carries `n`) so a new param of a rig group that no pattern matches fails it, and checks that no other Strata param is rig but `tempo` and `seq_follow_transport`.
- **Every sound param is set, in menu order**, through its own `set` (never `params:set` silently, never `params:read`): its line, or its load default (`S.lib.params_setup.load_default`, the PSET read hook's own) when the set has none, so a set never inherits the session's sound. Menu order puts `scale`, `root`, `scale_mask`, the tuning's two text params and each voice's `quantize` (`add_first`) ahead of every `freq`, so a quantized pitch lands where the set's scale and tuning put it, whatever the file's order. A file param has no default: a slot the set does not name keeps its audio. Every voice's pending type choice is canceled first, as a PSET read cancels them (ruling 63).
- **A set's files are read, never set aside or written**: they sit in the script's folder. Its five side files are read through their modules' PSET hooks inside `S.lib.side_files.read_only(fn)` (an unusable one skipped with its line, never renamed; `docs/notes/lua/data-files.md`); `index.data` and `set.samples.data` through `S.lib.data_files.read`, `set.params` through `read_text`. The tests copy `test/fixtures/factory/` into a script folder of their own first (ruling 53), so a failing read can never touch a tracked file.
- **The copy never takes a `.part` for a sample**: each file goes to `<name>.part` in `copy_chunk_bytes` chunks, every write, the flush and the close checked, then `os.rename`d; a failure removes the `.part`, prints one line and stops the load. A file already installed with the set's file's size is left alone (one of another size, cut short by a power cut, since the copy writes no fsync, is copied again through its `.part`; never copied again otherwise; a new version installs to its own folder beside the old, which is never deleted, since the player's PSETs, scenes and `buffers.data` may name files in it). The copy opens through `io.open` looked up at each call, so `watch_writes` can refuse a write.
- **The live scenes are kept before anything is set** (`S.lib.scenes.back_up_live()`, the rule a PSET load follows): when they cannot be kept the load stops with one line and a flash, and no param, scene, side file or record of the player's has changed: the only additions are the installed audio and its records in `samples.data` (they are stored before the backup, the fact file's order, a ruling of the fix round). Once the backup has moved `scenes.data` aside, it is on disk again when the load's step ends, holding the scenes in memory, on every path: the set's scenes taken, its `set.scenes.data` missing or unusable (the scenes' read-only load writes them back), or a later step raising (the load writes them back before it raises again), so a restart never finds no scenes file and takes the player for a new one.
- **A load is marked only when it ends whole**: `factory.data`'s `loaded[key] = version` (and `pending` cleared) is written after the side files; a load that stops (a refused write, a backup that cannot be made, cleanup mid-copy) marks nothing, and the next load finishes the copy.
- **One load at a time, in one clock** (`S.factory_clock`): a second `load` while one runs is refused (`false, "loading"`); the cleanup step cancels the clock (an invariant: the clock is a live coroutine while it is set).
- **`factory.data` is written only once an index was read** (ruling 51): a start with no index (every 3.8 start, every test start: the stub's script folder is empty) reads nothing more and writes nothing. A first run writes `pending` before the copy starts; a start that finds `pending` (a set the index lists) runs that load again whatever this start found; a player whose scenes file was found at this start (`S.scene_file.start_outcome`, `"loaded"`, `"unreadable"` or `"older"`), or whose marker was found (an unusable one counts), gets no load. So a first run happens once, never to a player who has scenes, and one cut short runs again at the next start. A pending or first-run load that `load` refuses (its set's files unreadable: one line) clears `pending` (`{loaded = <as it was>}` written), so it is not tried, and its line not printed, again at every start (#847).
- **SETUP's list is a modal owner** (`S.lib.ui_modal`), open exactly while its own owner is the modal top (or beneath SEQ's step editor; the invariant `factory`); K3 goes through `load`, and while `S.scene_file.unsaved` the first K3 only arms for `SCENE_LOAD.confirm_seconds`, as `load scenes` asks.
- A key matches `FACTORY.key_pattern` (`^[%w_%-]+$`): `util.make_dir` runs `mkdir -p` unquoted on norns, so a key is a safety rule. A slot line names a bare file of the set's `audio/` (no `/`, no `..`).
- A version is compared only with `FACTORY_DATA_VERSION`, `FACTORY_FORMAT_FLOOR`, `FACTORY_INDEX_DATA_VERSION` or `FACTORY_SET_DATA_VERSION`.

## Machines

### factory load
- **State:** `S.factory_clock` (the load's clock while it runs; `S.lib.factory.loading()` says whether one does), the marker `factory.data`'s `pending` and `loaded` (across starts), and SETUP's list, the local `list` (`open`, `cursor`, `sets`, `armed_until`) with its modal owner; `armed()` (the prompt has not lapsed) is read by the hints, the K3 and `animates`.
- **Invariant:** `factory`: the load's clock, while set, is a live coroutine; the list is open exactly while its owner is the modal top (or beneath SEQ's step editor); an open list's cursor is on one of its sets.
- **Test:** `test/unit/factory_test.lua`: "a second load while one runs is refused".

No table (3.9, #948): a load is one clock (idle, then loading until its steps end, a step refuses or cleanup cancels it; a second `load` meanwhile is refused), and the marker's pending and loaded are written at its first-run start and at its whole end (Must not break, above); the list is open or closed, with its two-press prompt. The audit (`docs/design/3.9-state-machines-facts/lua-scenes.md`, section 14) found no transition fault to hold; the marker's states by start are the start step's rules (ruling 51, above).

## lib/factory.lua (`S.lib.factory`)

Included at the end of the data modules, after `lib/voice_presets.lua` and `lib/fx_hold.lua`, before `lib/params_setup.lua`; it reads every other module at call time. 3.8 builds and tests the mechanism and ships no set: there is no `factory/` folder in the script, so `sets()` is empty and no start finds an index.

Fields: `FACTORY`, `sets()`, `load(key)`, `loading()`, `parse_params(text)`, `is_rig(param_id)`, `open_list()`, `close_list()`, `is_open()`.

- **`FACTORY`**: the names (`folder` `factory/`, `index` `index.data`, `marker` `factory.data` under `data_folder` `strata/`, `params_file` `set.params`, `samples_file` `set.samples.data`, `side_base` `set`, `audio_folder` `audio/`, `install_folder` `strata/factory/` under `_path.audio`), `key_pattern`, `copy_chunk_bytes` (1 MiB), `backup_suffix` (`.bak`, the marker's), `pset_hooks` (the six hooks a set's side files are read through, then `voice_presets`, which reads no file and clears the voices' preset names, #861), `rig` (`groups` and `patterns`), the list's `list` layout and `texts` (its armed prompt is SETUP's `load_texts.confirm`), and `index_version` and `set_version` (`FACTORY_INDEX_DATA_VERSION` and `FACTORY_SET_DATA_VERSION`, what a test or SETUP's layout states write an index and a `set.samples.data` at, #847).
- **A set** is `factory/<key>/` in the script's folder (`norns.state.path`): `set.params` (a PSET's line form, `"<id>": <value>`; a slot line `"buf<n>_file": <name in audio/>`), `set.scenes.data`, `set.macros.data`, `set.matrix.data`, `set.gestures.data`, `set.sequences.data` (each its module's side file, as beside a PSET), `set.samples.data` (`{version = 1, files = {[<name>] = <a samples record>}}`, one entry per audio file, so the copy lists no folder) and `audio/`.
- **`factory/index.data`**: `{version = 1, sets = {{key, name, version}, ...}, first_run = <key> | nil}`. One that cannot be used (unreadable, another version, an entry that is no `{key, name, version}`, a key twice, a first run naming no set) is refused whole with one line and reads as none; it is never moved.
- **`factory.data`** (the marker, in `data/strata/`): `{version = 1, pending = <key> | nil, loaded = {[key] = <set version>}}` (ruling 51). One that cannot be used is set aside (`factory.data.bak`, ...) with one line.
- **`parse_params(text)`**: `{[id] = raw}` as norns' `params:read` reads the text, through `S.lib.params_setup.pset_line` (the one reader of a line, shared with the PSET read hook): a `--` line is none, the first line of an id wins, an id's `\"` unquoted, a line's trailing `\r` dropped (a set written with CRLF lines loads as its Unix copy; norns' own read keeps the `\r`, which a number ignores but a text or a slot's file name would not).
- **`is_rig(param_id)`**: whether an id matches one of `FACTORY.rig.patterns`. On this base the rig is 194 params: the 192 of the groups `strata_midi` (6), `strata_zones` (21), `strata_out_midi` (74), `strata_crow` (24), `strata_out_ii` (39), `strata_out_nb` (14), `strata_tape` (7), `strata_record` (6) and `strata_input` (1, `input_follow_gain`), and `tempo` (its action sets norns' `clock_tempo`) and `seq_follow_transport`. `scene_sequencer_enabled`, `mutation_enabled`, each `v<i>_solo`, `record_duration` and `record_level` are sound.
- **`load(key)`** → `true`, or `false` and why: `"loading"` (one runs), `"no set"` (no key, or none the index lists), `"unreadable"` (its `set.samples.data` cannot be used or its `set.params` cannot be read; one line). It reads the set's files, then runs `S.factory_clock`, which sleeps once (`clock.sleep(0)`, so its caller goes on first) and then:
  1. makes `audio/strata/factory/<key>-<version>/` and installs each file `set.samples.data` names, in name order, a `clock.sleep(0)` after each (so a test's `context.clock.advance()` stops after a given file): one there of the source's size is left alone (another size is copied again); one missing from the set's `audio/` gets one line and its slot line is skipped; a copy that fails stops the load (one line, the `.part` removed);
  2. stores each installed file's record for its installed path (`S.lib.samples.store_file`, which checks it: a refused one gets one line and the file keeps none);
  3. `S.lib.scenes.back_up_live()`: false stops the load (one line, the hint row's flash `set not loaded`); from here steps 4 and 5 run in a `pcall`, after which `S.lib.scenes.autosave()` always writes the scenes in memory back, and an error is raised again (nothing marked);
  4. a running scene fade canceled where it is (`cancel_scene_transition`, #859: its later steps and its landing would set the old target's params over the set's, a set without scenes or a step that raises included), then the params (Must not break): each refused line printed in id order, then every sound param in menu order. A line's value: a text param the text; a file param its installed path (a name not installed, one line); a number param the number rounded; the others the number (`inf`, `-inf` as norns reads them); a value that is no number is skipped with one line;
  5. the seven PSET hooks' `read(path_base, nil, path_base .. ".params", false)` in registry order (the six the side files go through, then `voice_presets`, which reads no file and writes none: it clears every voice's preset name, as a PSET read does, #861), `path_base` the set's `set`, each in its own `pcall`, inside `S.lib.side_files.read_only`: each module's own before and after hooks run (the gestures stopped, the macros' and morph's waiting applies dropped, so morph's clock never applies its corners over the set's params); the scenes take the set's without a second backup or a PSET mark (`docs/notes/lua/scenes.md`);
  6. the marker's `loaded[key] = version` written and `pending` cleared, `header_flash(name)`, a screen and grid redraw.
- **`loading()`**: whether a load's clock runs.
- **What a load leaves alone**: the rig, norns' params, the delay's freeze (saved nowhere, ruling 61: a held freeze stays held, unless a line moves the bypass, which ends the freeze as a bypass does), the scatter, the IO hooks' state and every slot the set does not name.
- **The first run** (`START_ORDER.factory_first_run`, 117: after the live files and the buffers are read, before the start-up clock starts any voice): Must not break, above. The load is not awaited: the script comes up at its defaults and the set takes over when its clock ends (its first `clock.sleep(0)` lets the start go on, so `pending` is on the card before any file is copied).
- **SETUP's list** (`open_list`, from SETUP's `factory sets` row; `close_list`; `is_open`): the index's sets, read at open, one row each, the name (printable, cut by `fit_text`) at x 0 and `v<version>` right-aligned at x 124, six rows from y 18, 7 px apart (`FACTORY.list`, as SETUP's); with no set one row `none`. E2 moves the cursor (clamped); K3 loads the set under it (`load`): while `S.scene_file.unsaved` the first K3 arms for `SCENE_LOAD.confirm_seconds` and the list's own hints say `K3 again: drop unsaved` while it is armed, over any flash (#897, as SCENES' overwrite prompt since #255: the next K3 loads, so nothing may hide that), and a second inside it loads; the owner's `animates` keeps the frame clock drawing while armed, and at the lapse it disarms and draws once more, so the prompt goes by itself; a K3 while a load runs is refused and flashes `loading`; a load that starts flashes `loading`, and one refused for its files `set not loaded`. K2 closes. Hints: the armed prompt while armed and ALT is up (under ALT K3 does nothing, so the prompt, which names K3, gives way to the ALT hints), else `K2:back E2:set K3:load`, `K2:back` with no set, the flash while one shows (under a modal owner the hint row is the owner's); with ALT held `E2:set` (K2 and K3 do nothing).
- **Cleanup** (`CLEANUP_ORDER.factory`, 116): the load's clock canceled where it is; a cut copy leaves its `.part` (the next load writes over it) and nothing is marked. SETUP's list is closed (`close_list`, its owner popped, #847; the modal's step 141 then finds it closed). The list's owner's record names it `SETS`, the header's title while it is on top (#901), and its `close` calls `close_list`.
