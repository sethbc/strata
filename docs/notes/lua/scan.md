## Must not break

- **Only this module calls `engine.syncScan`**, through the engine sender `scan sync <v>` (gated on the voice running), marked due on the LFO clock's round robin (`S.lib.lfos.mark_due`), with `S.lib.playheads.phase(v)` read when the send goes.
- **The bar sync** goes at the step in which `floor(clock.get_beats() / FOLLOW.bar_beats)` changes (the first step only notes the bar; a beat that jumps is a change), to each running voice that follows (`M.following`), in wrap or bounce, with no scan hold, no glide (`S.lib.positions.scrub_rate` 0) and no freeze. Never in one shot (every hit restarts it), never to a voice that does not follow.
- **Follow changes no stored value.** The scan's ratio is an engine factor (`S.lib.engine_sync.set_engine_factor("follow", "v<i>_buf_scan", ratio)`), applied after the clamp, so `engine_param_value("v<i>_buf_scan")` carries it and the param, the scenes and VOICE do not move. The read rate is `followRate`, worked out (`M.rate`), never a param, a scene field or a PSET value.
- **A small move is never sent; a larger one within a step**: the step hook (`S.lib.lfos.on_step`) sets the factor when the ratio moved by more than `FOLLOW.ratio_threshold` (0.5%) of itself from the one last set, and marks the rate due (`follow rate <v>`, whose sender sends `followRate` while the voice runs) when it moved so. A value back at exactly 1 is set at once, and `follow`'s action settles at once: a voice that stops following gets factor 1 and rate 1 without waiting for a step.
- **Every voice sync carries `followRate`** (the record's `sync`, `M.rate(v)`), and the start carries the factor (`start_value`), so a started voice never inherits an old rate. A fresh Strata sends `scanMode 0` and `followRate 1` and nothing else new.
- **A scan mode change restarts the scan**: the engine's mode change never does (both phases run and a `Select` picks one), so `scan_mode`'s action calls `S.lib.positions.restart_scan(v)` (`t_scanReset` to a running buffer voice, then the playhead's reset), after the param's `scanMode` send.
- **`pass_seconds(v, fraction)`** is nil unless the voice reads a buffer in one shot with an engine scan that is not 0; else `fraction × slot seconds / |scan|`, the scan as the engine has it (its factor included). Package 2b's notes read it for a one-shot note's end.
- Neither param joins a randomize, a mutation or the fader pages (`fader = false`, no `randomize`; plan ruling 35).

## Owns

`lib/scan.lua` (`S.lib.scan`, 3.7 design §2.3, §2.4, decision 3, package 2a), included right after `lib/positions.lua`:
- `M.FOLLOW` (`S.constants.FOLLOW`): `{ratio_threshold = 0.005, rate_min = 0.25, rate_max = 4, bar_beats = 4}`. `M.SCAN`: the record's keys, options and engine names. `M.MODE`: `{wrap = 1, bounce = 2, one_shot = 3}`.
- The voice-param record `scan`: `v<i>_scan_mode` (option `wrap`, `bounce`, `one shot`, default wrap; grain key `scanMode`, the index less 1) and `v<i>_follow` (option `off`, `stretch`, `repitch`, default off; no grain key). Both are discrete scene fields (`{1, 3}`, defaults 1 and 1, so a scene without them loads them off), VOICE rows at the end of a buffer voice's synth section (after the loop), with a layout state per voice (`v<i> buffer follow`, the cursor on `follow`).
- `M.mode(v)`: the scan mode's index (wrap for a bad voice). `M.following(v)`: a buffer voice whose `follow` is not off, reading a slot whose file has a tempo (`S.lib.samples.tempo(slot)`, package 2d; a finite tempo above 0), with a clock that gives a beat. Without a tempo, follow does nothing: no factor, no rate, no sync, and the playhead keeps to the time.
- `M.ratio(v)`: `clock tempo / file tempo` for a following voice, else 1; the clock's tempo is `60 / S.lib.params_setup.beat_seconds_now()`, as the synced delay and the clocked LFOs read it. `M.rate(v)`: the ratio clamped to 0.25-4 under `repitch`, else 1. Stretch scales the scan only (the pitch stays); repitch the scan and the read rate.
- `M.pass_seconds(v, fraction)` (above).
- The step hook, the two senders per voice and the bar sync (above).

Elsewhere: the playhead's modes, speed, region and beat time are `lib/playheads.lua`'s (`docs/notes/lua/playheads.md`); `restart_scan` is `lib/positions.lua`'s; the factor is `lib/engine_sync.lua`'s (`docs/notes/lua/engine-sync.md`); the engine's modes, `followRate` and `syncScan` are the positions area's (`docs/notes/engine/positions.md`). VOICE shows `buf_scan` as a speed (`1.00x`, `value_text` in `lib/pages/voice.lua`, `LAYOUT.speed_format`).
