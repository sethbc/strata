## Must not break

- **Ports and listeners only through `S.lib.io_ports`**: `claim`, `release`, `listen`, `unlisten`, `out`, `device` and `on_change`; nothing is set on a vport. Frames go out as raw bytes through `out(port):send(bytes)` and CCs through its `:cc(cc, value, channel)`, and only while a device is on the port.
- **Rig settings are read, never written**: `S.lib.io_rig.get` at each use (channel, first CC, encoding and hires are live) and `on_change` for the eight controller keys; the module never calls `set` or `step` (a structure test), so the layout states set a rig row the way a user does: E2 to the row and E3 on IO's own page (`M.turn_rig_row(key, value)`: `S.lib.pages_io.go_to_row("controllers", "controllers", {key = key})` puts the cursor on the row, raising, naming the key, when the section has no such row or the cursor did not land, so a state never turns another section's row; then E3 turns), devices plugged through the `context` their setup is given, faders moved by CCs through `context.midi.send`, MAP by `norns.pmap.rev`. The module has no preview path: its code reads only the rig, the ports and the params.
- **A macro's value is its param's value**: a fader sets `macro_<m>` with `params:set`, an E16 turn is `delta_with_detent("macro_<m>", d, {source = "midi"})` (a touch from midi, so macro learn and the gesture recorders see it). An LFO or a matrix routing on a macro moves engine values and never the param, so it neither moves a ring or an echo nor drops a pickup.
- **The echo guard takes one CC**: Strata keeps one entry per CC number it sent (value, channel, time); the first CC to arrive with that number, channel and value less than `CONTROLLERS.echo_guard_seconds` after it uses the entry up and is ignored, and an entry older than that is dropped. A real step that looks like the echo (from 0 the first step's echo is value 1, `rel1`'s step up) therefore costs one step at most, never a run of them.
- **One clock, only while a controller port is set**: `clock_id()` is nil with both ports off; the clock is ended before its replacement (a rig port change) and at cleanup 146. It is `S.lib.clocks`' (#870, `docs/notes/lua/clocks.md`): stopped with `S.lib.clocks.stop` (retired, never canceled, while its resume may be posted, so it ends at that wake running no tick), canceled with `S.lib.clocks.cancel` only by the cleanup step; `clock_id()` is its handle's id. All of a tick's work (the stale-pickup check, the echo, the marks) runs in one `contained_call`.
- **A claim that fails is shown and retried**: a controller whose configured port is not the port it holds (both on one port, or another owner has it) makes the section's status `port taken` (before `map clash` and `[--]`); the module's `on_claim` listener claims the port when its holder releases it (not during cleanup, `closing`).
- **`M.pickup` and the marks are a pure query** (IO's draw calls them; a draw never requests a redraw). The pickup ends in the fader handler and in each tick (`drop_stale`), and the tick requests the redraw when the marks changed.
- **A setting resets its own kind**: an E16 key (`e16_channel`, `e16_cc`, `e16_encoding`) resets the echo (every macro goes out again on the new numbers), a fader key resets every fader's pickup; only the port keys claim and release.
- **Nothing is echoed at an arrival**: the arrival (or the setting, with the device present) sends the labels and the title and clears the echo, so the next tick sends all sixteen CCs and one ring frame; a label is built only when a macro's first target id changes.
- **The frames' bytes** (`CONTROLLERS.header` = F0 7D 53 54): ring `01` then sixteen two-byte values (`round(value * 16383)`, high 7 bits first) then F7 (38 bytes); label `02 <m - 1> <4 characters> F7` (the first target's `target_label`, cut or padded to four, or `M<m>`); title `03 STRATA F7`. The index byte is 0-based; the E16's own indexes count from 1, which is why `extras/lib/e16/strata.lua` adds 1 (`docs/design/3.6-facts/checks.md` section 2).
- **Relative encodings** (`docs/design/3.6-facts/controllers.md` section 1, `checks.md` section 3): `rel1` 1 to 63 up by that many and 65 to 127 down by `128 - value`; `rel2` 63 up and 65 down (below 64: `64 - value` up, above: `value - 64` down); 0 and 64 nothing.
- **A 14-bit fader** (`faders_hires` on): the value is `(high * 128 + low) / 16383` once a low byte (CC + 32) has come, else `high / 127`; a new high byte resets the low to 0 once one has been seen (MIDI 1.0's rule for a 14-bit pair), so a boundary crossing never applies the old low byte; a 7-bit box never sends one and keeps its 7 bits.
- **Pickup**: a fader picks its macro up when its value comes within `pickup_window` (2/127) of the param or crosses it between two messages; a param value that is not what the fader last set ends it (`M.pickup` checks live). With hires on, a CC `faders_cc + m - 1 + 32` is the low 7 bits; once one has come the value is `(high * 128 + low) / 16383`, until then `high / 127`; a low byte before any high byte moves nothing.
- **The start step 94 sends nothing** with both ports off (a structure test's start log): refreshes at start ask for no redraw.

## Owns

`lib/io/controllers.lua` (`S.lib.io_controllers`, 3.6):
- `M.CONTROLLERS`, `M.pickup(m)`, `M.map_clash()`, `M.clock_id()`;
- the E16 handler (listener name `e16`) and the faders' (`faders`), the echo clock (15 Hz, at most 16 CCs a tick, newest values, one ring frame when any changed, a label frame for each macro whose first target changed), labels and the title at a device's arrival;
- IO's `controllers` section: the eight settings as `rig` rows, a `status` row of sixteen marks (`|` picked up, `.` waiting), the section status `map clash` or `[--]` when a set port has no device; `layout_states` `no port set`, `port without device`, `both present` and `map clash`;
- start step 94 (`START_ORDER.io_controllers`) and cleanup step 146 (`CLEANUP_ORDER.io_controllers`).

`extras/lib/e16/strata.lua`: the E16 scene script (never loaded by norns): `controller.onSysex` checks the header, F7, 7-bit data and the frame's length, then draws the rings (`leds.update`), labels (`slots.update`) and the title (`page.setTitle`). `test/stub_e16.lua` runs it with the E16's globals.
