## Must not break

- **A jump** (`jump(v, p)`): inside the voice's loop (`loop_start - 1e-6 <= p < loop_start + loop_length - 1e-6`, since the params return values a rounding away from a cell's fraction) `buf_pos` becomes `(p - loop_start) / loop_length`; outside, `loop_start` 0, `loop_length` 1 and `buf_pos` p. Everything but the reset goes through `params:set`, then `setGrainParam(v - 1, "t_scanReset", 1)` while the voice runs, the glide ends and the playhead resets. Only buffer voices respond; a stopped voice's position still changes and sends nothing.
- `set_loop(v, a, b)` sets `loop_start`, then `loop_length`, then jumps to a (the order the loop clamps need, `docs/notes/lua/loops.md`).
- **Only the grid's keys wait for the beat or bar** (3.4, `docs/notes/lua/quantize.md`): `grid_key`'s jump and two-key loop go through `S.lib.quantize.schedule("position<v>", ...)`, one-line wraps at the call sites, and `strip_key`'s recall through `recall_bookmark_quantized(v, n)`, which BUFFER's `bm` field calls too: it schedules `bookmark<v>` (a buffer voice and a bookmark 1..`NUM_BOOKMARKS` only) and keeps the target with the action's token, so `waiting_bookmark(v)` names the bookmark that waits while that action is the one that waits (nil once it ran or another replaced it); the held-key bookkeeping (`record.held`, the grid voice selection, store) still happens at the press. `jump`, `set_loop`, `recall_bookmark` and `S.lib.bookmarks.recall` themselves never wait: a step's bookmark lock reaches them and must never wait for a bar.
- **The scan hold, the glide's rate and the last recalled bookmark are transient**: never params, scenes or PSETs. The `bookmarks` record's `sync` empties the voice's holders and sends `scrubRate 0` and `scanHold 0` in every voice sync (after the source), so a started voice never inherits a glide or a hold, even one whose grid key is still down (its LED goes dim). Anything else that changes the hold or the rate calls `S.lib.playheads.advance(v)` first; the sync does not, since it relies on the grain-restart hooks, which reset the playhead (`S.lib.playheads.reset`) at every grain restart (a start runs them after its `voiceOn`, just after the sync it sends before `voiceOn`, and a running voice's source switch runs them in `send_grain_source` before its sync).
- **The scan hold has holders** (#238): a set per voice (`"grid:<port>"` for each grid port, `"arc"` for BUFFER's ALT ring 1, `"caller"` by default), and the voice is held exactly while its set is not empty (the `"scan holds"` invariant). `scanHold 1` goes out when the first holder joins, `scanHold 0` when the last one leaves, so one holder's release never ends another's hold. Only a buffer voice gains a holder; a release counts whatever the voice's source is now; a release by a holder not in the set changes nothing. Change the hold only through `hold_scan(v, on, holder)` (the cleanup step does too, once per holder); the `bookmarks` record's `sync` is the one other place, and it empties the set. Every change of the hold (`set_scan_hold`) calls `grid_redraw()`, so each grid's hold key shows it whoever changed it: another grid's key, the arc, a grid that left (released by the playhead tick) or cleanup.
- **A grain restart ends the glide** (`S.register_grain_restart`), so does a jump or a new ring turn. A source switch forgets the last recalled bookmark (`S.register_source_change`).
- **One glide clock per run of turns** (#515): `scrub_turned` starts a clock only when the voice has none; a running one reads the voice's latest turn (`fling[v].turned_at`) and waits until the ring has been still for `SCRUB.release_seconds`, so a run of deltas starts one clock, never one per delta. A turn during the glide sets the rate to 0 at once and sends the same clock back to waiting. Anything that ends a glide for another reason (`end_glide`, a grain restart, cleanup) cancels the clock and forgets `fling[v]`.
- **The row context cache is keyed by what a cell's level reads, never by the time** (#398): the key holds the loop, the head and record cells, the slot's seconds and the held cells, and the cache also compares the peaks table's identity (`S.lib.waveforms.peaks(slot)`, replaced only when the peaks change). The device's clock moves between two calls, so a time comparison never hits there.
- **A voice that reads no buffer has a dark strip** (#445): `strip_level` returns 0 for every key, and a press on its strip (`strip_key` with `z` 1) records no store, hold or pressed bookmark; releases still end what they ended before.
- **The glide's clock never dies of an error** (#517): its two steps (`start_glide`, `decay_glide`) run through the frame's `S.lib.ui_frame.contained_call`, the sleeps outside it. An error prints `strata: scrub glide failed:` with its traceback, once per distinct message per voice (a good step forgets it), and the glide runs on while its rate is not 0, so a failed send never leaves the engine gliding with no clock to end it.
- **A held grid key lives in `S.lib.grid_core.port_state(port).positions`** (the held position key with the page it was pressed on, the hold, store and pressed-bookmark keys per voice, and `store_down`, the one store key of a layout that selects a grid voice). It ends within a playhead tick (the port lets go of its hold, `"grid:<port>"`, and the held key is dropped) when the state is gone (the grid was removed) or `S.lib.grid_core.page(port)` is not the page of the press; a key event checks it first too. Never keep a held key anywhere else (`records` here only finds the state again). The stale-port check and the `"strip store"` invariant read the state with `S.lib.grid_core.existing_port_state(port)`, never `port_state` (which would create an empty state for a port whose grid left; an invariant only reads).
- **Store follows the grid voice on the layouts with one strip** (#239): a layout record with `selects_grid_voice` (the 128h, 128v and 64, read through `S.lib.grid_core.layout_of(port)`, never the grid's size) has one store key per port, so store belongs to the port while that key is down (`store_down`, the page of the press): a bookmark press stores for the voice the layout names then, the grid voice shown, whatever voice store was pressed with. The 256 keeps a store key per voice (`store[voice]`). A port holds store one way only (the `"strip store"` invariant).
- **A strip `hold` or `store` release ends that key for every voice the port holds it for**, whatever voice the release names (one such key per port on the layouts that select a grid voice, 128h, 128v and 64; the 256 has a hold and a store key per voice and a release ends only its own voice's; the layouts send the grid voice as it is at release time, which may have changed since the press, #221). `hold` calls `hold_scan(v, false, "grid:<port>")` once for each held voice and for the named one; `store` clears `store_down` and every pressed bookmark. A bookmark release likewise ends that bookmark key for whichever voice it was pressed for on those layouts (its LED goes back from 15 at once, even after a grid voice change); on the 256 it clears only its own voice's pressed key. A store release clears every pressed bookmark.
- **Each grid's strip LEDs are its own**: every layout's redraw passes its port to `strip_level`, so `"store"` and a stored bookmark show only that port's keys (a 256 beside a 128h never lights the other's store); without a port (the playhead clock's `display_signature`) they read any port's.
- Bookmarks are one registered voice-param record (`bookmarks`, count 4, `fader = false`): continuous scene fields (`scene_ranges` 0-1 each, so a scene outside it is rejected), defaults 0, 0.25, 0.5, 0.75 (also the migration defaults, scenes from version 3), PSET-safe in any order (nothing reads them in a filter), never touched by MAIN's randomize or mutated, never on the fader pages. A quick ALT+K2 on VOICE's bookmarks section is the one exception (#557): the record's `randomize` (`randomize_draws`) gives four uniform 0-1 positions in ascending order. VOICE draws them in row order, each set before the next is drawn, so bookmark n reads bookmark n - 1's new value and draws the lowest of the `NUM_BOOKMARKS - n + 1` uniform positions left above it: `1 - (1 - previous) * u ^ (1 / left)` (bookmark n averages n / 5).
- `scrub_friction` is `controlspec.new(0, 100, "lin", 0, 100, "%", 0.01)` in the group `strata_positions` (step 0, quantum 0.01); it is not a scene field.

## Owns

`lib/positions.lua` (`S.lib.positions`): moving a voice's read position.

**Jumps and bookmarks.** `jump`, `set_loop`, `recall_bookmark` (a jump to the bookmark; `last_recalled(v)` becomes n, remembered with the voice's source, and reads nil once the voice's source differs, stopped or not, so a scene recall forgets it too), `store_bookmark(v, n)` (the playhead, or `buf_pos` mapped into the loop when the voice is not running), `bookmark(v, n)`, `hold_scan(v, on, holder)` (a holder joins or leaves the voice's set; `setGrainParam(v - 1, "scanHold", 1 or 0)` when the set stops or starts being empty, sent while running; see States), `holds_scan(v, holder)` (whether that holder is in the voice's set; false for a bad voice: the arc rejoins by it). `scan_held(v)` and `scrub_rate(v)` are what `S.lib.playheads` reads.

**The glide.** `scrub_turned(v)` is called by the arc's ring 1 after each turn of the voice's `buf_pos` (BUFFER's arc, 2b). It ends a running glide, records `buf_pos` with the time, and (unless `scrub_friction` is 100%, the ring is direct) starts a clock, or tells the voice's running one about the new turn (#515): after `SCRUB.release_seconds` (0.08 s) with no new turn, the speed over the last `SCRUB.window_seconds` (0.1 s), in loop fractions a second, is sent as `scrubRate` and decays every `1 / PLAYHEADS.update_hz` by `exp(-dt / tau)`, `tau = SCRUB.max_glide_seconds x (1 - friction / 100)` (4 s at 0%). Below `SCRUB.stop_rate` (0.001) it sends 0 and ends. The cleanup step `scrub_glide` (`CLEANUP_ORDER`, 124) stops every glide and releases every holder of every scan hold (one `scanHold 0` per held voice).

**Grid.** `grid_key(port, v, cell, cells, z)`: a press jumps to `(cell - 1) / cells`; with another key of the same voice's row held, it sets the loop `[(lo - 1) / cells, hi / cells]` (the second key is not remembered as held, its release does nothing). Only buffer voices respond. On the layouts whose record has `selects_grid_voice` (the 128h, 128v and 64, from `S.lib.grid_core.layout_of(port)`) a position press for a buffer voice first calls `select_grid_voice(v)` (any other voice's press returns before it selects or jumps); the 256 never selects.
`grid_level(v, cell, cells)` (design 3.3 section 9): 0 for a voice that is not a buffer voice or whose slot reports 0 s (`S.lib.playheads.has_audio`, the check BUFFER's heads read too, so the two never disagree, #433); the voice's playhead cell 15 (a stopped voice shows where it will start: `buf_pos` mapped into its loop), the record head's 13, a held key 11, then 4 + round(peak x 4) in the loop (the cell's middle inside `[loop_start, loop_start + loop_length)`) or 1 + round(peak x 2) outside, from `S.lib.waveforms.bins(slot, cells)` (no bins: peak 0).
`strip_key(port, v, key, z)` and `strip_level(v, key, port)`: keys 1-4 recall (store held: store the playhead, level 15 while pressed), 6 otherwise and 10 for the last recalled; `"store"` 15 held, 4 otherwise (both from the port's own record when `port` is given, any port's otherwise; on a one-strip layout store is held for every voice the strip shows); `"hold"` 15 while the voice's scan is held (`scan_held(v)`, whoever holds it: another grid or the arc lights it too, and a voice sync dims it while the key is down), 4 otherwise (the key is momentary: it holds as `"grid:<port>"` while down; `record.hold[v]` stays the port's record of the voices it holds, for the release sweep and the stale-port end); `"whole"` sets the loop back to the whole slot with no jump, level 15 when it is, 4 otherwise. A voice that reads no buffer gets 0 for every key and records no press (#445).
A bookmark key that waits (`waiting_bookmark(v)`) shows `LEVELS.waiting_high` / `waiting_low` (15 / 2), alternating every `LEVELS.waiting_ticks` (4) ticks of the playhead clock (`advance_blink()`, its `blink` tick part; the clock is the only timer, #593): no steady level is clear of 6, 10 and 15 on a varibright grid. A stored key still shows 15 first. The blink moves the signature only while a bookmark waits. A wait's repaints go to every connected grid while any grid shows the page (`grid_redraw()` repaints them all, as for every signature change).

`display_signature()`: every LED level a page-5 grid shows plus the bookmark values, as one string; the playhead clock redraws when it changes (`docs/notes/lua/playheads.md`).

**Params.** `add_params()` (the `positions` record in `lib/params_setup.lua`, after `buffers`): `scrub_friction`. The `bookmarks` record adds `v<i>_bookmark_1..4` (three decimals) and VOICE's `bookmarks` section for a buffer voice; its `layout_states` put each voice on buffer 1 with the cursor on bookmark 1.

## States

The scan hold, per voice (`scan_hold[v]` and `holders[v]`, locals of `lib/positions.lua`; the port records' `hold` only remember which voices a port holds):

| `holders[v]` | `scan_hold[v]` | Meaning |
|--------------|----------------|---------|
| empty | false | not held: the voice scans |
| one or more holders | true | held: `scanHold 1` was sent (while the voice ran) |

Any other combination is illegal (the `"scan holds"` invariant). Transitions:

| From | To | Function |
|------|----|----------|
| not held | held | `hold_scan(v, true, holder)`, a buffer voice only (`scanHold 1`) |
| held | held (another holder) | `hold_scan(v, true, holder)` or `hold_scan(v, false, holder)` with another holder left: nothing is sent |
| held | not held | `hold_scan(v, false, holder)` by the last holder (`scanHold 0`); the cleanup step `scrub_glide`, through `hold_scan` per holder |
| either | not held | the `bookmarks` record's `sync` (every voice sync: the set emptied, `scanHold 0` sent) |

The last recalled bookmark, per voice (`recalled[v]`, a local of `lib/positions.lua`):

| `recalled[v]` | Meaning |
|---------------|---------|
| nil | no mark |
| `{bookmark, source}` | `recall_bookmark` ran with the voice on `source`; `last_recalled(v)` returns the bookmark only while `S.voices[v].source` is still `source` |

Transitions: `recall_bookmark(v, n)` sets it; the grain-restart and source-change hooks clear it; a source changed any other way (a scene recall of a stopped voice) hides it through `last_recalled` (and shows it again if a later recall brings the source back: the mark shows only while the voice has the source it was recalled on).

A strip's store, per port (the port's record in `S.lib.grid_core.port_state(port).positions`):

| Layout (`layout_of(port)`) | `store` | `store_down` | Meaning |
|----------------------------|---------|--------------|---------|
| selects a grid voice (128h, 128v, 64) | empty | nil | store up: a bookmark press recalls |
| selects a grid voice | empty | the page of the press | store down: a bookmark press stores for the voice the layout names (the grid voice shown) |
| a store key per voice (256) | `{[voice] = page}` for each key down | nil | each voice's store key down or up on its own |

Any other combination is illegal (the `"strip store"` invariant). Transitions:

| From | To | Function |
|------|----|----------|
| up | down | `strip_key(port, v, "store", 1)`: `store_down` (one-strip layouts) or `store[v]` (256) |
| down | up | `strip_key(port, v, "store", 0)`: `store_down` and every pressed bookmark cleared (one-strip layouts, whatever `v`), or `store[v]` and `pressed[v]` (256); `end_stale_port` when the grid is gone or shows another page |
