# 3.8 decisions (the groundwork before 3.8, then sound)

The other releases: [README](README.md).

This file opens with the work built between 3.7.0 and 3.8 and released with 3.8.0: the groundwork (`docs/design/3.8-groundwork-design.md`, approved 2026-11-16, its passages marked "amended" where the plan found the merged code to differ and "as built" where the build did). It settled the seams 3.8 builds on (one value table per voice with one registration path, an LFO's destination as a home routing of the matrix, one stepper under the pattern chain and the scene sequencer, scenes that travel with the PSET), made the three revisions (`frozen` renamed `locked`, fader pages for newer params, MIDI note off as latch or release) and fixed #738-#744 and #747-#754, with the findings filed during the build (#757, #758, #760, #762, #766-#770). What follows was decided by the maintainer, by the plan's review, by the plan where the design met 3.7's merged code, and as rulings while the packages were built, reviewed and landed (the plan is removed with this file; git history keeps it). The plan's thirty-seven rulings keep their numbers: the notes and comments cite them as "the groundwork's ruling N" or "ruling N of the groundwork before 3.8" (a bare "ruling N" beside a 3.7 feature is 3.7's plan ruling, `docs/decisions/3.7.md`). The build's rulings are unnumbered, each named by the package or the step that took it. Every device behavior below is built from the documents and is unverified on the device until the 4.0 hardware check (#6). 3.8's own decisions follow, under "3.8: sound".

## 3.8: sound

### Decided by the maintainer

- **The design's twenty-three decisions** (2026-11-17, each asked in the brainstorm with its alternatives; two not as recommended, 9 and 14), listed in the design's "Decided in the brainstorm". The design's "Cost if wrong" gives each one's cost at length. By number:
  1. A scene carries each voice's type; a recall switches it with a cut at the end of a fade, a morph at the crossing. If wrong: types a PSET alone holds, and a scene's recall that no longer changes a voice's sound.
  2. One tuning for the script, saved with the PSET; scenes do not change it. If wrong: a tuning per scene or per voice, a second set of params and sends.
  3. A voice preset holds the sound only, never the source, a buffer's file, the pattern, the lock or the routings aimed at the voice. If wrong: a second kind of preset that carries a place in audio.
  4. The 128h, the 128v and the 64 are reworked to the 256's model in this release. If wrong: three layouts relearned by their players for nothing.
  5. Each type's values are remembered per voice: every voice carries every type's params under today's ids, only the current type's shown (213 more params with twelve types). If wrong: about 190 params more than a CM3 has been timed with (#6); slots are the fallback, which changes every synth param's id.
  6. Voice presets are one library file of named slots, shared by every PSET. If wrong: a file per preset, or a PSET side file, and presets that travel.
  7. Factory sets are Strata's own list on SETUP, never norns PSETs, and a set changes sound only. If wrong: a player cannot see a set where they look for PSETs; SETUP could also save one as a numbered PSET.
  8. Any Scala tuning plays; scales and the scale editor work in tunings of twelve notes to the octave and show inactive in others. If wrong: an editor that follows the tuning's own degrees.
  9. Five new types, not the roadmap's three (not as recommended): wavetable, additive, noise, a detuned saw and a formant voice, twelve in all. If wrong: two more types to keep under the one voice-def limit.
  10. Voices read each other's output, loops allowed; the ring's writer clips softly at full scale. If wrong: a careless loop held at full scale into the master's limiter, loud but never unbounded; a feedback trim per reader is one control.
  11. Shimmer in the delay and in the reverb, each with its own amount, one interval for both. If wrong: one of the two places dropped.
  12. Plain sends: dry at full level, sends as sends, the mixes as return levels, a dry level per voice, a delay-to-reverb amount. If wrong: every 3.7 PSET's balance away from the defaults moved once, and the crossfade cannot come back beside it.
  13. The grids are panes: one list of seven pages for every size. If wrong: a 256 player relearns every page; fixed pairs are a table in the 256's arranger.
  14. Grid maps are reviewed as text (not as recommended, which was a browser). If wrong: a map misread in text, caught at a page's review.
  15. A reverb freeze on the high tier only, within 1 dB at the freeze, or cut and reported, never shipped jumping. It was cut (3a, #819; plan ruling 27). If wrong: nothing shipped; 3.9 builds it again.
  16. With the arpeggiator on, a held chord becomes the steps of one grain stream and takes no extra note slot. If wrong: chords that stay chords under an arpeggiating voice.
