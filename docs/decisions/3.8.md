# 3.8 decisions (the groundwork before 3.8, then sound)

The other releases: [README](README.md).

This file opens with the work built between 3.7.0 and 3.8 and released with 3.8.0: the groundwork (`docs/design/3.8-groundwork-design.md`, approved 2026-11-16, its passages marked "amended" where the plan found the merged code to differ and "as built" where the build did). It settled the seams 3.8 builds on (one value table per voice with one registration path, an LFO's destination as a home routing of the matrix, one stepper under the pattern chain and the scene sequencer, scenes that travel with the PSET), made the three revisions (`frozen` renamed `locked`, fader pages for newer params, MIDI note off as latch or release) and fixed #738-#744 and #747-#754, with the findings filed during the build (#757, #758, #760, #762, #766-#770). What follows was decided by the maintainer, by the plan's review, by the plan where the design met 3.7's merged code, and as rulings while the packages were built, reviewed and landed (the plan is removed with this file; git history keeps it). The plan's thirty-seven rulings keep their numbers: the notes and comments cite them as "the groundwork's ruling N" or "ruling N of the groundwork before 3.8" (a bare "ruling N" beside a 3.7 feature is 3.7's plan ruling, `docs/decisions/3.7.md`). The build's rulings are unnumbered, each named by the package or the step that took it. Every device behavior below is built from the documents and is unverified on the device until the 4.0 hardware check (#6). 3.8's own decisions follow when its plan is built.
