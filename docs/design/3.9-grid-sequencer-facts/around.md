# Facts: around the sequencer (SEQ page, step editor, arc, params, pattern operations, outside drivers)

Read on `land/sm-wave-2` (3dc72822).

## 1. How it works today

### Q1. The SEQ page
- **Pattern view** (`lib/pages/seq.lua:182-221`): 7 rows 6 px apart from y 13 (5 px since #921, which added a status line at y 55); 16 cells 4×4 at x 10-103; empty = level-1 outline, past `v<i>_seq_length` = 1×1 dot; playing column (`sounding_step`) +4; `G` x 121 (gated), `+`/`-` x 127, `f` x 108 on the selected row while fill. The strip between cursor and `G` is 11 px: no word fits (`SEQ_PAGE` `:47-56`, #735). Header `<tempo> bpm` (`:806`).
- Keys (`:723-803`): E2 step cursor; E3 level 0-15 (direct write + `note_pattern_edit`); K2 `pattern_toggle()`; K3 `toggle_pattern_step` (15/off); ALT+E2 `select_voice_by`; ALT+E3 tempo; ALT+K2 on release: quick = randomize/undo (`ui_alt.k2_up`, spec `{page=SEQ, section="pattern", voice, pattern=voice}` `:767`), held 0.5 s = edit view (`:796`); ALT+K3 `clear_pattern`.
- **Edit view** (`EDIT_ROWS` `:77-111`; 5 visible rows 7 px apart from y 24, `SEQ_EDIT` `:64`). *voice*: `length`, `division`, `swing`, `gate` (`seq_gate`), `gate len`, `gate rel`, `direction`, `misstep`, `fill` (`seq_fill`: on/held/off), `euclid` (`5/12 +2`, `S.seq_euclid`), `clear`. *step n*: `level`, `prob`, `ratchet`, `gate`, `cond`, `slice` (buffer voices), `note`, `note 2..8`, `add note`, `pos`, `pitch`, `size`, `bookmark` (with bookmarks). *chain*: `chain`, `from`, `scenes`, `bars`, `next`, `prev`, `random`, `quantize`. Every attribute edit goes through `M.turn_step` (`:353`: prob 0-100, nil = 100; ratchet 1-4; notes -14..14, ≤ 8; cond 79 stops; slice 1-64; locks on the param's controlspec).
- Edit-view keys: E2 row, E3 value, ALT+E2 step, ALT+E3 fine/rotation; K2 back; K3 step on/off (`clear` clears, `fill` toggles); ALT+K2 quick = randomize/undo, held = `reset_row` (`K2:cancel` where nothing resets, `:673`); ALT+K3 clear.
- **Step editor** (`:815-956`): the edit view as a modal owner (`:898`), opened only by `M.open_step_editor(voice, step, port)` (`:917`) from `lib/grid/core.lua:403-437` after a 0.3 s step-key hold (`GRID_HOLD.step_edit_seconds`, `lib/constants.lua:132`); a second open replaces the first. Closed by K2 (`:854`), the key's release, a pane page change, the grid's removal, or a whole-pattern replacement not its own (`end_step_gestures`, `lib/grid/core.lua:440-449`); its own (euclid, clear, ALT+K3, ALT+K2) run in `run_replacement` (`:450`, ruling 71). E1 inert; never moves `S.selected_voice`, the cursor or the page. Invariant `step editor` (`:950`); table in the notes' Machines.
- Layout states (`:958-1156`) cover every row at its widest (`edit_windows`).

### Q2. The arc's SEQ rings (`lib/arc/seq.lua`)
- Page rings (`:58-88`): 1 step cursor, 2 the cursor step's level (direct write + `note_pattern_edit`, carry forgotten when `"<voice>:<step>"` changes), 3 tempo (`delta_with_detent`), 4 the voice (`select_voice_by`); 10/10/10/20 ticks per step (`ARC_SEQ`, `:27-35`). Rings 1, 2, 4 draw exact fractions (`docs/notes/lua/arc-pages.md` Must not break 4). The arc button plays/stops (`lib/pages/seq.lua:811`).
- Step editor rings, set on the modal owner (`:184-187`): 1-3 the `pos`/`pitch`/`size` locks, `delta / ARC_TICKS_PER_SWEEP` of the param's range through `turn_step` (never `arc_sweep_param`); 4 `prob` at 10.24 ticks a percent; with ALT: ratchet, the cursor's note, bookmark, level, 20 ticks a step. This is one of the listed exceptions to the full-turn rule (arc-pages.md:9-13, :18).

### Q3. The sequencer's params
- `strata_seq` group (`lib/sequencer.lua:1611-1639`; `SEQ.group_params` 10 + quantize's 1): `seq_chain` (binary 0), `seq_chain_from` (1-16, 1), `seq_chain_scenes` (1-16, 2), `seq_chain_bars` (1-16, 4), `seq_chain_next`/`_previous`/`_random` (0-100, 100/0/0), `quantize_actions` (off/beat/bar, `lib/quantize.lua:24`), `seq_division_reset` (trigger), `seq_follow_transport` (binary 1), `seq_fill` (binary 0, `set_save` false). PSET: all but `seq_fill`; scenes: none.
- Per-voice record `seq` (`:1644-1692`, count 8): `seq_length` (1-16, 16), `seq_division` (8 options `1/32`..`1 bar`, default 3 = `1/16`), `seq_gate` (off/on, 1; grain key `seqGate` = option-1), `seq_gate_length` (control 0.05-16 st exp, 0.5), `seq_gate_release` (0.005-4 s exp, 0.1; grain key `gateRelease`), `seq_swing` (50-75, 50), `seq_direction` (forward/reverse/ping-pong/random, 1), `seq_misstep` (0-100, 0). All in scenes (`scene_defaults`, `:1682`): length, division, gate, swing, direction, misstep `discrete`; gate length and release crossfade (`scene_ranges`). PSET stores all. No VOICE rows, no fader, no randomize/mutate group. The chain carries only `SEQ.chain_keys` = length, division, direction, misstep (`:55`).
- Adding a per-voice param: the record (`S.register_voice_params`, `lib/state.lua:346`) adds exactly `count` through `add_voice_param` (`lib/params_setup.lua:889`; id `v<i>_<key>`); `scene_defaults`/`discrete`/`scene_ranges` make it a scene key that `voice_scene_keys` (`:1208`) feeds to `validate_scene` and `fill_scene` (`params.md` "Registering params"; `scenes.md` Must not break 1). Non-param data is a scene block, never a `capture_scene` field (`scenes/validation.md:32`).

### Q4. Pattern operations and undo
- `clear_pattern` (`lib/sequencer.lua:1504`): levels 0, **attributes kept**. `randomize_pattern` (`:1509`): each step `math.random() > 0.5` then level 8-15 (`RANDOM_STEP_FLOOR`), attributes kept. `M.euclid(voice, hits, rotation)` (`:1527`): first `length` steps from `er.gen`, hits 15, past-length steps and attributes kept, sets `S.seq_euclid`.
- `M.replace_pattern(voice, steps)` (`:1492`), the one door for a whole-pattern change, writes **levels only**, clears `S.seq_euclid`, ends overrides, `end_step_gestures`, `note_pattern_edit`. Callers: clear, randomize, euclid, the undo (`lib/mutation.lua:241`), PC paste (`lib/grid/pages/voices.lua:74`), a recall (`lib/scenes.lua:493`), a chain link (`lib/sequencer.lua:1143`).
- Undo: one `S.undo` (`mutation.md:15`); a pattern spec holds one voice's levels (`lib/mutation.lua:131-136`) for 5 s; `note_pattern_edit` (`:302`) ends it. Only SEQ's ALT+K2 (and the step editor's) makes one. The grid's CL/RN call `clear_pattern`/`randomize_pattern` after a 0.5 s hold, no undo (`lib/grid/pages/voices.lua:52-58, 106-108`; `mutation.md:13`'s "256's row 15" is stale). Wave 4's 4f (#922) adds a chain start's patterns to the undo.
- PC (`lib/grid/pages/voices.lua:64-76`): per port, `pane.state().patterns = {voice, steps}` levels; paste via `replace_pattern`; attributes and settings stay.
- Whole-pattern replacers: a scene recall (all voices; `steps` block by `set_all_steps`, `lib/sequencer.lua:302-316`, patterns after every param, at a fade's end, `scenes/recall.md:47-58`); the scene sequencer (a full `recall_scene` every `scene_duration` 4-120 s with the transition, never bar-quantized, `scenes.md:47-51`, `recall.md:11`); the chain (every `seq_chain_bars` bars: patterns, steps block, `chain_keys`, nothing else, `lib/sequencer.lua:1137-1166`; its first scene at a start, `:1575`).

### Q5. Mutes, solo, lock
- `lib/voice_mix.lua` record: `v<i>_mute`, `v<i>_solo` binary. The engine gets `silenced(voice)` as `voiceMute` in the persistent stage, even on a stopped voice; a mute never stops a voice and the pattern keeps stepping (`docs/notes/lua/voice-mix.md:11`). Silence hooks tell the targets, which end and skip a silenced voice's notes (`:12`; `docs/user/pages/io.md:45`).
- Keys: voices page MU/SO/LK on every size (`lib/grid/pages/voices.lua:97-102`; 8×8 its left half); M1-M7 on the 256's row 16 only (`docs/user/grid/256.md:8`); O1-O7 light 6 for a running muted/silenced voice. Lock: `toggle_lock` (voices LK, MAIN, VOICE); it covers params, never patterns (`mutation.md:20`).
- Scenes store `mute` (discrete, default 0) and `locked`, never `solo`.

### Q6. Fill
- On = `seq_fill` latched or any holder (`lib/conditions.lua:131`). Latch: SEQ's `fill` row (E3 or K3), PARAMETERS (MIDI-mappable), crow trigger action `fill` (toggles, `lib/io/crow.lua:424`), OSC `/strata/fill 0|1|2` (`lib/io/osc.lua:192`), both via `S.lib.io_actions.fill` (`lib/io/actions.lua:126`, `set_binary_param`). Holders: FL on the strip (256/128h row 8 col 2, 128v col 8 row 2; **no 8×8 key**), `hold_fill(holder, true, still)` from `lib/grid/pane.lua:311-313`. A release ends only its own hold; a latch stays; an unplugged grid's hold is dropped at the next LFO step (`lib/conditions.lua:118-128`); a page change keeps it. No Teletype fill call.

### Q7. What outside drives or follows the patterns
- MIDI: `note_gate(voice)` opens the voice's own gate length (#639); only a held key keeps the own note from a step, a latched one gives way (`docs/notes/lua/midi.md:9`, ruling 55); a note on slot 1 calls `own_note_taken`. Program change in recalls a scene through `io_actions.recall_scene` (quantized, `lib/io/midi_out.lua:502-511`).
- Actions: `patterns(mode)` (`lib/io/actions.lua:113`) calls `pattern_clock_start/stop` directly, **not** through the quantizer (K2 is); from crow's `patterns` trigger, OSC `/strata/patterns`, Teletype `CROW.C3 5 0 x` (`lib/io/ii.lua:597`). `mute` only from Teletype (`ii.lua:590`). OSC feeds `/strata/patterns` back; TouchOSC layouts are generated (`tools/touchosc/`).
- Transport: followed only with `seq_follow_transport` and an external source; a start plays every voice from step 1 at once, unquantized (`docs/notes/lua/sequencer.md:199`).
- Step outputs: `voices`, then `targets` (`lib/io/targets.lua:349`): each hit's pitches to MIDI out, crow, JF, W/, ER-301, TXo, nb; a step note ends 30 ms before its gate (`io/targets.md:5`).
- Chain against scene sequencer (Q4): the chain is bar-locked and pattern-only; the sequencer is seconds-timed and recalls whole scenes. Both pick only through `playable_slots`/`next_slot` (`scenes/sequencer.md:4`).

## 2. What the rework would touch

- **Step mode** (accent/pulse/move): a new per-voice param in the `seq` record (count 8 → more), discrete scene key, maybe in `chain_keys`; `seq_gate` today is the engine's `seqGate` grain key, so promoting it touches the record's `grain_keys`/`sync` (`lib/sequencer.lua:1675-1681`). SEQ: `EDIT_ROWS`' `gate` row and the pattern view's `G` mark (`SEQ_PAGE.gate_mark`, an 11 px strip shared with `f`). Move targets: `SEQ.lock_params` has pos/pitch/size only (`:65`); cutoff (`v<i>_filter_freq`, `lib/voice_mix.lua`) is no lock today; the step editor's arc rings 1-3 are those locks.
- **Lanes**: `S.patterns` (levels) and `S.pattern_steps` (attributes) are separate stores with separate scene formats (`data.patterns` NUM_VOICES × 16 ints 0-15, `lib/scenes.lua:1454-1470`; the `steps` block, `valid_steps` `lib/sequencer.lua:268`). Per-lane lengths are new per-voice values (params or a block). `turn_step`, `row_text`, the edit view's rows and `layout_states`, the arc ring 2 level, PC copy (levels only), the undo (levels only), `replace_pattern` (levels only) would all need a lane-aware form; at all-lanes-equal they must behave as today.
- **Keys and lights**: the step editor's open path (0.3 s hold, `grid_core.open_step_editor`) and its close rules; "holding a step turns that side into the step's values" overlaps the screen editor's open on the same hold and the level gesture (second key of the line sets level, `lib/grid/core.lua:420-438`).
- **Performing**: variations A-D. Today more than one pattern per voice lives in: the 16 scene slots (levels + steps block + seq keys), the chain (reads those slots), PC's per-port copy (levels of one voice), and the undo (one voice's levels). A variation store would sit beside them as a module-owned scene block (the rule for non-param data), switched through `replace_pattern`-like doors that keep the editor/gesture/override endings. Mutes/solo/fill on every size: the 8×8 has no FL; mute keys outside the voices page exist only on the 256.

## 3. Constraints
- Every pattern edit calls `note_pattern_edit`; every whole change goes through `replace_pattern` (`pages/seq.md` Must not break 2; `sequencer.md:27`).
- Step editor: open exactly while modal; only `run_replacement` sets `replacing`; its four grid functions keep names and shapes (`pages/seq.md` Must not break 10-11).
- Page files set no arc field, ring files only arc fields (tests, `arc-pages.md:3`); the whole-step exceptions are a closed list (`:9-15`); ring fractions and levels pinned (`:4-7`, `arc_pages_test.lua`).
- Layout tests and renders; the 7 rows fill y 13-53 above the hint row (y 62).
- Scenes: format 10, floor 10; a stored meaning change raises the floor (files set aside, never converted); no version-keyed code (structure test, `scenes/disk.md:3-4`); every scene key validated and filled. "Layer lengths: old scenes convert" (ledger answer 8) collides with the no-conversion rule.
- `NOTES_WORD_LIMIT` 9000 (`test/unit/docs_test.lua:2758`); AGENTS.md 8000 (`:855`).
- 200-local limit with 30 free per chunk/constructor (AGENTS.md Code Style).
- Lock never covers patterns; scenes never store solo; `seq_fill` never saved; actions set only their listed params (`io/actions.md:5`).
- Live patterns are in no PSET hook and no data file: only scenes keep them (`S.patterns` built fresh, `lib/sequencer.lua:87-104`; no `register_pset_hook` in it).
- Later waves change this area (`docs/design/3.9-state-machines-design.md:207-220, 274-289`): 4d (#933, arc carries), 4f (#922), 5a (#876, SEQ `K2:cancel` while a start waits), 6c (#921, SEQ shows the division reset, chain link and bars, a failed output), 6d (#901/#899, the step editor's `name`/`close`).

## 4. Open questions
1. Does a scene capture all four variations of every voice (and the order), or only the playing one? The chain and PC then follow; the code leans to a scene block holding all.
2. Lane data's scene shape: extend `data.patterns`/`steps` (raises the floor, sets old files aside) or a new block beside them (fill defaults from today's data). "Old scenes convert" needs a ruling against the no-conversion rule.
3. Which of the new per-voice values (mode, move target, floor, lane lengths, variation order) are params (PSET, scenes, MIDI-mappable) and which block data; and which join `chain_keys`.
4. Does a variation switch count as a whole-pattern replacement (closing the step editor, ending held step gestures, overrides, `S.seq_euclid`, the undo)?
5. The grid hold: screen step editor at 0.3 s versus the layer side turning into the step's values: both, or one replaces the other?
6. Should the `patterns` action stay unquantized while K2 waits for the quantizer?
7. Randomize and clear: per lane or whole pattern; should the grid's RN get the undo SEQ's has?
8. Move to cutoff: a lock param today's `turn_step`/arc rings do not cover.
