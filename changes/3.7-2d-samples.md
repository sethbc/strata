### Added
- A file's tempo, key and normalize, remembered per file (and start point) in Strata's data folder and back whenever that file is loaded into any slot; a take keeps its own until its slot is cleared or recorded over, an overdub of a file starts with the file's, a whole save hands them to the saved file, and a take recorded with record sync takes the clock's tempo. A key makes that note play the sample at rate 1 and be its quantize reference; normalize raises a quiet file to full level (up to 16 times).

### Changed
- `buffers.data` is version 3 (a take's settings per slot); a version 2 file loads with none. Strata 3.6 sets a version 3 file aside.
