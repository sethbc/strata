### Added
- A random sound file can be loaded into a buffer from the folder of its current file, the last folder you chose from, or the audio folder, and the empty buffers can be filled with different random files from a folder.
- A start point for files longer than a buffer: the file reloads from the new start a moment after you stop moving it.
- Saving only the loop region of the voice reading a buffer.
- The buffers' waveform overviews are read from the engine, and refreshed twice a second while a buffer records without emptying.
- `buffers.data` remembers each buffer's start point (version 2; files from 3.2 still load, from 0).
