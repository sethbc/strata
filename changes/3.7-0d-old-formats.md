### Changed
- Scenes files from before 3.5 and buffer lists from before 3.3 are no longer converted; they are set aside as backups (`scenes.data.bak`, `buffers.data.bak`) with one console line, and no `.v<n>` copy of an older file is kept at a save.
- PSETs no longer hold a hidden format line, and a PSET from before 3.3 is no longer converted as it loads (the Pulse voice's res loads as it is, and 3.3's LFO settings are not imported); a setting a PSET does not hold still loads its default.
- A MIDI map left on one of 3.3's LFO parameters is no longer moved or removed at start: a map carried straight from 3.3 shows an error in the console on its CC again (maps on a norns that ran 3.4 to 3.6 were repaired then).
