### Added
- A slice editor on BUFFER: over the buffer's waveform, pick, nudge (1 ms, ALT 0.1 ms), add and delete its slice starts, and set its file's slice mode and count or sensitivity, tempo (by hand or by bars), key (by hand or from a MIDI note) and normalize; the arc's four rings pick, nudge, turn the amount and the tempo. BUFFER's waveform marks the slice starts.

### Changed
- K3 on BUFFER's new `slices` field opens the slice editor instead of recording.
- On BUFFER, ALT+K2 now loads a random file into the buffer (held, it still fills every empty buffer) and K2 held clears it; a quick K2 still opens the file browser.
