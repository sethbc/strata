### Added
- Each voice's grain window is two controls, shape and skew, that LFOs and macros move; grains can be dropped by chance; a cloud mode keeps the overlap constant as the size moves; the pan wander is a setting.

### Changed
- The five grain envelopes are gone; a 3.7 PSET's envelope is not loaded.

### Fixed
- The engine no longer builds its grain envelopes with a per-sample loop at start (Closes #778): the window bank is built from whole-table operations.
