### Added
- SEQ's edit view and step editor edit a step's whole chord: one row per note (`note`, `note 2` to `note 8`) and an `add note` row; ALT+K2 held on a note row removes it, and the step editor's ALT ring 2 turns the note the cursor is on.

### Changed
- Turning a step's `note` below -14 removes that note, not the whole chord; ALT+K2 held on a `note` row removes that note and no longer clears the chord.
