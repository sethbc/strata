### Added
- K1 held is ALT: with K1 held, K2 and K3 take a page's ALT actions and E2/E3 its ALT turns. The pages get their ALT actions in later 3.1 work.

### Changed
- K2 and K3 pressed while K1 is held no longer run their plain action (for now they do nothing). A key pressed with K1 held stays an ALT press until it is released, even if K1 comes up first, so on BUFFER it never opens the file browser.
