### Changed
- "Freeze" is now called "lock" everywhere you see it: `[L]` in the voice list, `[LOCK]` on MAIN, K3's hint and the grid's row 16. A locked voice is still protected from randomize and mutation; scenes keep storing it as `frozen`, so saved scenes load unchanged. "Freeze" is kept for a real audio freeze in a later release.
- Each effect (filter, delay, reverb) remembers its last non-zero mix, so bypass can restore it.
