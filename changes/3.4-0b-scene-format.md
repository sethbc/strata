### Changed
- Development: no user-facing change. A scene recall is now one ordered list of the scene's values (`scene_entries`) applied by `apply_entries`, which sends exactly what a recall sent before, in the same order; scenes gain registered blocks, migrations, per-slot revisions and lock hooks for 3.4's features, the LFOs' scene fields move into `lib/lfos.lua`, and an empty slot's name is empty (3.3's default `scene <n>` loads as no name).
