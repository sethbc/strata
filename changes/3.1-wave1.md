### Added
- ALT: hold K1 and K2, K3, E2 and E3 take a page's ALT actions; the hint row shows them while K1 is held. The pages get their ALT actions in later 3.1 work. A key pressed with K1 held stays an ALT press until it is released, even if K1 comes up first, so on BUFFER it never opens the file browser.
- Fine adjustment: ALT+E3 moves a continuous value a tenth as far per detent (the MAIN parameter and the FX rows). Values in whole steps (sources, envelopes, MIDI settings) still step whole values. ALT+E2 and the arc are never fine.
- Center detents: a value whose range runs through 0 (pan, buffer scan, crossmod amounts) stops at 0 when a turn reaches or crosses it, even on a fast turn, and stays there for the next 3 encoder detents or 24 arc ticks.
- The header shows eight page dots (the current page bright), a play triangle while the patterns play and `REC` while a buffer records, beside `[M]` and the scene. A changed value can show in the header for 1.5 s in place of the dots and indicators.
- One level of undo for randomize: for 5 seconds after a voice is randomized, its previous values can be put back (MAIN's ALT+K2 in 3.1). Randomizing another voice, recalling a scene, a mutation of that voice or editing one of the randomized params ends it; the pitch drift does not.
- Grid holds and step levels: hold a step key and press another key of the same voice to set the held step's level (its share of 15 along the voice's steps), on every grid size. With several grids connected, each grid shows and changes its own page.
- Hold to save: a grid scene save key saves once held for half a second and lights while held; a shorter press, or unplugging the grid mid-hold, saves nothing.
- The user documentation has one page per screen page (docs/user/pages/) and per grid size (docs/user/grid/).

### Changed
- "Freeze" is now called "lock" everywhere you see it: `[L]` in the voice list, `[LOCK]` on MAIN, K3's hint and the grid's row 16. A locked voice is still protected from randomize and mutation; scenes keep storing it as `frozen`, so saved scenes load unchanged. "Freeze" is kept for a real audio freeze in a later release.
- Each effect (filter, delay, reverb) remembers its last non-zero mix, so bypass can restore it.
- The header no longer shows master density (it is on the FX page's first row and MAIN's arc ring 1). `[M]` moves left to make room.
- Grid scene saves (row 3 of the scene page on the 16×16 and 16×8) need a half-second hold.
- K2 and K3 pressed while K1 is held no longer run their plain action (for now they do nothing).
