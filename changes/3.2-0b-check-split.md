### Changed
- The engine check runs per area: `test/engine_check.scd` is a runner for the area files `test/engine_check/<area>.scd` (structure, voices, grains, lifecycle, memory, buffers, files, effects, performance), `STRATA_ENGINE_CHECK_AREAS` runs only the areas it names, and after each area the check makes sure no voice synth is left running and prints the area's time. The engine notes are one file per area under `docs/notes/engine/`, each opening with what must not break; `docs/notes/engine.md` is their index.
