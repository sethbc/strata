### Added
- SETUP is now a scrolling list of fields: MIDI port, channel mode, mutations on/off, rate, probability and amount, save scenes and load scenes. E2 moves, E3 changes the value, K3 runs save or load. The grid, arc and buffer status lines sit below the fields.

### Changed
- SETUP no longer shows the saved-scene count. The grid size line appears only while a grid is connected.
