### Added
- MAIN shows three fields for the selected voice (its main parameter, grain size and grain density; for an input voice grain size, density and pitch), each with its unit. K2 moves the cursor between them and E3 adjusts the one under it.
- ALT+K2 on MAIN randomizes the selected voice; pressing it again within 5 seconds undoes the randomize. The hint row shows `K2:undo` while it can.
- The MAIN details show the voice's source (`synth`, `buf 2`, `input`) next to its name.

### Changed
- MAIN's K3 now starts and stops the selected voice, and the arc button follows it. Lock moved to ALT+K3; randomize moved from K2 to ALT+K2.
- MAIN's voice list entries start with the voice number (`3- fold [L]`), and the list keeps four voices in view at both ends (no blank top row on voice 1).
- MAIN marks a locked voice `[L]` and triggered grains `[T]` on the ON/OFF row, and a locked voice's values are no longer dimmed.
- The crossmod sources (`mod:V3 V5`) moved from MAIN to the VOICE page.
