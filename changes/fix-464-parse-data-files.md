### Fixed
- `scenes.data` and `buffers.data` are read by a parser of the layout norns writes them in, never run as Lua: a file holding code (one passed from another norns, say) can no longer touch the card or keep norns at its loading screen, and a hostile file can no longer use up the memory at start. Such a file, like any other damaged one, is reported in the console and kept as `.bak`; every file an earlier Strata saved loads as before (#464).
- A scenes file holding a value that is not a finite number (`inf`, `nan`, or a number too large such as `1e999`, which earlier versions read as infinite) is refused as any other invalid value is, instead of being loaded into a scene (#464).
