### Fixed
- **Development: the local engine check's full run no longer crashes at the start of the modulation area on SuperCollider 3.14.1.** With no areas named, `test/run_engine_check.sh` now runs the areas in CI's shards (read from `.github/workflows/test.yml`), each in a sclang of its own, one after another, and prints a line per shard; the run passes only when every shard passed. A signal stops the running shard and says where it came, after the lines of what ran, and no shard starts while a crashed shard's server may still hold the port. One sclang running every area failed there about half the time (#671). `STRATA_ENGINE_CHECK_ONE_SCLANG=1` still runs every area in one sclang.
- **Development: the engine check runner's tests no longer depend on timing.** The tests that check the runner stopped a process (sclang's scsynth, a crashed sclang's server, a signaled run's sclang) wait up to 10 s for its end, and count a zombie as ended, instead of asking once at the moment the runner returns, which a slow machine could answer before the process was gone (#673).
