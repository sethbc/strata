### Changed
- Development only, no change to the sound: every accent of a voice goes through one door (`S.lib.engine_sync.retrigger`) that tells the new `voice_hit` hooks once per hit (a step, a note, an action, a start); the engine values can carry a factor (`set_engine_factor`); a modulation source can list settings rows that MOD shows in a settings view (K3 on its row, K2 back; on the arc, ring 1 the row and ring 2 the value); `S.lib.chance.pick` picks the next slot by three chances; the tempo divisions 3.7 shares are `S.constants.DIVISIONS`.
- The scenes file is version 8. A version 7 file (3.5 and 3.6) loads as it is, and the first save writes version 8, which 3.6 does not load.
