### Added
- BUFFER page: an input meter (`in`, eight segments of 6 dB from -48 dB, the louder channel, the highest segment held for 1 s), so you can set the record level before recording.
- BUFFER page: ALT+K2 clears the buffer under the cursor (it never opens the file browser).
- BUFFER page: the row under the cursor lists the voices playing that buffer (`v2 v6`).
- BUFFER page: the arc's button records or stops the buffer under the cursor, as K3 does.

### Changed
- BUFFER page: E2 now moves a cursor over the eight buffers instead of selecting the voice (pick the voice on MAIN). K3, K2 (load), ALT+K2 and ALT+K3 act on the buffer under the cursor, whatever the voices play, so any buffer can be recorded, loaded, cleared or saved.
- BUFFER page: the left column has three fields, source, record duration and record level; ALT+E2 picks one and E3 changes it.
- BUFFER page: saving moved from K2+K3 to ALT+K3 (with the same `saved`, `busy` and `empty` confirmations). The hint row reads `K2:load K3:rec`, and `K2:clear K3:save` with ALT.
- BUFFER page: the buffer rows are 7 px apart and scroll, six at a time, with a scroll bar; empty buffers show `-` without a length, and names use the width up to the length column.
