### Changed
- Each voice's filter and sends now run once per voice, in one mix stage after its grains, instead of in every grain synth. The sound is the same (measured), except that a filter, send, amp or crossmod change or an accent during a source switch's crossfade or cut now also reaches the old buffer or input tail, and with the voice filter on, the fades of a grain synth (an attack, a release, a switch or a slot fade) now run before the filter: while the fade runs the difference is at worst about -37 dB of the level at the 5 kHz default (a slot fade) and about -2 dB at 200 Hz, res 0.9. The steady sound is unchanged.
- Each grain stream takes about 16 KB less real-time memory.
