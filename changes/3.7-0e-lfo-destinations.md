### Changed
- LFO and matrix destinations are listed by voice: the globals, then each voice's destinations together (its main parameter through its level), then the macros; ALT+E3 on an LFO's destination jumps to the next voice. A PSET or scene keeps the destination itself, so a later release that adds destinations never moves it; an LFO's destination in an older PSET or scene reads as none.

### Fixed
- A scene recall that changes an LFO's shape, mode or division no longer sends its old rate and depth to the engine for a moment: the LFO's recalled settings arrive together.
