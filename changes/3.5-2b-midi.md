### Added
- Chords from MIDI: a key played while another is down on the same voice adds a note, up to eight on a voice, from the pool of extra notes all voices share.
- MIDI note off has three choices: latch (a chord sounds on, each note at the highest pressure it reached, until the next chord's first key replaces it), release (each note ends with its key, and the voice stops with the last) and auto, the default (latch on a plain keyboard, release in the MPE modes).
- MPE in two modes: mpe selected plays an MPE controller's notes on the selected voice, mpe split on every voice whose zone and note range hold them, each note with its own pitch bend, pressure and slide (CC 74). A LinnStrument, an Osmose or an Exquis plays chords on one voice with every finger's own expression.
- Poly aftertouch presses its own note, and channel aftertouch every note its channel holds.

### Changed
- A second held key adds a note where 3.4 re-pitched the voice's one note; a voice's note cap at 1 restores 3.4's one note.
- MIDI notes pitch input voices: a note sets an input-sourced voice's grain pitch (note 60 plays at 1).
- Changing the MIDI channel mode or the note off mode releases every MIDI note, as a port change does: every chord's extra notes end (latched or held), each voice keeps sounding its own note, the sequencer's notes play on, the keys still down are forgotten, and the new setting decides what happens to their voices. Under release (with auto, any MPE mode) those voices stop, so switching from per voice or omni to an MPE mode with keys down stops the voices they held; under latch every voice keeps sounding. In 3.4 a channel mode change kept the held notes.
- A voice's own note that faded under other notes (its key lifted in release mode while others sounded) comes back, without an accent, when the voice's last note ends and the voice runs on (a sequenced note ending, or a change to latch), so a running voice never falls silent for want of a note.
- A note off that no note on played (a stray one, or one after a reset) changes nothing; in 3.4's voice off mode it stopped its channel's voice.
