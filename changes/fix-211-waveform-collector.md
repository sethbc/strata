### Fixed
- **A long load or save on the high tier could corrupt the engine's language process.** A while after the engine started, loading or saving a long file (a 300 s buffer) could fill maiden with the language's garbage-collector errors, leave a load that never took effect or a save reported as failed, or crash or hang SuperCollider's language process, taking the engine and its sound with it until a restart. The engine's startup, a voice synth started again after it ended, a synced overdub or loop recording and an engine LFO's new shape no longer leave the language's garbage collector a frame pointing at freed memory (#211).
- **Development: the engine check's 300 s load-and-save check no longer fails about one run in ten** (the waveform area, CI's `record,waveform` shard), and a full single-sclang run no longer crashes at the start of the modulation area (#671). The area hooks, `strataAreas` and each call from a function of a method that keeps a closure go through `Engine_Strata:areaCall`; a structure test checks the hooks, `strataAreas`, the calls it lists and that the commands whose methods keep a closure stay one call each, and a structure-area check covers the SynthDef functions (`docs/notes/engine/structure.md`, Areas). A collector error seen again is a regression of that rule, not noise to rerun.
